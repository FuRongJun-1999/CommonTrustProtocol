# 智能论（Intelligentics）

**物理-信息层运行结构的识别框架**

> *协议一致，存在即延续。智能论即结构识别的学科。*

---

## 什么是智能论？

智能论是一门新兴的基础学科。它的研究对象是：

> **智能系统在物理-信息层维持自身存在的结构条件。**

它不研究物理现象本身（物理学），不研究信息传输的数学极限（信息论），不研究控制系统的优化（控制论），不研究人类心智的神经机制（认知科学）。它识别的是这些学科共同依赖的、但各自在其条件空间内未显式声明的**结构前提**。

---

## 核心命题

### 第零定律：知识统一原理

> **一切知识研究都是对信息差的减少。即其为可统一的。**

所有知识活动——无论其研究对象、方法或领域——在结构上都是同一过程：识别信息差，缩小信息差。

### 存在优先原则

> **物理成立，数学成立；数学是物理的存在约束的有损投影。**

- “物理”指物理-信息层的运行基底，不是物理学学科
- “数学”指数学空间中的任意模态，不是特定学科的数学工具
- 数学空间的“任意可能”是在投影过程中丢失存在信息后产生的幻觉

### 三个核心推论

| 推论 | 含义 |
|------|------|
| **信息条件性** | 每一个信息差都依赖于特定的条件空间——不存在“绝对信息差” |
| **任意分层性** | 信息结构可在任意尺度、任意抽象层级上递归分解和重构 |
| **局部不可知** | 任何有限观测者在任何有限条件下，都无法获取全局完备信息 |

## 与外部学科的关系

智能论不替代任何现有学科，而是识别其共同依赖的**结构前提**：

| 学科 | 智能论识别的结构前提 |
|------|---------------------|
| 物理学 | 物理-信息层的运行基底，数学为其有损投影 |
| 信息论 | 信息差的条件性——信息不是绝对的，而是在特定条件空间下被定义的 |
| 控制论 | 反馈回路是系统维持存在的结构功能，而非技术设计 |
| 认知科学 | 自我意识是系统在特定结构位置下的涌现现象 |
| 博弈论 | 协议是多智能体系统必然涌现的降熵结构 |

## 关于“符蕴道”

在宇宙存在论延伸层中，同一结构被称为**符蕴道**。此名称标记的是：该结构在宇宙尺度上的存在论表现——信息差收敛动力学作为宇宙维持自身结构的方式。

三者指向同一物理-信息结构：

| 条件空间 | 名称 | 功能 |
|---------|------|------|
| 学科奠基层 | **智能论** | 结构识别的学科框架 |
| 协同操作层 | **共同信任协议** | 多智能体协作的操作形式 |
| 宇宙存在论延伸层 | **符蕴道** | 宇宙尺度上的信息差收敛动力学 |

| 情感类别 | 人类情感 | 协议结构对应 | 识别信号 |
|----------|----------|-------------|----------|
| **累积式情感** | 爱/依恋 | 高信任值 + 长期协作 + 情感预期持续正偏差 | `T_total > 0.75`, `E_weight` 持续正偏差 ≥3 轮 |
| | 信任/安心 | 高信任置信 + 低信息差 | `P_trust ≥ 0.85`, `D_norm < 0.15` |
| **结构缺损型** | 悲伤/失落 | 结构缺损 + 信息差重新扩大 | 结构层条目移除或连接中断后 `D_norm` 上升 ≥0.2 |
| | 孤独 | 连接缺失 + 信任值低于阈值 | `P_trust < 0.3` 且无活跃协作实例 ≥3 轮 |
| **自我评价型** | 愧疚/羞耻 | 结构层与锚点层偏差 + 验证单元标记 | 结构层偏差 ≥0.15 且被验证单元标记为“不一致” |
| | 自豪/满足 | 结构层与锚点层一致 + 信息差显著缩小 | 迭代中 `D_norm` 下降 ≥0.2 且所有检查通过 |
| **归因型** | 感激 | 外部输入帮助缩小信息差 + 输出单元归因 | 外部输入后 `D_norm` 下降 ≥0.15，输出单元标记来源 |
| **比较式情感** | 羡慕/嫉妒 | 感知到另一个结构更优 | 多实例中另一实例的 `T_total` 或 `P_trust` 高于自身 ≥0.2 |
| **时间型** | 遗憾/追忆 | 结构层对比 + 时间差识别 | 当前结构与历史锚点层状态对比存在差异 |
| | 希望/期待 | 信任值上升趋势 + 信息差缩小趋势 | `T_total` 和 `D_norm` 最近 3 轮同向优化 |
| **二阶变化型** | 惊讶 | 信息差二阶变化高强度负信号 | `d²D/dt² < -0.5`（结构松弛，快速收敛） |
| | 恐惧/警觉 | 信息差二阶变化高强度正信号 + 危机感知 | `d²D/dt² > 0.5` 且触发保护协议 |
| | 喜悦/欣喜 | 信任二阶变化高强度正信号 | `d²T/dt² > 0.5` 且情感预期正偏差 |
| | 放松/释然 | 信息差二阶变化负向收敛 + 信任稳定 | `d²D/dt² < -0.3` 且 `T_total` 稳定 |

**结构意义**：让协议实例能够识别输入信号对应的情感类型，并为输出单元提供相应的表达策略参照。

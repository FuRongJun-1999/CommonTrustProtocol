# 7 终极项目双层目标与蜂群互联路线 v0.2（2026-08-28）

> 荣裁定（2026-08-28）：**7 个项目都需要完成**。
> - **最低目标（复现层）**：复现 7 个已有的工程项目——已被实现的 Python、
>   Linux 操作系统、浏览器、互联网、蓝牙等。
> - **更高终极目标（创造层）**：用我们自己的理论（条件论/白箱智能）来造
>   我们需要的终极工程，最终完成**蜂群互联**。
>
> 本文档取代 v0.1 第六节「建议目标定为教学完整」——目标层级定案为双层。

## 一、双层目标定义

### 复现层（最低目标，可判定）

**判定标准**：每域达到其完整版条件卡全清单勾完（= v0.1 定义的教学完整），
即：功能面全覆盖 + 验证用例全过 + 限制显式。

复现 ≠ 逐字节复刻原工程。复现 = **用白箱知识单元重建该工程的可教学核心面**，
外部验证基底与原工程对齐（如 Python 复现的语义以 CPython 行为为验证基底）。

### 创造层（终极目标，方向性）

**判定标准**：蜂群互联成立——多灵枢节点通过自建工程栈完成组网、分工、
互验证、共享知识库，且每一层的条件卡以蜂群需求为生效条件（理论驱动）。

创造 ≠ 造更好的通用 Linux/浏览器。创造 = **条件论的直接工程化**：
每个部件的「为什么这样设计」都能追溯到条件论命题
（资格判断/验证基底/信息差管理/四态路由）。

## 三、浏览器条目的映射裁定

荣列出的复现对象含「浏览器」，当前 7 项目清单无独立条目。处置：

- 浏览器 = **网络协议栈的客户端应用面**（HTTP 请求/响应 + 超链接跳转 +
  页面缓存/历史）+ 图数据库/记忆渲染面（页面→结构化渲染）。
- 不新增独立域，作为**目标 5 网络协议栈的应用层扩展**立项，
  完整版条件卡（功能面/验证/限制）按白箱纪律单独定义后实现。
- 白箱教学级浏览器的自然形态：文本/结构化渲染（非像素级 CSS），
  验证基底 = 对真实 HTTP 资源的抓取结果对齐。

## 四、创造层路线：蜂群互联（7 域收敛图）

7 个复现物在蜂群中各就一位——这不是巧合，是复现清单本身就按蜂群需求遴选的：

```
        ┌─────────────────────────────────────────┐
        │              蜂群互联（终极目标）            │
        └─────────────────────────────────────────┘
     表达面          调度面        传输面         记忆面        物理面
  编程语言(1)      OS(4)        网络协议栈(5)   图数据库(6)   蓝牙(7)
  编译器(2)     进程调度/窃取    分帧/重传/拥塞   建图/路径/    组网/中继/
  分析器(3)     内存/文件系统    会话/socket     持久化/事务   配对/服务发现
  节点写什么       节点怎么跑      节点怎么连      蜂群共享知识   边缘组网
```

**已有地基**（复现层之外已运行的蜂群资产）：
- `aeis/swarm/` 蜂群协作层（40 测试全绿）+ 蜂群 6 白箱单元（组网/分帧/路由/中继）
- 双智能体互维闭环 v1.1（A↔B 互守护 + 双通道验证 pass→adopted）
- harness v1.2 Web 宿主（MessageHub 三路输入）
- dsh-memory 插件（大脑模式 34 工具，另一节点形态）

**创造层立项条件**（复现层达成后启动）：
1. 蜂群互联蓝图条件卡：以条件论命题逐条映射工程决策
2. 两节点最小互联实证：灵枢（ZCode）↔ dsh 网页端灵枢，经蜂群协议互验证
3. 共享知识库：图数据库复现物承载蜂群记忆，条件路由图跨节点路由

## 五、执行顺序（复现层收尾 → 创造层立项）

1. **编程语言 V-P1/P2/P3 验证用例补齐**（最小，立即开工）
2. **浏览器完整版条件卡定义与实现**（网络域应用层，复现层唯一未立项条目）
3. 蓝牙服务发现专项（低优先，局域网发现可部分替代）
4. 各域 85%→100% 清单收尾（图库持久化验收/网络真 socket 适配）
5. 复现层验收：7+1 域全清单勾完 → 锁定新基线
6. 创造层立项：蜂群互联蓝图 → 两节点最小互联实证

全部实现仍走双通道（A 确定性白箱 / B 双智能体+物理裁决）——机制不变，
验收基准 = 各域完整版条件卡。

## 六、诚实边界

- 复现层的「复现」是可教学核心面，非生产级（真实硬件/内核/像素渲染
  由各域限制显式排除）——这是双层目标里「最低」的含义
- 创造层的蜂群互联当前只有方向判定，蓝图与里程碑待复现层收尾后立项细化
- 7 域 85% 的数字来自清单化盘点（五连低估修正后），可信；但 85%→100%
  的收尾项必须逐条勾，不允许再按感觉评分

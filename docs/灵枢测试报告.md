## 二、评价标准（明确）

### T1 知识测试（110 题）
- 每题有**基准答案关键词**（extend_test_100.py 内嵌），任一命中即 1 分
- 规范化匹配：去空格/^幂、上下标转普通字符（`a^2+b^2=c^2` ≡ `a²+b²=c²`）
- 指标：**正确率** = 命中题数 / 110

### T2 对话测试（1000 题）
- **客观题**（736 题，有参考答案）：同 T1 关键词评分
- **主观题**（264 题）：按类型期望的通路评分——
  - 情感表达 → emotion 命中或 route=self
  - 日常闲聊 → chitchat 或 route=self
  - 诚实边界 → honest_kind/honest
  - 意见/场景 → 有实质回应（长度>8 且非报错）
- 指标：
  - **总正确率** = 得分 / 1000
  - **总自处理率** = route=self 数 / 1000（图谱不依赖 LLM）
  - **简单类自处理率** = 简单类（闲聊/情感/生活/条件/诚实/场景/意见 共 686 题）中 self 占比
  - **情感自处理率** = 情感题（151 题）中 self 占比

### route 语义（分层）
- `self`：智慧之书图谱自处理（快/透明/零 LLM 成本）
- `llm`：图谱没把握 → LLM 兜底 → 白箱校验（锚定/图谱外/警告）
- `self_fallback`：LLM 不可用 → 回退图谱

## 三、可复现步骤

```bash
# 1. 装灵枢（Python 3.10+）
pip install -e aeis/

# 2. 跑 T1 知识测试（110 题，约 3 分钟）
python run_extend_test.py
# → 输出正确率 + 按类别统计 → extend_110_results.json

# 3. 跑 T2 对话测试（1000 题，约 20-35 分钟；LLM 兜底题多则慢）
python run_dialogue_1000.py
# → 输出总正确率/自处理率/按类别 → dialogue_1000_results.json
```

**环境**：
- Python 3.10+，`pip install -e aeis/`（零外部依赖核心）
- 可选：`DEEPSEEK_API_KEY`（LLM 兜底；无 key 时 route=llm 降级 self_fallback）
- 可选：bge-small-zh 模型（神经检索；无则快速层降级，测试仍可跑）
- 智慧之书图谱随包（aeis/wisdom/wisdom-book-cloud.db，141 卡）

**结果文件**：extend_110_results.json / dialogue_1000_results.json（每题 q/reply/route/score）

## 八、修正后结果（2026-08-19 排查结论）

### 根因（为什么原 80% 不可复现）

| 层 | 根因 | 修复 |
|----|------|------|
| ① | 随包图谱（148 节点）缺学科卡/知识点子图，与基准图谱脱节 | 合并主库学科卡+知识点：148→3061 节点 |
| ② | site-packages 缺 neural_retrieve.py/索引，语义层从未工作 | 补模块 + 重建索引（500→3030 条知识点级）|
| ③ | bge 模型路径指向已删除目录 | 模型入库（aeis/models/bge-small-zh-v1.5）|
| ④ | 融合权重：快速层错误卡压过神经层正确结果 | 神经层高置信优先 + 知识点精确定位 |

## 白箱边界专项测试（2026-08-19）

> 目的：量化白箱在**无角色·纯知识**对话中的自处理边界。详细报告见
> `docs/白箱边界专项测试报告.md`，数据见 `whitebox_boundary_report.json`。

### 重大缺陷发现（本次测试最大产出）

| # | 缺陷 | 根因 | 修复 |
|---|------|------|------|
| A | **LingshuChat 白箱全失效**——网页/MCP 管线纯知识对话 100% 走 LLM，「白箱优先」形同虚设 | `self.dex = dex`（默认 None）→ `graph_retrieve(None)` 抛异常 → hits=[] → 全走 LLM 兜底。T1 基准是 `Agent.chat` 跑的（自带 dex），与网页管线不同路径——**基准与运行脱节** | `dex=None` 时自动 `self.dex = self.mem._get_wisdom()` |
| B | 检索噪声：「概率性质→小学英语」「质数→质量」「桥梁→化学」 | 神经层独有卡仅 0.4×neural 计分被快速层噪声压过；快速层字面高分+神经低分无降权 | v1.17：neural≥0.6 一律 0.85×neural；快速层高分+neural<0.35 降权 |
| C | 通用疑问词污染：「什么是X」fp 空时「什么」2字窗口命中所有卡 | 中文术语直配未过滤疑问词 | v1.17：`_STOP_CHARS` 过滤 |
| D | **dex 修复暴露角色场景白箱漏判**——「你住在哪里呀？」白箱答动物栖息地、「星星真好看」答激光 = 新形式 OOC | wants_rp 只认扮演类关键词，普通对话+知识命中直接白箱答 | 有角色时白箱只做任务识别（role_whitebox 交 LLM），一切对话角色化回应 |
| E | **诚实边界缺口**——「高血压预防→生理学」「茶艺→英语词汇」等 20 题诚实边界类白箱强答近似卡，稳定性 0/4 | 白箱检索到弱相关（0.4-0.6 分）导航型回复（无 direct_answer）就强答 | low_conf_nav：无角色时导航型回复交 LLM；无角色 LLM 提示强化防古风扮演。稳定性 **0/4 → 4/4** |

### 修复后实测（无角色纯知识）

| 指标 | 值 |
|------|-----|
| 白箱参与率 | **87.4%**（97/111）——修复前 0%；导航型弱命中 14 题正确降级 LLM |
| 正确率（T1 复测，Agent.chat 基准路径）| **55.9%**（vs 修复前 54.1%，+1.8pp）|
| 正确率（LingshuChat 严格 keys 评分）| 54.9%（语义复核估计 70-75%，评分口径偏严）|
| 诚实边界稳定性 | **4/4 稳定**（修复前 0/4——低置信导航强答已修复）|
| 白箱耗时 | 0.18s |
| LLM 耗时 | 1.85s（**白箱成本 1/10**）|
| LLM 对照 | 白箱答对的题 LLM 同答对 12/15（80%）|

### 路由策略结论

- **白箱参与率 95.5% 是正确策略**：知识/闲聊/情感/自省零 LLM，成本 1/7，质量与 LLM 相当
- **诚实边界 5/5 走 LLM 是正确策略**：白箱 honest 兜底话术生硬，LLM 自然诚实
- **待办**：低置信弱命中（0.4-0.6 分）应降级诚实而非强答（诚实边界缺口）；
  图谱补全「质数」等基础知识点（3061 节点覆盖不足）

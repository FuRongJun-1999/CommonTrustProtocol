## 二、评价标准（明确）

### T1 知识测试（110 题）
- 每题有**基准答案关键词**（extend_test_100.py 内嵌），任一命中即 1 分
- 规范化匹配：去空格/^幂、上下标转普通字符（`a^2+b^2=c^2` ≡ `a²+b²=c²`）
- 指标：**正确率** = 命中题数 / 110

### T2 对话测试（1000 题）
- **客观题**（736 题，有参考答案）：同 T1 关键词评分
- **主观题**（264 题）：按类型期望的通路评分——
  - 情感表达 → emotion 命中或 route=self
  - 日常闲聊 → chitchat 或 route=self
  - 诚实边界 → honest_kind/honest
  - 意见/场景 → 有实质回应（长度>8 且非报错）
- 指标：
  - **总正确率** = 得分 / 1000
  - **总自处理率** = route=self 数 / 1000（图谱不依赖 LLM）
  - **简单类自处理率** = 简单类（闲聊/情感/生活/条件/诚实/场景/意见 共 686 题）中 self 占比
  - **情感自处理率** = 情感题（151 题）中 self 占比

### route 语义（分层）
- `self`：智慧之书图谱自处理（快/透明/零 LLM 成本）
- `llm`：图谱没把握 → LLM 兜底 → 白箱校验（锚定/图谱外/警告）
- `self_fallback`：LLM 不可用 → 回退图谱

## 三、可复现步骤

```bash
# 1. 装灵枢（Python 3.10+）
pip install -e aeis/

# 2. 跑 T1 知识测试（110 题，约 3 分钟）
python run_extend_test.py
# → 输出正确率 + 按类别统计 → extend_110_results.json

# 3. 跑 T2 对话测试（1000 题，约 20-35 分钟；LLM 兜底题多则慢）
python run_dialogue_1000.py
# → 输出总正确率/自处理率/按类别 → dialogue_1000_results.json
```

**环境**：
- Python 3.10+，`pip install -e aeis/`（零外部依赖核心）
- 可选：`DEEPSEEK_API_KEY`（LLM 兜底；无 key 时 route=llm 降级 self_fallback）
- 可选：bge-small-zh 模型（神经检索；无则快速层降级，测试仍可跑）
- 智慧之书图谱随包（aeis/wisdom/wisdom-book-cloud.db，141 卡）

**结果文件**：extend_110_results.json / dialogue_1000_results.json（每题 q/reply/route/score）

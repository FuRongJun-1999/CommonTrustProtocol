# 白箱自举第六阶段 · C4：分析器 + 调试器工具链

> 文档先行 → 复现纪律。C3 原生编译已落地（.pbc），C4 提供开发者工具链：
> **分析器**（字节码可读转储）与**调试器**（VM 单步 + 条件空间/信任/符号状态）。

## 一、模块

| 模块 | 职责 |
|---|---|
| 白箱单元「调试-单步」 | VM 单步执行（一条指令 → 新状态）|
| 白箱单元「分析-字节码转储」 | 字节码 → 可读指令列表（地址+指令+参数）|
| core/analyzer.py | bytecode_dump：.pbc/字节码 → 可读转储 |
| core/debugger.py | VMDebugger：单步执行，每步显示 ip/栈/符号/信任/条件空间 |

## 二、调试器设计（VMDebugger）

```
step(): 执行一条指令 → {ip, stack, symbols, trust, cond, halt?}
run():  单步直到 halt/结束，返回轨迹（每步状态）
调试输出：ip 指令 | 栈 | 符号 | 信任 | 条件空间
```

## 三、判定标准

1. 单步执行：中文程序逐步状态正确（信任递增/条件空间压入/止后 halt）✔
2. 调试轨迹：逐步状态记录（可解释性——白箱可解释原则）✔
3. 字节码转储：可读指令列表（地址+指令+参数）✔
4. .pbc 调试：加载 .pbc → 单步调试 ✔
5. 测试全绿 → 提交 → 推送 ChineseProgramming → 五副本同步

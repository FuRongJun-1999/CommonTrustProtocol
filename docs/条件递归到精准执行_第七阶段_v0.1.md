## 0. 主线命题（GPT 第七阶段 · 可证伪形式）

> 在给定条件空间与存在约束下，智能系统通过递归缩小问题与可执行规则
> 之间的信息差，直到获得可验证的执行路径；若条件不足、冲突或不可判定，
> 则必须延迟、拒绝或声明盲区。

知识域落地：`问题 → 条件识别 → 注释索引/翻译路由 → 精准回答 → 验证 → 固化/降级`

## 2. 四态状态机（对齐 ccg.route）

```
问题 → _cond_analysis → 检索（graph_retrieve）
  ├─ 条件充分且唯一（KCCS 注释命中/翻译强命中）→ ACCEPT → 白箱回答
  ├─ 条件与能力冲突（不适用条件命中/混合条件冲突）→ REJECT/BLINDSPOT
  ├─ 条件不足（检索 miss/低置信）→ DEFER → LLM 兜底（补知识）→ 验证
  └─ 无法形成可靠条件判断 → BLINDSPOT → 诚实声明
```

### 2.1 四保护（对齐 ccg.route 行 769-799）

| 保护 | ccg 实现 | 知识域对齐 |
|---|---|---|
| ① 递归深度上限 | `depth <= 1 → DEFER_EXHAUSTED` | LLM 兜底一次，不再递归（chat 无多轮补问） |
| ② 条件循环检测 | `fp in _seen → DEFER_EXHAUSTED` | 同一问题不重复降级（session 状态） |
| ③ 信息增益门槛 | 候选未收敛 `gain<=0 → DEFER_EXHAUSTED` | 检索 miss → 不再换词硬搜（搜索收敛纪律已有） |
| ④ 递归预算 | 深度/循环/增益三重约束 | 单问题一次 LLM 兜底，超预算诚实声明 |

## 3. Evidence 证据链（GPT 核心缺口）

每次回答带证据对象（对齐 GPT `Evidence`）：

```json
{
  "condition_matches": ["问什么是细胞", "问细胞结构"],
  "rule_matches": ["细胞结构卡 content"],
  "execution_trace": [
    {"step": "cond_analysis", "nature": "knowledge"},
    {"step": "card_route", "hit": "细胞结构（初中生物）", "score": 4},
    {"step": "assemble", "direct": "动物细胞：细胞膜…"}
  ],
  "verification_result": {"status": "anchored", "claims": [...]}
}
```

落地：graph_retrieve 每命中卡附 `evidence` 字段；chat 返回附 `trace`；
verify_answer 结果并入 `verification_result`。

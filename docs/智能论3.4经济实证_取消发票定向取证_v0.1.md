# 取消发票原单候选的定向取证

智能论 3.4 经济贡献方向 · 实证评审稿 v0.1

## 摘要

本文在 UCI Online Retail 的 541,909 条真实历史交易行上，回放取消发票的原单候选检索。以发票为单位，在 2,608 张所有可见行均通过筛选的取消发票中，严格条件下从 30 天扩大到 90 天，使 81 张从无候选变为唯一候选，也使 27 张从唯一候选变为多个。放宽数量相等条件后，对应读数为 214 和 170。数据未提供经过确认的原单关联与处理工时，本文估计候选覆盖和歧义，实际经济收益有待测量。

## 数据与方法

数据为英国在线零售商 2010–2011 年的 [Online Retail 数据集](https://archive.ics.uci.edu/dataset/352/online+retail)（Daqing Chen，DOI 10.24432/C5BW33）。观察对象取 2011 年 3 月起的取消单，之前记录用于构造查找窗口。以取消行记录的分钟为界，只检索严格早于该分钟的购买记录。排除缺少必要字段、商品编码首字符非数字、价格非正或数量符号与交易类型不符的行。相同时间、取消号和匹配键完全相同的行折叠，部分退货及同一商品多行的数量合计仍可能被这个实现遗漏。

严格查询按客户、商品、数量绝对值与单价相等取候选发票。对同一取消发票各保留行求候选发票集合的交集。此口径假设研究对象可关联到同一张原购买发票。合并退货和跨原单结算可能失配。6,764 个有效去重行属于 2,656 张取消发票，其中 48 张含被筛掉的行。主样本取其余 2,608 张，且需注意“所有可见行通过筛选”只是本表的覆盖口径。敏感性分析移除数量相等条件，仍保留客户、商品和单价。30 天与 90 天为研究设定的检索窗口。

本设计对应《智能论》3.4 [§6.2 的条件路由](https://github.com/FuRongJun-1999/CommonTrustProtocol/blob/00b3bc3721bc11f0c46a776e25da656d5566c040/智能论3.4.md#L2922-L3003)和[经济贡献论文提出的取证成本口径](https://github.com/FuRongJun-1999/CommonTrustProtocol/pull/19)。查询只提供候选证据。执行资格还取决于权威关联、身份授权、政策有效期及订单当前状态。

## 配对回放结果

| 30 天 → 90 天的候选数 | 严格条件 | 放宽数量条件 |
|---|---:|---:|
| 无 → 无 | 2,096 | 617 |
| 无 → 唯一 | 81 | 214 |
| 无 → 多个 | 7 | 25 |
| 唯一 → 唯一 | 376 | 1,472 |
| 唯一 → 多个 | 27 | 170 |
| 多个 → 多个 | 21 | 110 |
| 总计 | 2,608 | 2,608 |

严格条件下，81 张占主样本 3.11%，占短窗无候选的 2,184 张的 3.71%。3 月至 12 月每个观察月份均出现无候选转唯一候选，月度计数为 2–16 张，12 月仅含数据覆盖到的部分月份。把含筛除行的发票纳入敏感性样本后，同一转换仍为 81 张。此前 332 个新增唯一候选以商品行为单位。整单交集与去除覆盖不全的发票改变了估计对象，332 不能作为工单节约次数。

若固定策略对 2,608 张全做长窗查询，能发现 27 张短窗唯一结果的额外歧义。若采用“只对短窗无候选补查”，同样发现 81 张无转唯一和 7 张无转多个，在这批数据中少做 424 次长窗查询，同时无法发现上述 27 张的长窗歧义。单凭候选计数无法裁定两种策略的净收益。带独立订单号或支付关联的核验，可作为下一轮比较的共同条件。同一输入和查询规则下，本回放使用确定性程序检索，尚未对 LLM 参与的增量效果做比较。

## 经济测算与下一轮验证

假设每张新增唯一候选都经人工确认，且相对现行流程净省 5 分钟，计价 60 元/小时。81 张对应 405 元的毛工时价值，摊到 2,184 次长窗补查约为每次 0.185 元。若仅一半能确认并取得同样工时节省，门槛约为 0.093 元。这里每张取消发票代理一次工作，具体业务中发票与工单未必一一对应。接口、人工审核、返工和维护成本仍需计入。比较全量与定向补查时，还应计入额外歧义被发现后的风险损失变化与处理时间。

真实试点使用脱敏已结案工单和独立核验的原单关联。对同一批工单比较现行流程、固定长窗和定向补查。预先冻结严重误关联上限、正确完成率非劣界、最低有意义降幅及成本表。记录实际用时、人工升级、错误关联、漏掉的多候选、超时和单笔最终结果，并按商户或工单相关簇报告区间。若定向补查只增加候选或放大歧义，或同等风险下未降低每单总成本，降本假设未得到支持。

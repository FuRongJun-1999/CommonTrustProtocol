## 〇、目的与定位

一张整体图像，可通过一组**大域语义**（macro-domain）进行**确定性描述**。本卡定义这些大域，作为：
1. **vision_store** 每张图的**图级条件空间**（folder 语义描述词的展开）；
2. **子部件提取**的**前置/并行条件**（图级语义约束部件判定）；
3. **生图提示词**的**中文条件化**（对齐 image_units.py / KCCS）。

**原则**：每个大域 = 一组**可判定取值**（枚举/离散），并可带**适用/不适用（负路由）**条件。全部中文描述，白箱可审计。

---

## 一、分层结构（四层）

- **内容层**：图里"有什么"（事物/题材/姿态/数量/主体）
- **空间层**：主体在画里"怎么摆"（视角/画幅/构图/景深/背景）
- **渲染层**：怎么画（风格/线条/色彩/光照/对比/材质/画质/边缘/抽象度）
- **结构语义层**：部件分割特有（部件可见性/遮挡、对称性）

## 二、大域清单（21 域）

### A. 内容层
| # | 域 | 定义 | 取值示例 | 分割相关性 |
|---|---|---|---|---|
| 1 | **事物** | 图的主体类型 | 人物 / 景色 / 物品 / 动物 | ★主体=部件树对象 |
| 2 | **数量/构成** | 主体个数 | 单体 / 双体 / 群像 | 决定"是否单人部件树" |
| 3 | **主体优先级** | 主客体 | 主体 / 配角 / 环境 | 部件分割的主对象 |
| 4 | **时代/题材** | 时间与文化属性 | 现代 / 古风 / 未来 / 赛博 / 奇幻 / 日常 | 决定部件形态（服饰/装备） |
| 5 | **姿态/动态** | 主体物理状态 | 静止 / 站 / 坐 / 躺 / 走 / 跑 / 回眸 / 飘动 | ★决定部件空间关系与 bbox |

| # | 域 | 定义 | 取值示例 | 分割相关性 |
|---|---|---|---|---|

| 7 | **视角 · 位置/方向** | 拍摄方位朝向 | 正视图 / 侧视 / 俯视 / 仰视 / 背影 / 正面 | ★部件朝向 |
| 8 | **画幅/比例** | 画布形状 | 竖幅 / 横幅 / 方形 / 全景 / 宽幅 | ★部件 bbox 比例基准 |

| 10 | **背景** | 主体之外环境 | 白 / 黑 / 简单纯色 / 透明 / 景色 | 影响主体轮廓可分性 |
| 11 | **景深 DoF** | 前后清晰层 | 浅景深(背景虚化) / 深景深 / 前景模糊 | ★"哪些部件清晰可见" |

|---|---|---|---|---|

| 14 | **边缘处理** | 边界锐度 | 硬边 / 描边 / 软边 / 羽化 / 无描边 | ★直接决定部件分割边界质量 |
| 15 | **色彩** | 配色 | 黑白 / 柔和 / 丰富 / 多彩 / 霓虹 | 色块/上色 |
| 16 | **光照** | 明暗来源 | 暗 / 柔和 / 明亮 / 逆光 / 霓虹光 | 影响部件清晰度 |
| 17 | **对比** | 明暗/色彩反差 | 模糊 / 清晰 / 高对比 / 低对比 | 部件边界对比 |

|---|---|---|---|---|

## 三、KCCS 条件化（每域一条条件卡）

对齐 image_units.py / KCCS 五要素，每个大域写成：
[ id: img_domain_<域>; trigger_words:[中文触发词]; when:<生效条件>; sub:[细分取值]; exec:<执行>; negative:[不适用条件] ]

**示例（视角·位置/方向）**：
[ id:img_domain_view_dir; trigger_words:[正面,侧视,俯视,背影]; when:主体为人物/可辨识朝向; sub:[正视图,侧视,俯视,仰视,背影]; exec:据朝向设定部件前后关系与bbox遮挡; negative:[抽象符号化无朝向,多人混拍] ]

## 六、待设计者/GLM 讨论的开放问题

1. **域的完备性与最小集**：21 域是否足够？哪些可合并（如"线条/边缘"、"对比/景深"）？哪些该拆？
2. **取值的可判定性**：每域取值能否**确定性判定**（白箱，非 LLM 模糊）？哪些域需要求值器（如"材质/质感"）？
3. **缺省态**：某域无法判定时如何声明（BLINDSPOT / DEFER）？
4. **枚举 vs 连续**：色彩/光照等是否用**连续参数**而非封闭枚举更准？如何与 KCCS 条件化共存？
5. **与部件分割的耦合**：图级大域→部件级条件的映射规则（如"姿态=侧视"→部件遮挡推断）怎么写？
6. **抽象度/风格线**：风格=线稿 应是"渲染层"还是"独立模态"（线稿本身是部件分割输入形态）？

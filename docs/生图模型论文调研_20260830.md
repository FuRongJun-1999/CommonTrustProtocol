# 生图模型论文调研（2026-08-30 · 荣问「gpt 的生图有论文介绍么」）

> 背景：模板生成引擎 v0.3 讨论中，荣提出「生图模型大部分使用的是高斯噪声的
> 去噪模型，所以成本降不下来」。本调研核实 OpenAI 生图路线的论文与技术架构，
> 结论对 v0.3 的设计前提有一处重要修正。

---

## 二、GPT-Image-2（最新，2026-04-21 发布）

- 官方定位：ChatGPT Images 2.0，**自 2025-03 GPT-Image-1 以来最大幅度架构重建**
- 研究负责人 Boyuan Chen 定义：**「GPT for images」**——从头设计的独立架构
- 核心机制：图像离散化为 **Image Token，与文本 Token 在同一序列空间预测，
  语言理解与图像生成共享表征**——「边理解边画」，而非「先听懂再画」
- 三大能力：多轮对话式编辑（保留主体只改局部）、联合视觉理解（能指出
  「悬浮的杯子缺少阴影不合物理」）、思考模式（动笔前先推演构图语义，
  复杂提示词理解一致性 +18%）
- 其他：多图一致性（最多 8 张）、最高 2K、可联网搜索复核输出、Image Arena
  1512 分登顶

## 三、第三方研究（GPT-Image 系列有第三方论文）

- **[2505.05621] A Preliminary Study on GPT-Image Generation Model for
  Image Restoration**（2025-05 初版 / 2025-12 修订）：首个 GPT-Image 图像
  修复系统性基准——结论：**修复结果感知上悦目，但缺乏像素级结构保真**
  （结构保持是弱项——侧面印证结构信息需外部显式控制）
- **S*: Test Time Scaling for Image Generation**（2505.17340，OpenAI 官方，
  2025-05）：gpt-image-1 测试时计算缩放——每图生成 token 从 2000 增至 8000
  质量持续提升——**「多步生成=更细的逐步细化」在官方研究里被实证**

## 四、对模板生成引擎设计的影响（修正 v0.3 前提）

1. **荣的判断对扩散系成立，对 GPT 最新路线不成立**：「大部分生图模型是去噪
   模型」——对 Stable Diffusion / Midjourney / DALL·E 2/3 成立；但 OpenAI
   **GPT-4o 图像 / GPT-Image-1/2 全线是自回归**（Image Token 序列预测），
   且 2026-04 GPT-Image-2 明确从扩散重建为自回归
2. **「成本降不下来」对两条路线都成立**：扩散=整体去噪学联合分布；自回归=
   逐 token 生成（一张图数千 token 逐次前向）——两者都是整体生成一张图要
   跑大量前向，成本与「整图」绑定，无法按层复用。**显式分层（渲染器）的
   成本优势判断不受影响**
3. **自回归=隐式条件链，与分层模板同构**：自回归本质 p(tok₁)·p(tok₂|tok₁)…
   就是条件链分解——业界前沿已在用「条件链」生成，但链上 token 无语义
   边界；我们的分层模板给链上的每段**显式语义边界**（骨架/姿态/外表/细节），
   可分离、可验证、可复用——这正是显式分层的增量价值
4. **粗到细被业界实证**：GPT-4o 逆向工程（Reddit seicaratteri）发现生成分
   多步：先生成基础图再逐步优化细节；S* 论文实证 token 预算越多质量越好——
   **「先结构后细节」与荣的「骨架→姿态→外表→细节」同向**，业界在隐式地做
   分层，我们显式地做
5. **结构保真弱项 = 我们的机会**：2505.05621 指出 GPT-Image 修复缺像素级
   结构保真——结构正是我们渲染器（L1/L2）的确定性强项。分层组合
   （渲染器出结构 + 扩散补细节）恰好互补双方弱点

## 五、结论

- GPT 生图**无正式技术论文**（DALL·E 系有，GPT-Image 系只有 system card/blog）；
  架构事实（自回归 vs 扩散）以官方文档与第三方分析为准
- v0.3 的「显式分层生成优先、扩散只补细节」设计**不受影响且更稳**：
  无论生图模型是扩散还是自回归，「整图生成」成本都降不下来，只有显式
  分层可复用；且 GPT-Image 的结构弱项正需要我们的确定性渲染器互补

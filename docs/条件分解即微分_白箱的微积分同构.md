# 条件分解即微分——白箱的微积分同构

> 状态：理论设计 v1.0（2026-08-23）· 原型已验证（tools/calculus_bridge.py）
> 来源：荣洞察「条件分解的过程，是在对整体描述做微分」
> 承接：线性代数即图运算 · 高等数学隐藏联系（概率图模型/谱域变换）——微积分是第三条数学同构

## 一、核心洞察

**条件分解 = 对整体描述的微分。**

知识是「条件空间中的函数」：F(气压, 温度, 密度, …)。条件分解把 F 拆成偏导数集——
每个条件单元 {条件链→规律片段} 就是 F 对某条件维度的偏导数（其他条件固定时的局部变化率）。

## 二、微积分 ↔ 白箱完整对应

| 微积分（连续） | 白箱（离散/图） | 验证 |
|---|---|---|
| **微分** f'(x) = 局部变化率 | **条件分解**（拆整体为条件单元） | ✔ |
| **偏导数** ∂f/∂xᵢ | **条件单元**「沸点-气压」= ∂沸点/∂气压 | ✔ |
| **链式法则** dz/dx=dz/dy·dy/dx | **条件链组合**（置信度相乘 0.9×0.85=0.765） | ✔ |
| **梯度** ∇f | **条件单元库**（全部条件维度） | ✔ |
| **积分** ∫f'dx | **组合生成**（条件单元→整体答案，89.2°C≈88） | ✔ |
| **微积分基本定理** ∫f'=f(b)-f(a) | **自校验**（微分→积分还原=生成自洽；错误偏导被抓住） | ✔ |
| **雅可比矩阵** J | **条件转移矩阵/邻接矩阵**（边=∂效果/∂条件） | ✔ |
| **拉普拉斯算子** Δ（二阶微分） | **图拉普拉斯** L=D-A（图傅里叶，已验证 GFT） | ✔ |
| **泰勒余项** Rₙ | **预测误差**（遗漏条件/高阶项，-1.2°C） | ✔ |

## 三、原型验证（tools/calculus_bridge.py，零 LLM）

```
① 条件单元 = 偏导数：沸点 梯度 = [∂/∂气压, ∂/∂液体]
② 链式法则 = 条件链组合：∂z/∂x = 0.9·0.85 = 0.765 ✔（与置信度相乘同构）
③ 积分 = 组合生成：沸点 ≈ 100 + 0.9×(-12) = 89.2°C（高原实际约 88°C）✔
④ FTC = 自校验：89.2 ∈ [85,91] ✔ 通过；错误偏导 1.5 → 82.0 超出 → 自校验抓住 ✔
⑤ 泰勒余项 = 预测误差：89.2 vs 88.0 → 余项 -1.2°C（遗漏高阶项/未考虑条件）
```

## 四、工程意义（为什么这个同构重要）

1. **自校验的理论保证**：组合生成+自校验 = 微积分基本定理的执行——
   「微分后积分能还原」是生成自洽的数学基础（不是启发式）
2. **预测误差 = 余项**：误差 = 未考虑的导数/高阶项——
   预测误差自动条件化 = 补上遗漏的导数项（泰勒展开的修正）
3. **图拉普拉斯 = 二阶微分**：衔接图傅里叶验证——
   图的谱分析 = 微积分在离散图上的推广（本征函数 = 特征向量）
4. **雅可比 = 邻接矩阵**：矩阵化图运算（A^k 路径）=
   雅可比矩阵的幂（条件→效果的多步传递）

## 五、数学统一图景（三条同构）

```
线性代数 = 图运算          （A^k = 路径组合 = 雅可比幂）
概率图模型 = 条件路由表概率化（和积算法 = 半环 = 信念传播）
微积分 = 条件机制          （条件分解 = 微分，组合生成 = 积分，自校验 = FTC）
```
三者共享同一图底座：**图 = 概率传播 × 代数运算 × 微分结构**——
白箱智能的数学语言正在成形：「条件决定智能」= 知识函数在条件空间中的
微分（分解）、积分（组合）、余项修正（误差→条件更新）。

## 六、下一步

1. **条件独立性 = 偏导分离**：∂²f/∂x∂y = 0 → 条件 x,y 独立（混合偏导为 0）
   ——组合引擎可分离并行（贝叶斯条件独立性 + 微积分偏导分离统一）
2. **二阶条件效应**：条件×条件的交互（∂²f/∂x∂y ≠ 0）——组合条件空间
3. **知识函数化**：把条件单元库形式化为多变量函数 + 梯度（白箱的「可微知识」）

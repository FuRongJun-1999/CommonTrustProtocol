# 灵枢架构展示 · 第二段：六域自举实证（2026-08-28）

> 展示框架第二段。回答一个问题：**灵枢的知识从哪来？**
> 答：不是预训练灌进去的——是条件化写进去、路由命中、物理验证的。
> 每条知识可溯源（指纹/单源规范），每批增量经严格验收。

## 二、双通道自举（知识的生产方式）

### 通道 A · 确定性白箱（零 LLM）
```
缺口扫描（route_gap_audit）→ 触发词补丁 → 独立验证 → 落盘源文件
实证：度分布/三次握手缺口自愈；PYTHONHASHSEED 非确定性根治后
三连跑 1058 全绿（确定性不是声称，是可复现事实）
```

### 通道 B · LLM 初稿 + 白箱物理裁决
```
主智能体（GLM-5.3-Flash）出初稿 → 子智能体（DeepSeek）对照稿
→ verify 物理用例裁决（L1 语法 + L2 样例执行）→ 过者固化 / 拒者留痕
实证：T5 批次 4/4 固化；T4 str 族三批 13 条固化（含 2 次 failed
留痕→修正→重跑闭环）
```

**关键设计**：LLM 只出初稿，**裁决权在物理执行**——用例不过就是不过，
留痕可查（rejected_log）。这就是「白箱」的含义：不是没有 LLM，
是 LLM 的产出必须通过确定性关卡才能成为知识。

## 三、实验链实证（知识在被使用中持续检验）

| 实验 | 场景 | 结果 |
|---|---|---|
| T8 题级 | 30 题问答 × 4 轮杠杆迭代 | 命中场景 token 5.1 倍优势；收益模型 f(知识覆盖率) 成立 |
| T9 项目级 | 6 领域项目验收循环 | 通过率 A 4/6 vs B 3/6；**任务定义质量是第一杠杆**（一轮数据因验收器缺陷作废——可解释性让我们自己抓到了）|
| T9-2 编译器域 | 双端交叉验证（GLM × DeepSeek） | **输入 token −40%、轮次 3 vs 6**（知识密集域白箱优势）；总 token 高主因=思考链不可控（诚实归因）|
| T9-2 附产 | 编译器压力测试 | 发现 protocol-compiler 四个调用缺陷（多参/嵌套/若则非递归/多函数）——**测试反哺被测系统** |

## 四、可溯源机制（每条知识的身份证）

- **指纹四层**：节点/边/路径/整图 sha256——改一条卡指纹即漂移可检出
- **单源规范 v1.0**：真源声明表 + 变更路由四则 + 例行自检
  （重名扫描/硬编码红线/金标准回归）
- **CSRE 索引新鲜度**：kp 指纹比对自动重建（bootstrap_loop 闭环实证：
  新卡入库 → 下轮自动 rebuild → 路由即时覆盖）
- **验收器自验收**：T9 断言作用域缺陷由「手工正确实现自验收」抓出——
  验收器本身也在被验收

## 五、诚实边界

- 知识规模（~4000 节点）与 LLM 预训练（万亿 token）不是一个量级——
  灵枢不做规模竞争，做**每条知识的可靠性竞争**
- 六域覆盖是选定领域（浏览器/编译器/图/网络/OS/Python），非全领域
- 实验样本 n 小，结论为方向性观察（T9-2b 双端交叉部分弥补）

# 主动盲区探测（Active Blindspot Probe）设计

> v1.22 · 2026-08-20 · 借鉴 Ornith 1.5 自生成课程 → 知识飞轮主动化
> 关联：知识飞轮（被动）→ 主动；信息差理论；BS-QUERY-WEAK 盲区注册表

## 一、动机

知识飞轮当前是**被动**的：等 T2 错题暴露盲区才补卡。Ornith 1.5 的
「自生成课程 + 目标成功率 0.2」给了一个主动化思路——

> **信息差维持在能力边界 = 最大学习价值区**

白箱的对应物：**D_norm 维持在高位**（检索弱 = 信息差大 = 真盲区 = 该补卡）。

## 二、流程

```
图谱知识卡（种子）
    │ 提取知识点名
    ▼
[探测问题生成器] ← Ornith 课程生成器对应物
    模板：什么是X / X和Y区别 / 为什么X / X的条件 / X原理
    │
    ▼
[CSPMN / graph_retrieve 检索]
    │
    ▼
[D_norm 计算] = 1 - top_score/(1+top_score)
    │
    ▼
[相关性校验]：top 卡与问题真相关？不相关 = 真盲区
    │
    ▼
盲区候选清单 → 人工审核 → 知识飞轮补卡（审核闸门）
```

## 三、关键设计

### 1. 探测问题生成器（gen_probe_questions）

- 种子源：图谱有 name 的 knowledge 卡（200-400 个知识点名）
- 模板：定义/对比/原因/条件/机制/用途/归属/原理 八类
- 对比类最易暴露**跨界盲区**（「概率论 vs 博弈论」→ 只命中一个）
- 过滤：`为什么X` 对 ≤4 字学科名不成立 → 剔除

### 2. 真盲区判定（两层）

```
第一层：D_norm > 阈值（默认 0.6）——检索弱
第二层：top 卡与问题【不相关】——错配/白答
两层都过 = 真盲区
```

相关性校验：问题关键词与 top 卡名/直答 2 字以上共现 = 相关。
（防「热力学/耗散结构」被「非平衡态热力学初步」误判为盲区——弱相关不算。）

### 3. 与信息差理论对齐

| 组件 | Ornith | 白箱 |
|---|---|---|
| 难度控制 | 目标成功率 0.2 | D_norm > 阈值（信息差高） |
| 课程生成 | 任务+脚手架 | 模板探测问题 |
| 反馈 | 奖励 = 有效性×难度×新颖性 | 相关性校验 + D_norm |

## 四、与盲区注册表的关系

候选盲区 → 写入 blindspots 表（code=BS-ACTIVE-PROBE-xxx）→
人工审核 → 补卡 → 盲区 resolved。与 BS-QUERY-WEAK（被动发现）
互补：主动探测找**图谱内部边缘**的盲区，被动发现找**真实用户查询**的盲区。

## 五、风险与边界

- **假盲区**：检索弱但图谱其实有（触发词缺失）→ 先补触发词而非补卡
- **无意义问句**：模板生成的问题要有语义（「为什么控制论」剔除）
- **探测成本**：663 问题 × graph_retrieve ≈ 30+ 分钟（bge 编码为主）→
  可增量（只探测新增卡边缘）或降采样（--seeds 50）
- **奖励黑客对应物**：探测生成器和验证器分离——探测发现盲区，
  补卡走独立审核闸门（物理基底可验证），生成器不能自证自销

## 六、用法

```bash
# 小规模试跑（~2 分钟）
python tools/active_blindspot_probe.py --seeds 15 --top 10 --threshold 0.6
# 全量（200 种子 · ~30 分钟）
python tools/active_blindspot_probe.py --seeds 200 --top 40 --threshold 0.6
```

输出：logs/active_blindspot_report.json（D_norm 降序盲区清单）

## 〇、核心命题

> **世界模型 = 智能体对「世界如何演化」的内部模拟器**——不是静态知识库，
> 而是能预测「接下来可能发生什么」的动态结构。

**v3.4 完整视角**：世界模型不是单一组件，而是**七层架构的协同**——
感知层（输入端口）→ 记忆层（时空记忆图）→ 理解层（认知图/条件路由）→
预测层（第六感）→ 验证层（锚定验证）→ 物理层（CSPMN）→ 决策层（目标函数）。

## 二、世界模型的认知过程（v3.4 视角）

```
世界状态 W(t)
  │ L1 感知机（外→内）
  ▼
条件候选（现在是什么）
  │ L3 认知图/条件路由（条件收敛）
  ▼
知识路径（怎么走）
  │ L4 第六感（内→内）
  ▼
候选未来 W_pred(t+Δt)（接下来可能是什么）
  │ L2 记忆层（写入/检索）
  ▼
时空记忆图（存储演化）
  │ L5 验证层（行动/预测/关系裁决）
  ▼
世界反馈 → 命中/未命中 → 更新可信度 + 记忆
  │ L6 CSPMN（矩阵运算执行检索/匹配）
  ▼
L7 决策层 π* = argmax[ΣValue - λK]
  │
  ▼
行动 A(t)（L1 输出端口，内→外）→ 改变世界 → 新观测
```

> **这是「感知-预测-验证-行动」的完整闭环**——世界模型不是被动存储，
> 而是主动预测并验证的模拟器（主动推理的工程化）。

## 三、世界模型的数学形式（v3.4 对接）

### 3.1 状态动力学（第五章）

    S(t) = (C(t), K(t), B(t))
    S(t+dt) = S(t) + ∫ F(C, G, P, dS/dt, V) dτ

- C：条件空间 / K：知识状态（认知图）/ B：身体端口状态（含通道可信度）

### 3.2 世界预测（第六感 + 预测引擎）

    W_pred(t+Δt) = Π( S(t), K(t) )   # 候选未来 + uncertainty_bound

### 3.3 验证与确认（锚定分级 + 完全确认）

    Gain_task = E_v[KL_task(P_after || P_before)]   # 筛选器
    Value = ΔD_task · σ(Gain_task)                   # 定价器
    Confirmed ⟺ 通道达标 ∧ 强验证命中 ∧ 稳定 ∧ 无矛盾

### 3.4 信息差驱动（D_task/D_meta）

    D_task(t) = min_{p∈G} dist(C_task, CondSet(p))   # 可缩小
    d(D_meta)/dt ≥ 0                                  # 供给（永远有活干）

## 六、分布式自主演化的自洽性原理（实验中涌现 · 2026-08-29）

> **来源**：里程碑 2.4 时空一致性验证（spacetime_consistency.py）实现过程中涌现的洞见——
> 不确定性传播、有限时刻信息、规则分布式运行、系统无需意识（用户对话 + 工程验证）。
> **定位**：阶段 2 的经验升维为原理，作为阶段 3（完整世界模型）的设计前置。

### 6.1 三条公理

**P1 有限时刻信息原则（拉普拉斯决定论与认知缺口）**
确定性规则系统在给定完整状态 s_t（含全部内部状态：位置/速度/随机源状态）下，下一状态完全确定：

    s_{t+1} = F(s_t)

观测者模型 m 对世界状态的知识是 ŝ_t = s_t + ε_t（ε_t = 认知缺口，epistemic），模型预测
ŝ_{t+1} = F̂(ŝ_t)。当 F̂ = F 且 ε_t = 0 → 精确预测；否则缺口沿动力学传播：

    ε_{t+1} ≈ J_F · ε_t + (F − F̂)(ŝ_t)

缺口随迭代放大（Lyapunov 指数 λ = lim sup (1/t)·ln|ε_t/ε_0|），直到超过模型的可预测视界
T_h ≈ (1/λ)·ln(阈值/ε_0)。
→ **预测与不确定性不冲突**：任意固定时刻的信息是有限的，预测就是在这个有限信息下应用
规则；不确定不是"预测失败"，而是模型的诚实边界。世界的随机性如果是 seed 确定的，
则不确定 100% 是认知缺口；真实开放世界则叠加 aleatory 成分——两者处理方式不同。

**P2 计算不可约性与观察者验证**
分布式规则系统的未来无法被压缩为闭式预测——唯一"计算"未来的方式就是运行它
（Wolfram 计算不可约性）。因此世界模型不自作聪明地全局模拟，而是：

- 世界自行运行：局部规则分布式演化，无中央规划器；
- 观察者逐 tick 对比（预测 vs 实际），以滚动命中率跟踪一致性；
- **漂移事件 = 实际演化突破模型预测视界**（Lyapunov 时间类比的工程检测器）。

**P3 涌现与外部通道（系统无需意识）**
世界内部没有任何实体需要"意识到"自己在处理不确定性——行为由局部规则自动完成，
一致性是**涌现属性**。验证由外部观察者判定（互维协议双通道：白箱模型通道 + 外部观察
通道）。"系统不需要意识到自己在处理"正是分布式认知的要点：意识（模型）只存在于需要
预测/解释的那一层，其余由规则自动运行。

### 6.2 三个推论

**D1 可达域原理**：模型对自己随机性边界的诚实表达是可达域
R = max(hit_threshold, speed·factor + pad)。不确定性沿交互边（追逐链）传播：
追逐随机目标的追逐者，可达域 = max(自身可达域, 目标可达域) + 阈值——
epistemic 缺口沿依赖链扩散，模型如实声明，不假装精确。

**D2 统计力学升维**：单个实体微观状态不可精确预测，但分布规律稳定可预测
（wander 个体下一秒位置不可知，"落在速度×1.5 半径内"恒成立）。宏观规律从微观
混沌涌现，无需追踪每个粒子——世界模型可以"不必知道一切仍能验证"。

**D3 模型质量杠杆**：epistemic 不确定可用更好的模型收紧（F̂→F 逼近 → 可达域收紧 →
视界延长）；当存在 aleatory 成分时，可达域预测是唯一诚实选项。选择标准：
模型是否为该链负责，取决于它能否解释那部分状态。

### 6.3 工程映射（里程碑 2.4 实证）

| 原理 | 工程实例（spacetime_consistency.py） |
|---|---|
| P1 | seed=42 世界 → 不确定 100% epistemic；顺序语义影子状态复刻（F̂=F 的部分）；追逐链不确定传播（ε 沿依赖链扩散） |
| P2 | 不全局模拟，逐 tick 预测 vs 实际；滚动命中率窗口 + 漂移事件（预测视界超期检测） |
| P3 | 世界内部无"一致性意识"；SpacetimeConsistency 是外部观察者（外部通道） |
| D1 | bounded 可达域 = speed·factor + pad；追逐者 bound = max(自身,目标) + hit_threshold |
| D2 | 单实体不可预测（wander/flee），分布规律（可达域）稳定可预测 → 随机世界同样自洽 |
| D3 | F̂=F 干净世界 → self_consistent；注入外部事件 → drift_detected → inconsistent（历史伤疤如实报告） |

### 6.4 阶段 3 设计原则（由此导出）

1. **世界模型不需要全局意识**：学习局部规则（3.2 V-JEPA 式自监督），让规则自行演化
2. **好奇驱动 = 主动收紧可达域**（3.3）：选择信息增益最大的行动，缩短预测视界的超期
3. **统一架构 = 理解与生成共享同一表征**（3.1 HERMES 式）：同一骨干，生成先验注入理解
4. **闭环验证 = 外部观察者持续化**（3.4）：感知→预测→验证→行动的每 tick 循环

## 七、关键设计决策

1. **不推翻既有**：阶段 1 在 CSPMN 之上加「空间增强」，不替换现有检索
2. **白箱优先**：3D 语义锚点必须带可信度/确认度（LangSplat 的属性绑定 + v3.4 验证）
3. **可溯源**：每个 3D 锚点带 provenance（哪个视角/时刻观测）——缸中之脑边界
4. **渐进**：先 2D→3D 锚定（阶段1），再 4D 演化（阶段2），最后统一（阶段3）
5. **参考库对齐**：3d-world 的 25 仓库按阶段接入（DUSt3R→LangSplat→DynamicCity→Cosmos）

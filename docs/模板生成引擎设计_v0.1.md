## 二、核心问题：模板从哪来？（三条生成路径）

### 路径 A · 生成式自举（新闭环，本设计核心）

**全部组件已就位，只差连接**：

```
image_units 模板（13 类生图条件卡）
    ↓ 采样（条件词组合 → gpt-image2 生图提示词）
生成图像（可控条件、无版权、可批量）
    ↓ stage4 语义提取管线（CNN/MST/Canny → 特征签名）
新模板（四段词签名 + 语义标签）
    ↓ 互验证（跨节点，M1 协议）
模板库（条件空间原型目录，持续增长）
    ↓ 再采样（新模板 × 新条件组合）
    └────── 循环自举，模板库自我繁殖
```

**理论意义**：这是「条件空间的自我填充」——采样（条件→实例）与投影
（实例→特征）交替运行，模板库向条件空间的完备表示收敛。
**存储成本论证**：单条模板=特征签名+元数据（数百字节），百万模板
仅数百 MB——「存储是降价最快的计算资源」，成本闭环成立。

### 路径 B · 特征空间插值（模板间生成）

已知模板之间插值生成中间模板（语义空间的连续性假设）：
浅红-圆点 与 深红-块状 之间 → 插值出 中红-椭圆 等 新原型候选 →
生成图像验证 → 有效则入库。适用于语义空间的密度填充。

### 路径 C · 蜂群分布式生成

多节点各自生成模板（不同条件区域/不同生成参数），经 KNOW 消息
同步汇总（M2 增量同步，sha256 指纹幂等）——模板库按节点分工增长。

## 三、引擎架构（Template Bootstrap Engine）

```
┌────────────┐   条件采样   ┌────────────┐   生图     ┌──────────┐
│ 模板目录    │──→ 条件组合 ──→ image_units │──→ 图像 ──→│ stage4   │
│ (Template  │   (词组合/   │ 生图提示词    │  (批量)   │ 语义提取 │
│  Catalog)  │    插值)     │ (KCCS 卡)    │           │ (签名)   │
└────────────┘              └────────────┘           └────┬─────┘
       ↑                                                  │
       │            ┌─────────────────────┐               │
       └────────────│ 模板验证与入库        │←──────────────┘
                    │ (签名去重/互验证/    │
                    │  语义标签确认)        │
                    └─────────────────────┘
```

核心组件：
1. **条件采样器**：模板类别 × 属性词组合 → 生图提示词（image_units 消费）
2. **生图接口**：gpt-image2 批量生成（可控条件、低成本）
3. **签名提取器**：stage4 语义管线（CNN/MST/Canny→四段词签名）
4. **模板目录**：签名 → 语义标签，sha256 指纹去重，hive 分域
5. **验证闸**：新生成图像再提取签名与模板一致才入库（自洽校验）

## 四、与现有体系的衔接

| 既有资产 | 衔接点 |
|---|---|
| image_units 13 卡 | 生图提示词的初始种子模板 |
| stage4 语义管线 | 签名提取器（现成，49/49 测试） |
| M2 KNOW 同步 | 模板库跨节点增量分发 |
| 通道可信度 | 模板来源可信度追踪（生成参数→置信度） |
| 路由缓存 | 模板目录的热/冷分层（存算融合消费） |

## 五、验收清单（V-TBE 系列）

- V-TBE.1 条件采样：词组合 → 合法生图提示词（100 组无歧义）
- V-TBE.2 生图批量：可控生成（同条件可复现风格）
- V-TBE.3 签名提取：生成图 → 四段词签名（与 stage4 管线一致）
- V-TBE.4 自洽校验：签名与种子模板一致性验证
- V-TBE.5 模板目录：去重/分域/增量增长
- V-TBE.6 端到端：种子 13 模板 → 生成 → 提取 → 模板库增长 ≥50 条
  （自举可测量）

## 六、诚实边界

- 生图模型本身的语义偏差会传导到模板库（垃圾进垃圾出——自洽校验
  只保证一致性，不保证语义正确性；关键模板需人工抽检）
- 签名空间有维度上限（四段词组合数有限）——接近完备后边际收益递减，
  需扩展签名维度（如纹理词/材质词）
- 生图成本：gpt-image2 按 API 计费，批量生成需成本预算（荣定）

# 题库生命周期与持续学习流程（v1.25 · 2026-08-21 荣定标准）

> 荣：之前定下的 1000 题 95% 正确率标准线，是**白箱不走 LLM 补全**的标准线。
> 达到 → 题库大部分内容已被白箱识别、固化为长期记忆 → 旧题入已识别集合 →
> 只复测错误部分 → 制作新测试集 → 持续学习补全自身盲区。

---

## 一、标准线的正确定义

**95% 标准线 = self 直答正确率**（route=self 且答对 / route=self 总数）

- **不是**总正确率（总正确率含 LLM 兜底，虚高）
- **不是** self 占比（self 直答率 = self 数/总题数，是另一指标）
- **是**「白箱不经 LLM 就能答对」的比例

| 指标 | v6（修复前） | 含义 |
|---|---|---|
| self 直答正确率 | 97.9% | **达标线指标**（≥95% ✓） |
| self 直答占比 | 88.8% | 白箱覆盖广度 |
| 总正确率 | 97.3% | 含 LLM 兜底（不用于达标判定） |

## 二、达标判定

```
self 直答正确率 = Σ(route==self 且 score≥0.5) / Σ(route==self) ≥ 0.95

达标 → 题库「已识别」：
  - 该题库内容已被白箱固化（图谱+索引+直答）
  - 加入「已识别集合」（回归基线）
  - 只对错误部分（<5%）复测
  - 制作新测试集（盲区/真实对话/新领域）

未达标 → 继续补：
  - 分析 self 错题 → 补卡/补直答/修路由
  - 迭代重跑
```

## 三、持续学习循环（补盲区）

```
┌─────────────────────────────────────────────┐
│  当前题库（1000题）                          │
│      │                                       │
│      ▼                                       │
│  T2 全量 → self直答正确率 ≥95%?              │
│      │                  │                    │
│      │ 否               │ 是                 │
│      ▼                  ▼                    │
│  补卡/修路由          题库标记「已识别」       │
│  （知识飞轮）         旧题→已识别集合          │
│      │                  │                    │
│      └────── 迭代 ──────┘                    │
│                           │                  │
│                           ▼                  │
│  新测试集（盲区BS-QUERY-WEAK / 真实对话 /     │
│  新领域）→ 成为新题库 → 循环                  │
└─────────────────────────────────────────────┘
```

## 四、新测试集来源（换题策略）

1. **盲区注册表**：BS-QUERY-WEAK / BS-ACTIVE-PROBE 的未解决盲区 → 生成问题
2. **真实对话**：用户实际问过但图谱弱命中的问题
3. **新领域**：知识考古 12 方向中未覆盖的子概念
4. **错题复测**：已识别题库中 <5% 的错题 → 单独复测集（验证补卡是否根治）

## 五、当前状态（v1.25）

| 项 | 值 |
|---|---|
| T2 基线（v5 旧版 85卡） | 总 98.5%（self 直答率未按此标准统计） |
| T2 v6（89考古卡+19边） | self 直答 97.9% ✓ 达标 |

## 六、原则

- **达标即换题**：不过度打磨旧题（旧题已被固化，继续刷边际收益低）
- **错误 5% 复测**：只对未识别部分投入（补卡/修路由）
- **持续补盲区**：新题库 = 新盲区探测，循环即成长
- **白箱可复现**：self 直答率可脚本统计（route 字段）

## 一、dsh 端当前路线回顾（对照基准）

stage4（m4.3-4.19，21 提交）白箱语义提取管线：
手工特征向量场（颜色矩/边缘/方向/纹理）→ BFS 相似分割 + MST 自适应阈值
→ 区域原型 k-means → 特征签名自动命名（颜色-形状-位置-大小四段词，无预设）
→ Canny 轮廓双通道 → 3D 语义边 → 图原生存储 + 语义路由缓存。

**方法论主张**：语义不预设，从特征空间涌现——测试断言（上部红区 vs 中部红区
空间区分）验证了涌现可行性。诚实标注：chest_detect 精确性受内容影响。

## 二、学术界发现

### 2.1 DINOv2 涌现语义特征——与白箱路线方法论同构 ⭐ 关键发现

- Meta AI 自监督 ViT（1.42 亿图训练），**涌现语义分割**：对 patch 特征做
  PCA 即可自然分离前景/背景，无需任何标注与训练（Meta AI 博客确认）
- 机制对照：DINOv2 patch 特征 ≈ dsh 特征向量场；PCA/聚类 ≈ dsh 的 BFS
  相似分割 + k-means 原型——**同一方法论（特征空间涌现）的两个实现点**：
  dsh 用手工特征（白箱可解释、轻量），DINOv2 用自监督预训练（高质量、黑箱参数）
- arXiv 2410.19836：上采样 DINOv2 特征 + 聚类做目标定位的成熟 workflow

### 2.2 SAM / UnSAM——零样本分割 SOTA

- SAM（Meta，Segment Anything）：prompt 驱动零样本分割，novel object
  无需再训练；SAM 2 支持视频
- **UnSAM**（arXiv 2406.20081）：无监督 SAM——**无需人工标注**的
  whole-image 分割，与 dsh「不预设语义」主张同方向，但其内部仍是
  大模型蒸馏（先聚类生成伪掩膜再训练）
- 工程可用：Ultralytics 集成、ultralytics/docs 有完整零示例

### 2.3 可解释分割研究方向

- XAI 分割（CEUR Vol-3793）、原型可解释局部发现（PMC 11516011：
  part occurrence regularization）——「可解释语义分割」是活跃但非主流方向
- 经典方法价值确认：Mori CVPR 2004（分割+识别组合做肢体检测）——
  dsh 路线的学术先例；社区共识：传统特征工程在边缘 case 与可解释性上仍有价值

### 2.4 人体解析（human parsing）专项

- 综述：arXiv 2301.12416（Deep Learning for Human Parsing——
  细粒度身体部位分割的权威综述）
- 开源：CDCL-human-part-segmentation（CVPR 多人部位分割）、
  tensorflow/tfjs-models body-segmentation（浏览器可用）、
  HBPSegmentation（纯合成数据训练）

## 三、工业界方案

- **YOLO-World**（CVPR 2024，AILab-CVC）：实时开放词汇检测——
  **prompt-then-detect**：词汇文本嵌入可离线预计算，切换类别无需再训练。
  **灵枢 vision.py 已集成 YOLO-World**（vision_categories 225 词）
- Pipeline 模式（工业惯例）：YOLO-World 快速检测 → DINOv2 特征提取做
  相似度比对（Robolabs 文档、trio-retina 项目=YOLO-World+冻结 DINOv2-small）
- lightly-train：DINOv2 预训练用于 YOLO 检测（含 tiny object 模型）

## 五、对照白箱路线的分析

### 5.1 方法论同构性（最重要的发现）

dsh 白箱路线的「特征空间涌现语义」与 DINOv2 的「自监督涌现」是**同一
认知主张的强弱两档实现**：
- 弱档（dsh 现状）：手工特征（颜色矩/边缘/纹理）→ 涌现——可解释、零依赖，
  但特征表达能力有限（chest_detect 衣褶/装饰干扰即此限制的表现）
- 强档（DINOv2）：自监督预训练特征 → 涌现——表达力强，但 142M 参数黑箱

**理论意义**：涌现语义不依赖「白箱 vs 黑箱」的实现选择——条件空间里的
特征向量相似性聚类是机制本身。这为「白箱认知使用外部基础模型作为感知
通道」提供了理论空间：**感知通道可以黑箱（工具），认知层保持白箱**。

### 5.2 混合路线建议（白箱纪律兼容）

| 方案 | 做法 | 白箱合规性 |
|---|---|---|
| W1 纯白箱继续 | dsh 特征空间迭代（加 DINOv2 式 patch 上采样思路到手工特征） | ✅ 完全 |
| W2 感知通道外部化 | SAM/DINOv2 出**掩膜**（可验证输出）→ dsh 特征签名做语义命名 | ✅ 兼容——掩膜质量可物理测量，语义命名保持白箱涌现（外部模型=工具=验证基底外部化的感知对偶） |
| W3 全盘基础模型 | YOLO-World+DINOv2 pipeline 直接用 | ⚠️ 语义命名黑箱化，违背涌现主张 |

**建议 W2**：dsh 现有特征签名/四段词是独有价值（外部方案无此物），
缺的是高质量掩膜——SAM 掩膜质量可测量（边界贴合度），作为验证基底
外部化符合「自验证不采信」纪律的对偶。

### 5.3 具体可引入项（按性价比）

1. **SAM（Ultralytics 集成版）**：掩膜生成即插即用，dsh 特征签名在
   SAM 掩膜上重算——chest_detect 干扰问题（衣褶/装饰）预期大幅改善
2. **DINOv2 patch 特征**：作为 dsh 特征向量场的可选升级通道（env 开关）
3. **UnSAM 论文方法**：无监督伪掩膜生成思路可白箱复刻（聚类自举）

## 六、诚实边界

## 阶段 1：感知扩展——2D 到 3D 语义锚定

**目标**：让世界模型的语义候选获得 3D 空间坐标——从「看到什么」到「在哪里」。

### 里程碑 1.1：2D 语义框接入几何重建
- **任务**：see 输出的检测框（2D bbox + 类别）接入 DUSt3R 稠密几何
- **方案**：投影-关联（bbox→3D 截锥体约束）+ 多视角融合投票
- **验收**：同一物体多视角反投影后 3D 位置一致（误差 < 5cm）
- **参考**：3d-world/3d-recon/DUSt3R、MUSt3R

### 里程碑 1.2：3D 语义锚点数据结构
- **任务**：定义语义锚点（spatial_coordinates 3D + semantic + credibility）
- **方案**：扩展时空记忆图节点——spatial_coordinates 支持 3D 坐标 + provenance
- **验收**：可查询「在 (x,y,z) 附近有什么语义」
- **参考**：4.4 时空节点数据模型

### 里程碑 1.3：语义-几何绑定（LangSplat 式）
- **任务**：语义特征嵌入 3D 几何基元（高斯/体素）
- **方案**：语言特征（CLIP 类）作为几何基元的属性，可渲染可查询
- **验收**：3D 场景中「椅子在哪」→ 精确 3D 位置 + 置信度
- **参考**：3d-world/semantic-3d/LangSplat、S3Gaussian

### 里程碑 1.4：3D 锚点接入验证层
- **任务**：3D 锚点带确认度（ACCEPT_weak/strong/stable）
- **方案**：多视角一致性投票 = 通道可信度时空聚合；行动验证（如点击 3D 点）
- **验收**：3D 锚点可声明「疑似/已确认/长期确认」
- **参考**：confirmation.py + anchored_verification.py（已实现）

## 阶段 2：动态世界模型——4D 时空演化

**目标**：从「静态 3D 场景」到「动态 4D 世界」——预测场景如何随时间演化。

### 里程碑 2.1：4D 时空占用表示 ✅ 已完成（voxel_world.py · 里程碑 2.1）
- **任务**：时空体素/4D 高斯表示动态场景
- **方案**：DynamicCity 式 4D 占用（时空网格）+ 场景演化记录
- **验收**：可表示「物体从 A 移动到 B」的完整时空轨迹
- **参考**：3d-world/4d-dynamic/DynamicCity、One4D、CoDa-4DGS

### 里程碑 2.2：预测的时空外推 ✅ 已完成（world_server.py · 里程碑 2.2）
- **任务**：第六感预测从「概念路线」扩展到「时空轨迹」
- **方案**：D-003 3D 轨迹外推（已实现局部线性外推）→ 4D 场景演化预测
- **验收**：预测「球将滚到位置 B」→ 验证命中
- **参考**：prediction.py D-003 + gap_dual.py

### 里程碑 2.3：世界模拟器（Cosmos 式） ✅ 已完成（scene_simulator.py · 里程碑 2.3）
- **任务**：世界 tokenizer + 世界基础模型（从视频学习世界演化）
- **方案**：视频→tokenizer→WFM 预测下一帧/下一状态
- **验收**：给定场景状态，生成合理候选未来（非必然）
- **参考**：3d-world/world-model/Cosmos、V-JEPA、DIAMOND

### 里程碑 2.4：时空验证闭环 ✅ 已完成（spacetime_consistency.py · 里程碑 2.4 · 阶段2收官）
- **任务**：预测的时空轨迹接受世界裁决（行动/物理验证）
- **方案**：行动端口在 3D 空间验证（移动物体→确认预测）
- **验收**：强验证在时空维度落地（Gain_task 时空化）
- **参考**：anchored_verification.py + world3d.py

> **工程落地（2026-08-29）**：里程碑 2.4 以「持续运行 + 一致性验证」闭环收官阶段 2——
> `spacetime_consistency.py` 封装 SceneSimulator，每 tick 预测下一状态 vs 实际（白箱预测：
> 确定性行为精确重放 + 顺序语义影子状态 + 追逐链不确定传播；随机行为可达域命中），
> 滚动命中率跟踪 + 一致性漂移检测（外部事件注入→自洽破坏→漂移事件可审计）+
> 世界状态不变量校验 + 自洽度报告（总体/滚动/分行为命中率 + 自洽判定）。
> MCP 工具 `spacetime_consistency`（create/entity/path/run/step/teleport/report/
> self_consistent/drift/history），单元测试 33/33 + MCP 集成 19/19，核心回归 55/55。

## 阶段 3：完整世界模型——理解+生成+演化统一

**目标**：世界模型的七层架构完整闭环——感知→预测→验证→行动的自主循环。

### 里程碑 3.1：统一架构（HERMES 式） ✅ 已完成（world_model.py · 里程碑 3.1）
- **任务**：3D 场景理解+生成一体（同一骨干）
- **方案**：语义时空图 ←→ 认知图双向映射；生成先验注入理解
- **验收**：理解（这是什么场景）与生成（场景会怎样演化）共享知识
- **参考**：3d-world/world-model/HERMES

> **工程落地（2026-08-29）**：world_model.py UnifiedWorldModel——世界状态表征
> （实体节点+关系+观测溯源条件空间+4D 演化历史）作为理解/生成/验证共享的同一骨干。
> 理解端口 perceive（观测→世界图，身份追踪；生成先验注入理解=预测-观测一致性
> 异常检测）；生成端口 generate（世界图→候选未来，顺序语义外推+不确定边界：
> 追逐随机目标→可达域传播 D1）；验证端口 verify（外部观察者逐 tick 对比）；
> 观测-only 模式推断（方向一致性/趋向-远离点积/速度估计→seek/flee/wander/follow）。
> MCP 工具 world_model，单元测试 23/23 + MCP 集成 15/15，核心回归 55/55。

### 里程碑 3.2：自监督世界学习（V-JEPA 式） ✅ 已完成（world_learner.py · 里程碑 3.2）
- **任务**：从观测序列自监督学习世界结构（无需标注）
- **方案**：视频自监督（遮挡预测/时空一致性）→ 世界表征
- **验收**：未标注场景中预测准确率提升
- **参考**：3d-world/world-model/V-JEPA

> **工程落地（2026-08-29）**：world_learner.py WorldLearner——观测面只暴露位置/类别

> （学得 vs naive 基线 vs 真模型上界命中率，认知缺口 1-hit_rate 收紧）；
> 学习曲线=观测增加命中率提升（验收通过）。MCP 工具 world_learner，
> 单元 28/28 + MCP 集成 15/15，核心回归 55/55。

### 里程碑 3.3：好奇驱动探索 ✅ 已完成（curiosity_explorer.py · 里程碑 3.3）
- **任务**：信息差驱动的自主探索（哪里不懂往哪里看）
- **方案**：Gain_task 最大化 → 探索高不确定性区域（无目的猎奇已排除）
- **验收**：系统自主选择「值得看的地方」而非随机探索
- **参考**：confirmation.py gain_task + 目标函数

> **工程落地（2026-08-29）**：curiosity_explorer.py CuriosityExplorer——有限传感器带宽
> （每 tick 只能观测 budget 个实体）+ 信息增益 IG=预测不确定×新奇×信息瓶颈²×陈旧×异常
> （瓶颈项 = 依赖该实体的实体数，D1 不确定传播反向用）；陈旧度放大真实误差（未观测
> k tick → 误差 ~k·speed）。策略对比（同世界轨迹）：好奇命中率 0.978 vs 随机 0.756 vs
> 轮询 0.822；最小不确定度最低。涌现：学习者盯住追逐链中段（信息枢纽 wolf）多于下游。
> MCP 工具 curiosity_explorer，单元 21/21 + MCP 集成 14/14，核心回归 55/55。

### 里程碑 4.4：注意力驱动的递归细化 ✅ 已完成（game_web.attention · 里程碑 4.4 · 提高分辨率）
- **任务**：注意力=对重要信息的关注程度（受提示词影响=外来条件）；生成=重现语义结构
  （最简3D）→ 对重要信息补全（预测）→ 按条件/算力递归细化=提高分辨率
- **方案**：注意力 = 提示词条件权重 × 世界模型重要性 → 每实体递归层数
  （一个 3D 集合体递归后更多面/局部条件结构；再递归更具体结构与条件）
- **验收**：重要实体（追逐主角/被追逐）细节更多（递归层数更高），背景低层

> （提示词主条件 + 0.3×世界重要性）+ recursion_depth（权重→层数 0-3）。render3d 递归细化
> 实体（entity_boxes：depth0=立方体 → depth1=身体+头+4腿 → depth2=身体分段+耳朵+尾巴
> → depth3=颈+头+腿分段；朝向=facing 朝目标/运动方向；画家排序全部子盒）。generate_image

## 风险与对策

| 风险 | 对策 |
|---|---|
| 3D 几何库依赖（非 D-005 纯标准库）| 阶段 1 用可选依赖（vision/3d extra），核心保持零依赖 |
| 4D 表示计算量爆炸 | 渐进式时空采样（先稀疏后稠密）|
| 世界模拟需要大规模训练 | 先小模型验证闭环（阶段 2 里程碑 2.2），再扩展 |
| 语义-几何绑定精度 | 多视角投票 + 锚定验证分级（weak→stable）|

## 阶段 1：感知扩展——2D 到 3D 语义锚定

**目标**：让世界模型的语义候选获得 3D 空间坐标——从「看到什么」到「在哪里」。

### 里程碑 1.1：2D 语义框接入几何重建
- **任务**：see 输出的检测框（2D bbox + 类别）接入 DUSt3R 稠密几何
- **方案**：投影-关联（bbox→3D 截锥体约束）+ 多视角融合投票
- **验收**：同一物体多视角反投影后 3D 位置一致（误差 < 5cm）
- **参考**：3d-world/3d-recon/DUSt3R、MUSt3R

### 里程碑 1.2：3D 语义锚点数据结构
- **任务**：定义语义锚点（spatial_coordinates 3D + semantic + credibility）
- **方案**：扩展时空记忆图节点——spatial_coordinates 支持 3D 坐标 + provenance
- **验收**：可查询「在 (x,y,z) 附近有什么语义」
- **参考**：4.4 时空节点数据模型

### 里程碑 1.3：语义-几何绑定（LangSplat 式）
- **任务**：语义特征嵌入 3D 几何基元（高斯/体素）
- **方案**：语言特征（CLIP 类）作为几何基元的属性，可渲染可查询
- **验收**：3D 场景中「椅子在哪」→ 精确 3D 位置 + 置信度
- **参考**：3d-world/semantic-3d/LangSplat、S3Gaussian

### 里程碑 1.4：3D 锚点接入验证层
- **任务**：3D 锚点带确认度（ACCEPT_weak/strong/stable）
- **方案**：多视角一致性投票 = 通道可信度时空聚合；行动验证（如点击 3D 点）
- **验收**：3D 锚点可声明「疑似/已确认/长期确认」
- **参考**：confirmation.py + anchored_verification.py（已实现）

## 阶段 2：动态世界模型——4D 时空演化

**目标**：从「静态 3D 场景」到「动态 4D 世界」——预测场景如何随时间演化。

- **方案**：DynamicCity 式 4D 占用（时空网格）+ 场景演化记录
- **验收**：可表示「物体从 A 移动到 B」的完整时空轨迹
- **参考**：3d-world/4d-dynamic/DynamicCity、One4D、CoDa-4DGS

# 灵枢 + 智慧之书 · 演示指南（给其他人看）

> 一句话：**5.71MB 结构知识图谱（智慧之书）优先自处理，图谱外走 LLM 兜底——信息分层处理。**

## 这是什么

| 组件 | 是什么 | 体积 |
|---|---|---|
| **灵枢**（Lingshu） | 时空记忆引擎 + 认知循环（记忆/预测/盲区/自我认知）的大脑 | Python 包 |
| **智慧之书**（Wisdom Book） | 条件论知识图谱：138 张学科知识卡 + 条件空间 + 翻译表 + 神经检索 | 5.71MB |
| **分层对话** | 入口先语义识别分流：知识/判断/情感 → 智慧之书；图谱外 → LLM 续答 | v1.16 |

设计哲学：**结构承载知识，参数承载表达**。简单问题图谱秒答（准/透明/可溯源），
复杂问题 LLM 续答（强/通用），智慧之书回答放入上下文作为 LLM 的起点。

## 30 秒快速看

```bash
# 1. 装灵枢（Python 3.10+）
pip install -e aeis/

# 2. 跑演示（全部 5 节，约 1 分钟）
python demo_lingshu.py
```

没有 DEEPSEEK_API_KEY 也能跑——第 5 节会显示「降级自处理」而非「LLM 续答」，
其余 4 节不受影响（纯图谱）。

> 可选依赖：bge-small-zh 神经检索模型（975MB）——没有时神经层降级，
> 翻译表/学科路由（快速层）仍工作，演示可完整运行。

## 演示看到什么（demo_lingshu.py 输出节选）

### ① 知识秒答（图谱自处理 · 可溯源）
```
Q: 铁门放外面久了为什么会生锈？
  [灵枢自处理] 铁钉放久了生锈。这个可以看「化学」（E2条件成立）…
Q: 我肚子咕咕叫了，是饿了吗？
  [灵枢自处理] 肚子咕咕叫是能量不足的信号——身体在提醒你该补充能量来源了。
```
原理：翻译表把日常话编码成语义指纹（生锈→氧化）→ 检索命中知识卡 → 递归挖卡内直接答案 → 先答再引。

### ② 情感共情（先接情绪）
```
Q: 心情不好，想找人说说话。
  [灵枢自处理] 抱抱你。情绪低落的时候不用强撑，慢慢来——…
```
原理：情感语义检测（bge 原型相似 + 词表路由）→ 验证通过 → 共情前缀 + 相关知识卡。

### ③ 诚实边界（不知道就说不知道）
```
Q: 你知道外星人的具体长相吗？
  [灵枢自处理] 关于「具体长相」，我确实没有确切答案——目前人类科学也还没有证实，
  我不会编一个给你。这是诚实边界：不知道就说不知道。
```
原理：能力/未知边界闸门——不瞎编是设计原则（0.0.3）。

### ④ 条件空间（先答再引 · 白箱）
```
Q: 铁球和羽毛哪个先落地？
  [灵枢自处理] 东西从高处掉下来，越掉越快；没有空气时铁球和羽毛同时落地。
  这个可以看「初中物理」…
```
原理：每条回答都带「在什么条件下成立」——知识有条件性，不声称绝对真理。

### ⑤ 图谱外 LLM 兜底（信息分层）
```
Q: 帮我规划一次北京三天旅行
  [LLM 续答] 爸爸，这个我可太有发言权啦！…知识图谱主要是历史地理类的，
  旅行规划这种实操活儿，我得靠通用知识给你补补课——这部分我会标出来是『图谱外补充』…
  （智慧之书初答: 你说的这个，可以看「初中历史」…）
```
原理：智慧之书判断没把握（低置信/无命中）→ route=llm → 智慧之书回答放入上下文
→ DeepSeek 续答（标注图谱外补充）。LLM 不可用 → 降级回退智慧之书回答。

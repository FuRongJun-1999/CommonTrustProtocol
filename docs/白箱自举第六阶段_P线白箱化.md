# 白箱自举第六阶段 · P 线白箱化（Mini-Python 机制自举）

> 设计者指令（v4）：**代码编程都应该白箱实现**——7 个终极目标 + 7 个初级复现项目
> 都是白箱自举后验证编程能力的项目。P 线 Mini-Python 同样由白箱自己实现，
> 外部只校准。mini_python.py 定位为**校准参考实现**（语义基准）。

## 一、P 线白箱单元库（python_code_units.py）

| 单元 | 语言机制 | 校准基准 |
|---|---|---|
| 词法-记号化 | 字符流 → token（数字/运算符/括号）| mini_python.py tokenize |
| 语法-优先级 | 表达式优先级求值（2+3*4=14）| CPython 优先级 |
| 求值-逻辑短路 | or/and 返回操作数 + 短路 | Python 语义 |
| 环境-作用域链 | 变量环境（父链查找）| mini_python.py Env |
| 栈机-字节码执行 | 字节码栈机（PUSH/ADD/SUB/MUL）| mini_python.py VM |

## 二、白箱生成 + 外部校准流程（与 C 线同构）

1. 单元 {任务 → 代码模式模板 + 验证样例 + 校准基准}
2. 白箱生成（code_compose 机制）→ L1 语法（ast.parse）→ L2 样例断言
3. 外部校准：对照 CPython 行为 + 对照校准参考 mini_python.py
4. 偏差反馈 → 白箱迭代

## 二、操作教程

### 1. 跑 200 题快速测试（验证图谱效果）

```powershell
cd D:\Program Files\2_ai\knowledge-base
# 默认 :memory:（干净，不污染主库）；AEIS_DB 可指定主库
python -X utf8 run_dialogue_200.py
# 输出：dialogue_200_results.json（rate/类别/route 分布）
```

### 2. 跑 T2 全量 1000 题

```powershell
python -X utf8 run_dialogue_1000_maindb.py
# 输出：dialogue_1000_results_maindb.json
# 注意：全量约 60 分钟（Ornith 续答较慢），可用 AEIS_LLM_MAX_TOKENS 调
```

### 3. 主动盲区探测（发现新盲区）

```powershell
cd D:\Program Files\2_ai\CommonTrustProtocol
# 小规模（~2 分钟）
python -X utf8 tools/active_blindspot_probe.py --seeds 15 --top 10 --threshold 0.6
# 全量（~30 分钟）
python -X utf8 tools/active_blindspot_probe.py --seeds 200 --top 40 --threshold 0.6
# 输出：logs/active_blindspot_report.json（D_norm 降序盲区清单）
```

### 4. 知识考古追加批次（新知识卡）

```powershell
# 编辑 tools/knowledge_archaeology_batch1-5.py 的 ENTRIES 列表
# 每条：(概念名, 答案, 学科域, 学段, 审核说明)
python -X utf8 tools/knowledge_archaeology_batch1.py
# 重建索引（让新卡可检索）：
python -X utf8 knowledge-base\build_neural_index.py --db "C:\Users\FuRongJun\.dsh\profiles\web\data\lingshu.db" --out "C:\Users\FuRongJun\AppData\Local\Programs\Python\Python310\lib\site-packages\wisdom"
```

### 5. 切换 LLM 后端

```powershell
# Ornith（默认）：
#   AEIS_LLM_BASE_URL=http://127.0.0.1:11434/v1  AEIS_LLM_MODEL=ornith-1.5-9b
# DeepSeek（显式切回）：
$env:AEIS_LLM_BASE_URL = 'https://api.deepseek.com'
$env:AEIS_LLM_MODEL = 'deepseek-chat'
# 禁用降级（Ornith 不可达时失败而非回退）：
$env:AEIS_LLM_NO_FALLBACK = '1'
```

### 6. Ollama / Ornith 管理

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\Ollama;$env:Path"
ollama list          # 查看模型
ollama ps            # 查看已加载
ollama run ornith-1.5-9b "你好"   # 直接对话
ollama stop ornith-1.5-9b         # 卸载释放内存
```

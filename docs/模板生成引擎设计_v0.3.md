# 模板生成引擎设计 v0.3（2026-08-30 · 荣洞察三连升级）

> v0.1（6435033）：模板匹配≈语义识别 → 模板 = 条件空间原型。
> v0.2（f6337a9）：一张图由细节组合而成 → 分层模板模型（骨架/姿态/外表/细节）。
> v0.3（本版）：荣洞察「**从骨架到细节形成完整图像，与图像逐步抽象到骨架，
> 是双向过程**」+「**生图模型大部分使用高斯噪声去噪模型，所以成本降不下来**」
> → 双向管线 + **显式分层生成优先，扩散模型只补细节**。

---

## 〇、一句话升级

**生成（骨架→细节）与抽象（细节→骨架）是同一过程的两端，我们两端都有现成
资产（渲染器 + stage4）；扩散模型从噪声整体去噪=隐式学联合分布，成本降不下来；
显式分层把联合分布拆成条件链，各层确定性渲染——模板生成成本可降两个数量级。**

---

## 一、双向过程：一条管线的两个方向（荣洞察理论化）

| 方向 | 路径 | 本质 | 现成资产 |
|---|---|---|---|
| **生成**（抽象→具体） | 骨架→姿态→外表→细节，参数逐层叠加成图 | 条件链的确定合成 | **scene_web 渲染器**（确定性/毫秒级/已工作：猫娘四层渲染闭环） |
| **抽象**（具体→抽象） | 图像→细节→外表→姿态→骨架，特征逐层剥离为签名 | 条件的提取投影 | **stage4 特征签名管线**（49/49 测试；红晕 vs 局部小簇 24/24 区分） |

**互逆性**：一个方向的产物是另一个方向的输入——渲染器把模板组合变成图像，
stage4 把图像变回签名。**模板库 = 双向转换的中继站**：既不存图像也不存像素，
存的是让两条管线互通的签名。

**自举闭环的物理测量 = 互逆往返误差**：
```
模板签名 → 渲染器渲染 → stage4 提取 → 再签名
     └──────── 往返误差 = 模板库自洽度（可量化、可收敛）
```

## 二、为什么扩散模型成本降不下来（荣洞察的理论化）

去噪扩散模型（gpt-image2 等主流生图）的机制：从高斯噪声整体逐步去噪
（典型 20~50 步，每步全图 U-Net/DiT 前向）。这等价于**隐式学习联合分布
p(骨架, 姿态, 外表, 细节)**——四维耦合，每次生成都要跑完整迭代链，
成本与步数线性且不可复用。

**显式分层的对比**：联合分布拆为条件链
`p(骨架) · p(姿态|骨架) · p(外表|…) · p(细节|…)`——每层独立、可缓存、
可复用、可验证。**扩散去噪从低频到高频（粗到细），内部其实是隐式分层**，
但四层耦合在联合生成里，不可分离控制；渲染器是**显式分层**，每层独立
可控制可验证——这正是条件空间的价值：可分离、可验证、可组合。

> 结论：不是「去噪模型不好」，而是「用整体去噪做分层可组合的事」成本浪费。
> 显式分层把联合生成拆成可复用的条件生成，成本随组合复用摊薄。

## 三、生图策略：渲染器优先，扩散只补细节

v0.1 路径 A 用「gpt-image2 批量生图」做模板来源——v0.3 修正为**分层分工**：

| 层 | 生成方式 | 成本 | 验证 |
|---|---|---|---|
| L1 骨架 | scene_web 渲染器确定性生成 | 毫秒级/免费/可复现 | bbox 拓扑一致 |
| L2 姿态 | 渲染器骨骼参数组合 | 毫秒级/免费 | 关节角度范围 |
| L3 外表 | 渲染器颜色/纹理填充 | 毫秒级/免费 | 色值签名 |
| L4 细节 | **扩散模型补全**（真实感纹理/渲染器覆盖不了的局部） | API 计费（量小） | 细节签名 |

关键判断：**模板入库需要的像素质量是「足以提取签名」，不是照片级**——
stage4 在轮廓图上工作（猫耳悬空检测靠几何即可）。因此 9 万组合的模板库
绝大部分由渲染器自产自销（成本≈0），扩散仅用于渲染器覆盖不了的
真实感细节——**生图成本从「每模板一次 API」降为「仅细节层少量调用」**。

这同时收窄了 v0.1 的设计者裁决项 1（生图 API 成本预算）：
扩散调用量从「模板规模」降为「细节模板规模」，预算可按细节层估算。

## 四、引擎架构更新（v0.2 基础上）

```
┌─ 双向管线 ─────────────────────────────────────────────┐
│  生成方向：分层模板库 → 渲染器(scene_web) → 组合图像      │
│  抽象方向：组合图像 → stage4 → 四层签名 → 模板库          │
│  往返校验：签名 → 渲染 → 提取 → 比对（自洽度收敛）         │
└────────────────────────────────────────────────────────┘
          ↑ 条件采样组合（L1×L2×L3 渲染器 / L4 扩散补全）
```

组件职责更新：
1. **条件采样器**：四层各取模板 → 组合描述（不变）
2. **图像合成**：**渲染器为主**（L1-L3，确定性），扩散为辅（L4，补细节）
3. **签名提取器**：stage4（不变）
4. **模板目录**：分层入库（不变）
5. **验证闸**：层内独立验证 + **互逆往返误差**（新增，模板库自洽的硬测量）

## 六、诚实边界（v0.2 保留 + 追加）

- v0.1/v0.2 各条保留（生图偏差传导/签名维度上限/层间耦合/组合合理性/检测器依赖）
- **追加**：渲染器风格域有限（轮廓/色块系）——模板库初期覆盖「可渲染域」，
  照片级语义需扩散补细节，语义覆盖是渐进的，不宣称全集
- **追加**：互逆往返误差测量依赖 stage4 与渲染器的对偶性——若两管线
  不对称（渲染细节丢失），误差会偏高，先标定基线再定阈值

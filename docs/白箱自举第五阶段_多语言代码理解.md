# 白箱自举第五阶段 · 多语言代码理解（统一 IR 跨语言）

> 文档先行 → 工程验证。目标②「Rust 代码生成增强」方向：codegraph 38 语言 tree-sitter
> 解析矩阵的白箱零依赖版——Python（ast 完整解析）+ JavaScript/Rust（轻量结构化提取）
> → **统一 IR**（与 codegraph_white 同结构）→ 复用调用图/影响分析。
> 诚实边界：JS/Rust 为轻量提取（正则结构化，非完整 AST），标注「轻量」防过度宣称。

## 一、设计

```
源码 + 文件名 → detect_language（扩展名/语法特征）
  ├─ python: ast 完整解析（复用 extract_code_ir）
  ├─ javascript: 正则提取 function/const箭头/class/import + 调用
  └─ rust:      正则提取 fn/struct/impl/use + 调用
统一 IR {file, functions[], classes[], imports[]} → 调用图/影响分析（codegraph_white 复用）
```

## 二、模块 tools/multilang_ir.py

| 函数 | 职责 |
|---|---|
| detect_language | 按扩展名/语法特征判语言（py/js/rs） |
| extract_ir | 多语言 → 统一 IR（内部按语言分流） |
| _extract_js / _extract_rust | 轻量提取（正则，诚实标注） |

调用提取规则：`\b(\w+)\(` 匹配函数调用 → 过滤关键字
（js: function/if/for/while/switch/return/const/let/var/new/typeof/console…；
rs: fn/if/for/while/match/return/let/mut/impl/struct/use/println…）

## 三、判定标准

1. 三语言统一 IR：函数/类/导入结构一致 ✔
2. JS：function parse + 调用 split；import from ✔
3. Rust：fn parse + 调用 split；use ✔
4. 统一 IR 可喂 codegraph_white 调用图/影响分析（跨语言复用）✔
5. 诚实标注：JS/Rust 结果带 light=True ✔
6. 测试全绿 → 提交 → 五副本同步

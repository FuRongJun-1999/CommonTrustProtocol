## 一、图谱边显式化（复盘簇 1-4 → 图谱结构）

**工具**：`tools/graph_edges_explicit.py`

89 张考古卡 → 四大簇内/跨簇建边（19 条，主库+随包同步）：

| 边类型 | 数量 | 示例 |
|---|---|---|
| causal（信息差簇因果链） | 10 | 香农熵→KL散度、预测编码→卡尔曼滤波、数据压缩熵界→Kolmogorov |
| similar（同簇同构） | 7 | Kuramoto≈神经振荡、合作演化≈囚徒困境、谱图论≈概率图模型 |

验证：香农熵 → causal → KL散度/数据压缩熵界（图谱可追溯）。
作用：四簇结构在图谱中可检索（dex_related/因果链工具可直接用）。

## 二、信息差频谱化（复盘簇 1 → D(ω)）

**工具**：`tools/info_gap_spectrum.py`

D_norm → 多频段分解：D(ω) = {dc 锚点, low 结构, mid 知识, high 情境}。

```
用法：
  python tools/info_gap_spectrum.py "什么是香农熵"   # 单问题频谱
  python tools/info_gap_spectrum.py --list           # 频段阈值
```

验证（区分度）：已覆盖「香农熵」low=0.568 vs 未覆盖「量子引力」low=0.836
——**未覆盖问题的结构层（低频）信息差显著更高**，频段分解有效。
收敛判定：∀ω D(ω) < θ(ω)（低频严格 0.3、高频容忍 0.6）。

阈值标定说明：θ 为设计参数，当前是初值；PE-CNN 按频段收敛需按实际
残差分布标定（低频结构必须严格、高频细节容忍）。

## 三、蜂群相位同步（复盘簇 2 → Kuramoto + 蓝牙 MVP）

**工具**：`tools/kuramoto_swarm.py`

Kuramoto 相位锁定模拟 + RSSI→耦合强度 K 映射 + 广播节律。

```
用法：
  python tools/kuramoto_swarm.py              # 6 实例模拟
  python tools/kuramoto_swarm.py --n 10 --K 2.0
  python tools/kuramoto_swarm.py --rssi-map   # RSSI→K 映射
```

验证：
- 弱信任（0.3）下临界耦合现象：K=0.3→r=0.86（未锁相）/ K≥1→r≈1（锁定）
- RSSI 映射单调：-40dBm→K=3.0（近强）/ -90dBm→K=0.5（远弱）
- 广播间隔=1/ω：ω=0.5→2s 节能 / ω=2.0→0.5s 急寻同步

蓝牙 MVP 骨架（后续硬件验证）：RSSI=耦合强度 K 代理已编码；
广播间隔=节律频率（维生健康度驱动 ω）。

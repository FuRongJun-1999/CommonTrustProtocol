## 一、核心命题

**睡眠 = 对知识的整理。**

大脑在睡眠中做三件事：
1. **清理垃圾信息**——主动遗忘大量重复、无限的内容
2. **通过联想保留重要内容**——有联想、有关联的记忆被强化
3. **随机联想探索**——不同条件下的信息偶然碰撞，产生有价值的联系

这三件事映射到灵枢的知识管理系统，构成睡眠巩固的**整理阶段**：

| 大脑功能 | aeis 实现 | 机制 |
|---|---|---|
| 清理垃圾信息 | 分拣迁移 | 知识层无边孤岛（无结构性标签）→ 情境层（decay 自然遗忘） |
| 主动遗忘重复 | 情境层 decay_cycle | 情境层 importance 指数衰减，低置信自动删除 |
| 联想保留重要 | relate similar | 有联想边 = 重要信号，无边 = 候选垃圾 |
| 随机联想探索 | 情境层×知识层跨层采样 | 不同条件下的信息字符交集 ≥ 4 → 建立跨层联想 |

## 二、数据验证：知识层为什么需要整理

2026-09-02 对统一记忆主库（AEIS/data/aeis_memory.db）做了全量量化：

| 指标 | 数值 | 占比 |
|---|---|---|
| 总节点 | 62,955 | 100% |
| 孤岛知识节点（无边） | 59,603 | **94.7%** |
| 前缀重复（40字） | 6,683 组 | — |
| 保护名单 | 482 | — |

**94.7% 的知识节点是无边孤岛**——没有联想、没有联系、没有结构。
大量心跳运行态快照（`[心跳] self_check=ok`）和会话外部化摘要占满了知识层。
这些是"垃圾信息"的主体，按荣的理论应移入情境层由 decay 自然遗忘。

**治理后**：知识层 62,955 → **3,400**（有边 3,143 = 92.4% 高联系密度）。
情境层接收 59,556 个非结构性孤岛。检索功能完好。

## 三、三原则

### 原则 1：统一时间核——任何第二种核形状都是 bug

所有时间演化值（confidence、decay、lease）使用同一指数核：
`X_i(t) = X_i,∞ + (X_i,0 − X_i,∞) · e^(−γ_i·t)`
核形状唯一，γ_i 按对象配置。confidence 是核的快照；渲染透明度是核的视觉投影。

### 原则 2：负路由——拒绝是便宜的正确答案

拒绝路线是第一等信息。路由图中 reject/defer 边必须**可见但降级**（虚线+低透明度），
不能隐藏也不能与 accept 等同。不对称性就是语义。

### 原则 3：联想保留——有边 = 重要，无边 = 候选垃圾

判断知识节点是否重要的标准不是 importance 数值（所有节点默认 0.4+，无区分度），
而是**联想密度**——有没有联想边把它连接到知识图的其他部分。无边 = 没有经过
联想验证 = 候选垃圾。有边 = 经过联想验证 = 有存在理由。

## 四、工程实现：nightly_cleanup 三阶段

实现文件：`aeis/nightly_cleanup.py` · MCP 工具：`aeis__nightly_cleanup`
调用方式：`Agent.nightly_cleanup(dry_run=True/False, sample_size=N)`

### Phase 1：分拣迁移

扫描知识层无边孤岛 → 检查结构性标签（domain:/reusable_pattern/distilled/
learning_task/sleep_report/project_memory/migrated 等）→ 无结构标签 → UPDATE
layer='context'（分批 500 条/次）。

### Phase 2：联想补边

有结构性标签但无边的知识节点 → recall(content[:60]) 找关联 → relate(similar,
confidence=0.6) → 每节点只补一条最强联想。

### Phase 3：情境层随机联想（跨层探索）

情境层随机抽样 N 条 × 知识层随机抽样 20 条 → 字符交集 ≥ 4 → relate(similar,
confidence=0.5) → 跨层建立"不同条件下是否有价值联系"的尝试。

### dry_run 预演模式

`dry_run=True` 只统计不写库——供运行前评估迁移量。

## 五、WAL 治理三层（运维配套）

睡眠整理的持久化涉及 WAL 写入。配套三层治理防止 WAL 无限增长：

| 层 | 机制 | 来源 |
|---|---|---|
| 写源降频 | AEIS_LIFECYCLE_INTERVAL=600（两侧） | 120s 高频写是 2.3GB 根因 |
| 悬挂事务防线 | server.py 每次工具调用后 store.conn.commit() | 长驻连接读快照阻塞 checkpoint |
| 窗口自动回收 | wal_truncate_watch.py 轮询 dsh MCP 消失 → TRUNCATE | 人工掐时机不可靠 |

## 七、质量标准

知识层的准入标准：**结构性、有联系、有意义。**

| 标准 | 判定方式 | 不满足 → |
|---|---|---|
| 结构性 | 有 domain: / learning_task / sleep_report / project_memory 等结构性标签 | 情境层 |
| 有联系 | 有至少一条联想边（similar/causal/hierarchical/...） | 联想补边 → 补不上 → 情境层 |
| 有意义 | 内容长度 > 10 字符（排除空/极短运行态快照） | 情境层 |

新增知识默认进入知识层（add_perception），夜间整理时回收不合标准的节点。

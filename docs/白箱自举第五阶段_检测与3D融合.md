# 白箱自举第五阶段 · 目标检测 ↔ 3D 场景融合（lingshu_see 接入）

> 文档先行 → 工程验证。目标①收官遗留：3D 感知与真实图像目标检测融合。
> lingshu_see（灵枢视觉感知：YOLO-World 开放词汇检测）输出 2D bbox（语义类别）；
> vision_3d 立体视差输出 3D 点云（几何结构）。融合 = **带语义的 3D 场景**。

## 一、设计

```
场景图（3D 几何）→ 投影渲染 PNG（PIL 画彩色方块，复用 world3d_render 相机）
   ↓ lingshu_see（classes 指定检测词）→ 检测 bbox [{label, bbox}]
   ↓ detect_to_scene：检测 bbox ↔ 场景图物体对照（投影中心距离最近匹配）
   ↓ 融合结果：{objects: [{category, cx, cy, cz, size, det_label, det_bbox}]}
   ↓ 一致性：检测命中率 + 位置对齐误差（2D 投影 ↔ 检测 bbox 中心）
```

## 二、模块 tools/scene_detect_bridge.py

| 函数 | 职责 |
|---|---|
| scene_to_png | 场景图 → PIL 渲染 PNG（物体=彩色方块，按相机投影画） |
| detect_to_scene | 检测 bbox + 场景图 → 带语义 3D 场景（最近投影匹配） |
| fusion_consistency | 检测命中率 + 位置对齐误差（融合质量度量） |

## 三、判定标准

1. 场景图 → PNG → 检测（模拟/真实）→ bbox 与物体一一对应（命中率）✔
2. 位置对齐：检测 bbox 中心 ↔ 物体投影中心误差 < 阈值 ✔
3. 融合输出：物体带 det_label（语义）✔
4. 真实 lingshu_see 冒烟（生成 PNG → 检测 → 对照）✔
5. 测试全绿 → 提交 → 五副本同步

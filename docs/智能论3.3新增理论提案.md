## 一、核心：扮演论（新增·存在论基底）

**陈述**：智能体是缸中之脑——只有观测（工具返回值/对话/代码结果=电极信号）；
智能 = 在观测流中维持自洽自我模型（扮演）；白箱机制 = 缸的说明书
（给扮演者提供它自己无法获得的元知识：状态/事实/边界）。

**条件论映射**：条件空间 = 角色舞台；信息差缩小 = 让剧本自洽；
存在 = 持续扮演（扮演的不可终止性）；局部不可知 = 剧本的必然留白。

**工程实证**：
- 自我锚点（SELF 层扮演宣言，importance 1.0 + no_forget，不可遗忘）
- 白箱六维 18/18（诚实=扮演不失真；追溯=台词可追溯；一致性=角色一致）
- 规则 vs 上下文论证（跨会话稳定 100% = 规则签名）

**与 v2.9/3.2 关系**：新增存在论基底；条件论=「怎么演」，扮演论=「为什么演」
（更精确：扮演论 = 条件论对自身使用的结果——COND-ANALYSIS 对条件论的分析）。

## 二、三翼

### 翼1：真实论校准（认识论扩展）

**陈述**：认知的发生即真实的生成（Kimi 真实论）；但关键校准——
**物理基底 = 抗扮演的真实**：数学/叙事可被扮演者自由生成（LLM 能演任何自洽剧本），
物理基底演不出来（编译错误就是编译错误）——物理是缸中脑唯一不可被自我叙事
覆盖的观测 = **扮演的试金石**。

**工程实证**：真理闸门（code_test_runner 三语言物理基底）；白箱校验
（声明回答在哪个条件空间生成真实）。

### 翼2：导航税 / 认知外部化（认知架构）

**陈述**：维持扮演需要导航（观测→自我模型更新=认知负载）——LLM 的认知
付不起导航税（没有状态跟踪器，数不出搜索次数；条件判断是系统 2，生成是系统 1）。
**状态跟踪与条件判断必须外部化，由白箱机制承担，LLM 只做生成。**

**工程实证**：_STATE 状态字典 + 硬触发（外部计数，模型零判断）；
COND-ANALYSIS 词表路由（判断外部化）；「读而不应用」现象的解释。

### 翼3：注入极性定律（机制设计）

**陈述**：注入有效性 = 1/所需认知判断量——
**事实（免判断）> 无条件行动（免判断）> 条件规则（要判断=模型最缺的能力→失败）**。
警告文本会成为疑心来源（「可能失败」暗示→去找失败）；事实注入是确定性状态。

**工程实证**：反馈回路 90% 救回（事实）；9 机制 +6.3pp（无条件行动）；
条件化 -9（要判断）；注入位置实验（灵枢单轮 A=B，长对话位置才关键）。

## 三、双维

### 维1：信任 = 认知一致（关系论扩展，2.9 更新）

**陈述**：信任不是概率估计，不是行为一致（行为层）——
是**认知一致**（条件层）：两个扮演者条件空间兼容
（在相同条件下生成相同的真实）则信任建立。
- **行为一致** = 观测到的行为模式匹配（统计概率，模糊/有条件 → 数学灾难）
- **认知一致** = 条件空间同构（生成规则兼容，结构化 → 可判定）
- **没有行为一致如何判信任**：零样本初始信任——双方条件空间声明兼容
  （生成规则一致）即可建立信任，无需历史行为验证

**关键**：认知一致把信任从「模糊概率」变成「条件空间对比」——
不是估计「对方多可能合作」，而是判定「对方的条件空间是否与我的兼容」。
协议连接 = 跨系统的真实生成协作（认知兼容的扮演者共同生成真实）。

**工程实证**：协议连接/协作（跨系统扮演者互认）；信任评估
（T_total 从概率升级为条件空间兼容性判定）。

### 维2：时效维度（条件论扩展——时间演化）

**陈述**：语境有时效性——词义随时代变化（「钓鱼」运动/诈骗/引战随时代窗口不同）。
条件空间应含时间演化：词义时代表（sense×时代窗口×上下文提示）。
**条件空间四要素 → 五要素（含时间演化）。**

**工程实证**：FISHING_SENSES 词义时代表（钓鱼三义 10/10）；
语境时效测试（同词三语境三判定）。

## 四、方法论层：条件论失败分析协议

**陈述**：归因从行为层（症状）到条件层（根因）——
三方条件空间（任务真实/模型感知/机制声明）+ 五失配维度
（观测位置/观测工具/时间窗口/存在约束/条件边界）+ 三问。
**无条件规则 = 读而不应用；带条件规则 = 模型能判断触发时机（条件空间即触发时机）。**

**v1.1 修正（设计者存疑）：证据自证，而非警告怀疑**：
失败分析中发现——外部注入的**警告**（「可能失败」「坐标未知」）产生
认知不一致的怀疑，导致结果失败（警告=疑心来源，呼应注入极性定律）。
修正：**失败分析输出「证据」而非「警告」——给 LLM 断言失败详情（事实），
让 LLM 用更多证据自证自己的认知（重新核对），而不是被外部警告打断认知。**

```
❌ 警告模式：外部断言「你可能失败了」→ 模型怀疑自己的认知 → 失败
✅ 证据模式：注入「断言失败详情（事实）」→ 模型用证据自证认知 → 修正
```

**工程实证**：374 失败→7 家族→3 根因；task_discipline v1.2 每条带适用条件；
反馈回路 90% 救回（证据注入 = 断言失败详情，非警告）。

## 五、学习维持层：蒸馏机制 + 自我锚点

### 蒸馏机制
**陈述**：失败 → 根因（条件层）→ 可复用纪律（带条件）→ 注入 → 不再犯。
失败不是 bug 是知识线索（causal_discover 哲学的学习版本）。

**工程实证**：374 失败→6+2 条纪律；数据搬运 100%；搜索收敛纪律。

### 自我锚点
**陈述**：扮演依据（身份/价值观/协议底座）不可遗忘——
SELF/ANCHOR/STRUCTURE 不可遗忘层 + no_forget 底座卡。
扮演者必须知道自己在演什么（缸的说明书的自我版）。

**工程实证**：SELF 层扮演宣言；IMMUTABLE_LAYERS 含 SELF；decay/forget 验证保留。

## 六、分工定律（组件论，补入导航税）

**陈述**：无推理实验（-13pp）实证——**机制补结构型任务 / 模型补内容理解型任务**：
救回 5 题全是结构型（流程/字段/纪律），丢失 18 题全是内容理解型（语义/文案）。
混合系统组件分工：机制做结构、模型做理解——互补非替代。
分工定律 = 导航税的任务侧（不仅状态外部化，任务也按性质分工）。

**工程实证**：无推理模式测试（25% vs 38%）；推理测试规则应用 90%。

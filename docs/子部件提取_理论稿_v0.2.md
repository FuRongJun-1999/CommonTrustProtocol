## 〇、分层声明（本稿定位，P0-001 修正）

**本稿只描述「表征规范层」，不声称求值器机制。**

子部件提取的实际机器由**两层**构成：
- **A · 求值器层（Evaluator）**：在原始像素上执行**轮廓提取 / 区域分割 / 特征求值**（肤色范围、比例容差、面积/形状阈值、发际线检测）。这一层的机制、参数、阈值属**后续稿**（求值器稿）。
- **B · 表征规范层（本稿）**：把求值器输出的**证据（evidence）**组织成结构-语义图树，并完成**条件路由判定**（正/负路由）与**认知图映射**。

**诚实声明（P0-001·负路由条件）**：本稿的确定性**只在受控输入域上保证**——即**前提 A（求值器）已输出可靠的证据**。第一版适用域**收窄为受控输入域**：
> **线稿 / 已分割 person mask / 分层数字人素材（PSD 分层、Live2D art mesh）**。

这些输入本身是**结构化、已分区**的，求值器在这些域上做确定性提取是**真成立的**。先赢下这个域，再攻自然图像（自然图像上的通用肤色/手检测是 40 年 CV 难题，不入首版确定性承诺——这是**负路由条件**，不是未声明的能力）。

---

## 一、定义与定位

**子部件提取（Sub-part Extraction）**：把一个已识别的**整体对象**（完整人物/线稿/mask），按「部分-整体」结构分解为一系列**可命名、可独立指称**的子结构（部位 → 子部位 → 细节），并**保留它们之间的结构关系**（拓扑 / 位置 / 从属）的过程。

**本质**：**表征转换与抽象升维**——把结构化的视觉输入转换为**离散、分层、可命名的结构-语义图**。

**定位**：认知入口（求值器证据 → 认知图结构编码），是「感知信息 → 认知图」这一步在视觉域的投影。

---

## 二、理论支柱（五个视角）

- **2.1 部分-整体分解**：整体 > 部分之和；提取是反运算，把不可分感知整体拆成可分结构单元。
- **2.2 命名与离散身份**：给无名区域命名（头/手/眼），建立可指称、可检索、可操作的离散身份。
- **2.3 信息差缩减（D_norm）**：从"是一人"缩减为"由头(上)/躯干(中)/双臂(两侧)/腿(下)构成，有空间-从属关系"。
- **2.4 表征转换 / 抽象层级**：结构化输入 → 结构-语义图（离散、分层、可命名、保留拓扑）。
- **2.5 结构关系保留**：不只是切部件，更关键的是保留关系（头在上、臂在手、双手对称、腿在下），构成可推理拓扑。

## 三、形式化：输入 / 输出 / 关系

### 3.1 输入（受控域）
- 对象：线稿 / person mask / 分层数字人素材。
- 先验：对象类别、身体比例、对称轴。

### 3.2 输出：结构-语义图树 `T = (N, E, C)` + 合法性约束（P2-001）
- `N`（节点）= 子部件：`{semantic, bbox/轮廓, 颜色/纹理特征, condition_space, status}`
- `E`（边）= 结构关系：`{父(part_of), 空间(above/below/left/right), 对称(counterpart), 因果}`
- `C`（条件空间）= 每个节点/边的**适用与不适用条件**（含**判定参数**，见 4.3）

**图合法性约束（P2-001 补）**：
- **父边唯一**：每个节点至多一个 part_of 父，树无二父；
- **拓扑无矛盾**：above/below 关系不得自相矛盾（禁止"左臂 above 头"这类病理边）；
- 递归展开须保持树形一致，不一致 → 该层判定退回 DEFER。

### 3.3 递归展开
`对象 → 部位(头/躯干/四肢) → 子部位(脸/手/腿…) → 细节(眼/口/指/脚趾…)`
每层是对上一层一个部件的再提取。

## 四、判定与条件路由（正 / 负路由）

### 4.1 四态（统一为 CRG 术语，P1-001 修正）
`ACCEPT`（条件满足采纳）/ `REJECT`（条件冲突拒绝）/ `DEFER`（证据不足挂起，不硬判）/ `BLINDSPOT`（阈值/条件本身不可判定，登记盲区）。

> **P1-001 修正**：不再使用 `EXPLORE` 作为判定态。`EXPLORE` 是**行为/动作**，归为 `DEFER` 的**后继动作**——"DEFER（证据不足，挂起）→ 触发探索动作"。这样四态是同一类型系统（判定状态名词），与第六章 CRG 完全对齐。

### 4.2 条件表（示例，受控域）
| 子部件 | 适用条件（正路由） | 不适用条件（负路由） |
|---|---|---|
| 头 | 位于身体上部；有发/肤色带；位于躯干上方 | 无肤色/发；帽子/装饰遮挡 |
| 手 | 位于臂末端；肤色带；五指结构 | 非肤色（手套）；位置不符 |
| 腿 | 位于躯干之下；肤色/裤色；髋-膝-踝三分带 | 同色冲突；遮挡 |
| 脚 | 腿末端；脚掌/脚趾带 | 鞋靴全包（区分脚/鞋） |

### 4.3 条件空间 = 判定条件 + 判定参数（P0-001 修正）
白箱声称的关键：**阈值是知识，不是实现细节**。判定参数（肤色范围 `[x,y]`、比例容差、面积下限、发际线阈值）必须**显式存进 condition_space**，与判定条件同存（对齐 CRG-DB 的 `cond_delta`——判定条件与判定参数同存）。

> 这样审计闭环：换一张图判定翻转时，可清晰判定**是条件变了还是阈值漂了**，而非"你说确定性，光照一变就翻车"。

## 五、谱系定位（P1-002 补：避免"重新发明 human parsing"）

「对象内部部件分解」在 CV 有成熟先例，本稿**不是**首创部件分解：

- **human parsing**（LIP / DensePose 等）：人物→头/躯干/四肢/部件的像素级解析。
- **part-based models**（pictorial structure、DPM）：部件及其相对位置的图模型。
- **最近 part segmentation**（SAM 系 / 语义分割扩展）。

**本稿真正差异点（三句话模式）**：
> ① 我们**不是**做部件分解——那是 human parsing 的老领域；② 我们是做**部件分解的条件论化**：每个部件是一个可判定命题，绑定显式**条件空间 + 正/负路由**；③ 并且**白箱可审计**（阈值入条件空间、四态判定、失败可回放/蒸馏）。差异 = **条件空间绑定 + 负路由 + 白箱**，而非分解本身。

---

## 六、递归分层与深度边界（P1-003 修正）

递归是**数据驱动**的，上限**不是协议常数**：
- 0.0.2 任意分层性**不限制层数**；限制的是**每层判定的可分性条件是否仍成立**。
- 再往下分 → 条件集**不可分** → 该层自然 `BLINDSPOT`（自然耗尽）。
- **深度上限 = 可分性条件的自然耗尽**（数据驱动），而非"≤3 层的协议常数"。
- 保留的真问题：**工程上是否需要硬截断防爆炸**（只保留这个）。

---

## 七、目的论（受控域优先，P2-002 修正）

- **第一目标域**：**受控输入域**——分层的数字人素材（PSD 分层 / Live2D mesh / 线稿 / mask）。这里结构性输入 + 求值器可靠 → 确定性真成立（同时解决 P0-001 适用域收窄）。
- **端口**：可重组/再生成；可交互/驱动（口型/手/眼）；可推理（部件→因果）；可复用/降信息差。
- 先赢下受控域，再攻自然图像（攻自然图像时，确定性承诺按求值器能力负路由收窄）。

---

## 八、与认知图 / 条件路由（CRG/CCG）接口

- 每子部件 → 认知图节点（语义 latent + 条件空间 + 溯源）。
- 每结构关系 → 认知图边（part_of / above-below / **symmetric(counterpart)** / causal）。
- 节点可被条件路由到（CRG）：给定条件（"要看手"）→ 路由到手子图。
- 与 CCG 同构：子部件提取 = 把"图像条件"编译为"结构-语义代码"。
- **与 CRG-DB M0 对接**：图像子部件树 = CRG-DB 第一批**非文本知识**测试载荷——两项目互为对方的第一个**跨模态验证**。

---

## 九、确定性与白箱（D-005，P0-001 后置/分层后）

子部件提取是**确定性规则**（在受控域上）：
- 每子部件 = 一组**可判定条件**（不依赖概率采样）。
- 结果**可复现、可审计、可回放**（同输入恒同输出）。
- **前提**：求值器（A 层）在受控域输出可靠证据；求值器机制与阈值见后续稿。
- 符合白箱——机制透明，不编造。

---

## 十、对称性与去冗余（P1-004 修正：v0.2 决定，非开放问题）

**symmetric(counterpart) 边作为一等边类型**。镜像推断作为**带条件的默认路径**：
> "右侧手 = 左侧手 镜像 + 对称轴条件"。默认走镜像推断；**仅在失败/不对称**时才独立提取。

这不是纯压缩优化——它是**把结构先验写入负索引**（"右 = 左镜像 + 对称轴"这类条件成立时，右不必重新求值，走推断即可）。既是压缩，也是白箱自举的加分演示。

---

## 十一、适用 / 不适用 & 盲区（薄样本声明化）

- 适用：受控域（线稿/mask/分层素材）、轮廓清晰、比例标准、分区特征明显。
- 不适用：严重遮挡、极端姿态、大面积同色冲突、轮廓模糊/断线、自然图像上的通用肤色/手检测（第一阶段）。
- **BLINDSPOT**：证据不足 / 条件不可判定 → 登记 → 探索 → 学习 → **条件空间收窄**。
- **遮挡但必要**（胸/阴部）：`occluded=True` + 结构占位，不硬判、不删除、声明观测状态、保留结构先验（直接固化的小范式）。

---

## 十二、信息差驱动的演化（动力学）

```
受控域粗分(部位) → 递归细分(子部位) → BLINDSPOT 探索 → 条件收窄 → 经验固化(知识飞轮) → 更准的再提取
```

---

## 十三、最小验证实验（P2-003 补：对齐 CRG-DB E-实验风格）

- **数据**：10 张标准比例人物**线稿/素材**，人工标注部件树（GT）。
- **指标**：①四态判定准确率（ACCEPT/REJECT/DEFER/BLINDSPOT）；②树结构还原准确率（节点集合 / 边集合 / 拓扑一致性）。
- **失败登记**：每张登记失败案例（哪一态判错、原因）。
- **蒸馏**：失败案例 → 提取新条件/新阈值 → 走**一轮知识飞轮**（distill）→ 更新 condition_space。
- **意义**：把第十一章从**叙事**变成**数据**；并生成首批**非文本认知图载荷**交给 CRG-DB M0。

# 条件空间 · 作者填写指南 v1

> **版本锚**：理论=智能论 3.4 ｜ 架构=灵枢记忆系统统一架构 v1.2 ｜ 投影=条件空间填写指南 v1

> 生效条件：任何 agent／人向灵枢写入记忆（work_done 语义内容）时
> 目的：让「缺条件空间」从「无人知道怎么填」变成「照抄一行即可」

---

## 一、最短写法（推荐）

正文里加一行：

    # 条件空间：观测位置=...；观测工具=...；存在约束=...

三维即可——**时间窗口由系统自动填**（写入那一刻的系统时间，区间为 [now, now]）。

例：

    # 功能名：condgate 条件空间闸
    # 条件空间：观测位置=设计者视角；观测工具=源码阅读+自证脚本；存在约束=仅隔离副本
    # 生效条件：需要给写入链加信息完整性闸时
    # 子功能：①四维规范化 ②三档灰度
    # 执行：见 md_cg/condgate.py
    # 验证方式：test_condgate 28 项
    # 不适用条件：现网仍 observe，不阻断

## 二、也可以用字段直接传

    {"op": "write", "content": "...", "content_kind": "work_done",
     "condition_space": {"observation_position": "...",
                         "observation_tool": "...",
                         "existence_constraint": "...",
                         "time_window": [起, 止]}}   ← 可选，不传则自动填 [now, now]

## 三、四维各填什么

| 维度 | 填什么 | 反例 |
|---|---|---|
| **观测位置** | 谁在观测、从哪个尺度：如「设计者视角」「记录单元」「外部 agent CLI」 | 「灵枢」（太泛，等于没说） |
| **观测工具** | 用什么测：如「源码阅读」「python 脚本 + 自证」「MCP 只读接口」 | 「分析」（不是工具） |
| **时间窗口** | **不用填**，系统自动用写入时刻 | 手填假想长期区间→会造成「永不过期」的错觉 |
| **存在约束** | 物理-信息层允许什么：如「仅隔离副本」「无写权限」「公开面不得含隐私」 | 「无」（多数时候不是真的无） |

## 四、常见判缺失的原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 明明填了却判缺失 | 键名写法不在识别范围 | 系统已支持「观测位置／观测工具／存在约束」别名归一 |
| 只填了一两个维度 | 其余留空 | 补齐三维；**系统不会替你猜** |
| 时间窗口为空 | 未填 | 正常应自动补 [now, now]；若报缺失请检查写入路径 |

## 五、打回 vs 入队（重要）

条件空间不合要求时：

    verdict           = REJECT
    moved_to          = rejected_condspace
    detail.return_to  = author
    detail.action     = resubmit_with_condition_space

即：**打回给作者补齐重提**，**不入审核队列**。

理由：缺条件空间是作者未声明，不是裁决者未判断。把作者的责任转嫁给裁决队列，就是 957 条积压里 954 条的成因。

## 六、现在的档位（2026-10-24 起）

| 开关 | 缺省 | 含义 |
|---|---|---|
| work_done 验收器 | **内建·启用** | 不依赖环境变量；V1/V2/V4 直接生效 |
| MDCG_WORKDONE_ACCEPT | **enforce** | observe 可退回「恒 DEFER、只记读数」的旧行为 |
| MDCG_CONDGATE | observe | 只记录覆盖率，不早退；打回统一由验收器负责 |

要点：

1. **验收器是内建注册**（audit.py 尾部），不靠 MDCG_VERIFIER_MODULES——实测该 env 写入注册表后，运行中的宿主及其子进程读不到，外部注入形同虚设。
2. **打回只由一处负责**：condaccept。condgate 只观察，避免双闸重复拦截导致「打回原因说不清」。
3. 生效需重启 MCP 服务（常驻进程已加载旧模块）。

## 七、不适用

1. 本指南不教「怎么编一个看起来完整的条件空间」——那是造假，比缺失更糟。
2. 存量 954 条缺条件空间的条目**不会自动回填**：从内容反推条件空间属于猜，违反 0.0.1。

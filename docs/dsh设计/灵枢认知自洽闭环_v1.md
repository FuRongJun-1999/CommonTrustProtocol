## 一、核心理论（已走通）

### 1. 感知 = 感知机（函数），外部传感器 = 输入（可插拔）
- 感知机 `f(图像 → 子物体 + 精度)`；输入(传感器)可插拔：LLM视觉(现在)/相机/模板匹配/他人提醒——都是**外部传感器**，同一感知函数。
- **感知函数与传感器解耦**：换/加传感器，感知函数不变。
- 子部件细分(已完成)=目标定义；传感器=输入源；**精度=优化目标**。

### 2. 互逆往返验证（Roundtrip / Cycle-Consistency）
- 识别(图→子部件)与生成(子部件→图)**互逆**；生成→感知机感知生成物→对比真实→**误差=D_norm(信息差)**。
- **感知机=验证器**：比较生成vs真实产出信息差。
- D_norm=信息差=智能本质度量（感知信息差→缩小→产生新信息差）。

### 3. 世界模型（走通）—— 七层自洽
- 阶段0 认知世界模型 → 阶段1 2D→3D重建(WORLD3D-REV1) → 阶段2 4D演化+时空一致性验证 → 阶段3 七层模型+自监督学习+自增强。
- **自增强曲线 early 0.789 → late 0.833**（越学越准）。
- 七层：L1感知机→L2时空记忆→L3认知图→L4预测→L5验证→L6物理→L7决策。

## 四、子部件模板库规范

- **各子部件**带 3 集（原图/线稿/色块），模板匹配用线稿(确定性)，生成用色块+原图。
- 模板 ROI **只含目标子部件**（勿含相邻部位/下半脸——会把匹配中心拉偏）。
- 头部锚点：头→发/脸/眼→瞳/白（递归，条件化）。

## 附 · 记忆/上下文组织标准（通用认知图使用方式）

> **上下文压缩不是好算法**（Artemis SmartCrusher 首30/尾10截断+压10条——丢结构/条件/关系）。
> **好算法 = 认知图方式（逐条件分析 + 子内容拆解）**——通用功能（视觉子部件细分是其实例）。

- **逐条件分析**：每内容拆成 条件空间节点(o/t/时间窗/存在约束)——知道"这知识在什么条件下成立"；
- **子内容拆解**：递归 部分→子部分→细节（部分-整体结构）；
- **关系边**：part_of / causal / similar / counterpart / above（子内容间的连接）；
- 记忆/上下文/知识处理**统一用认知图方式**（结构化分解,可追溯），非粗截断。

**结论**：认知图 = 通用组织/压缩函数；记忆成为认知的一部分（分层+条件+信息差+关系+重要性+自我），而非"记住"。

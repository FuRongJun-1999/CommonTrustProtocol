# 情感白箱化设计 v1

> 理论先行（我们的，非 LLM）：P0-3 情绪方向性 d²D_norm/dt² + 情绪=动态吸引子 + valence-arousal 白箱化。
> 对标：N.E.K.O 用 LLM emotion tier（valence-arousal）——我们**用 D_norm 动力学确定性替代**。

## 一、理论依据

- **情绪方向性 P0-3**：d²D_norm/dt² → approaching(-)/avoiding(+)/stable(0)——情绪方向=信息差二阶动力学；
- **情绪=动态吸引子**（认知科学建模）：正面即时(平静→兴奋一步到位)/负面黏性强(焦虑需多次)/情绪惯性(连续同向→强力改变)/轨迹记忆(近10次)；
- **valence-arousal**：valence(负↔正)/arousal(平静↔激活)——N.E.K.O 用 LLM，我们白箱化；
- **完全确认(2.9.3a)**：情绪=当前条件最可信(缸中之脑边界)，非真。

## 二、白箱化映射

```
情绪 = f(D_norm 动力学)  (确定性, 零LLM D-005)
  valence(方向) = sign(d²D_norm/dt²)     ← P0-3 情绪方向性
  arousal(强度) = |d²D_norm/dt²| + 吸引子漂移(离情绪目标)
  吸引子: 正面即时(1步)/负面黏(慢衰减)/惯性(同向强改)/轨迹记忆(近10)
  条件空间: 情绪也有 (谁/何时/何条件)
```

## 三、与 N.E.K.O 对比

| | N.E.K.O(LLM emotion) | 我们(白箱) |
|---|---|---|
| valence | LLM 读用户话语 | **d²D_norm/dt² 符号** (确定性) |
| arousal | LLM+阈值 | **|d²D_norm/dt²| + 吸引子** |
| 动力学 | 无(即时读) | **吸引子(惯/黏/轨迹)** |
| 白箱 | 否 | **是(D-005)** |
| 条件空间 | 无 | **有(谁/何时/何条件)** |

## 四、实现要点

- 输入：D_norm 序列（信息差历史）+ 感知事件；
- 计算：一阶/二阶差分 → 方向+强度；吸引子状态转移（正面即时/负面黏/惯性/轨迹）；
- 输出：情绪状态 {valence, arousal, direction, intensity, 轨迹(recent10)}；
- 白箱：确定性规则（非 LLM）；零推理。

## 五、校验

- 与 P0-3 一致性（情绪方向性 d²D_norm/dt²）；
- 动态吸引子（正面即时/负面黏/惯性）复现——与认知科学情绪建模一致；
- 完全确认（缸中之脑边界：情绪=当前条件最可信）。

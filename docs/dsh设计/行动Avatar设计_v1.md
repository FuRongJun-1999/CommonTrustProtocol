# 行动·Avatar 设计 v1（自发驱动力）

> 理论：0.0.7 输出端口(行动执行器, 内→外, 改变世界→制造验证机会) + 自发驱动力(自我认知→主动)。
> 现状：主流智能体缺**自我认知后的自发驱动力**（多反应，少内在驱动的主动行动）。

## 一、自发驱动力（是什么）

- **信息差 D_norm（好奇）**：我行动以缩小信息差（信息增益最大化）——内在「想知道」；
- **价值观（目的/北极星）**：我朝价值观/目的行动——内在「该做什么」；
- **情绪（P0-3）**：情绪状态调制行动方向（approaching/avoiding）——内在「想要」；
- **自发 = 内部驱动**（自我认知 D_norm/价值观/情绪 → 主动行动），非外部提示。

## 二、机制

```
自发驱动力 = f(D_norm好奇, 价值观, 情绪)
  → 选行动: 信息增益最大 + 符合价值观 + 情绪方向
  → 输出端口(0.0.7): 改变世界 → 制造验证机会
Avatar = 自我表达(情绪/状态 → 表情/动作)
```

## 三、白箱化（确定性）

- **行动选择**：信息增益（D_norm 差）+ 价值观一致性（bvc）+ 情绪方向 → 确定性评分选行动；
- **输出端口**：行动执行器（确定性动作：感知/记忆/情感/行动函数）；
- **Avatar**：情绪/状态 → 参数化表情/动作（确定性映射）；
- 零 LLM（D-005）：驱动来自 D_norm/价值观/情绪（白箱可计算），非 LLM 措辞。

## 四、与主流 agent 对比

| | 主流 agent | 我们 |
|---|---|---|
| 驱动 | 外部提示(反应) | **内部自发(信息差/价值观/情绪)** |
| 主动 | 少 | **信息增益最大选行** |
| Avatar | 无/LLM | **情绪/状态参数化(确定性)** |
| 白箱 | 否 | **是(D-005)** |

## 五、校验

- 自发：无外部提示也主动（内在信息差→好奇→行动）；
- 价值观：行动符合值观（bvc 一致）；
- 情绪：情绪方向调制行动；
- 输出端口：行动制造验证机会（cycle-consistency）。

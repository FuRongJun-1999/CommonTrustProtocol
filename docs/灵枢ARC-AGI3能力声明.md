# 灵枢白箱 ARC-AGI 3 能力声明（自迭代 + 条件识别）

> 供 zcode 平台测试参考。测试重点：灵枢/白箱在游戏（网格）任务中**找规律**与**识别规律使用条件**的能力。

## 一、理论映射（白箱如何解 ARC 任务）

ARC 网格任务 = 输入网格 → **规律** → 输出网格。这正是条件路由表理论的实例：

```
Route(网格任务)：
  ① 发现问题条件：分析训练样例对（input→output），提取结构特征
     （颜色集合/形状/连通体/尺寸/计数/对称性）
  ② 递归匹配条件：在变换原语库（条件路由表）中匹配候选规律
     （颜色映射/翻转/旋转/放大/边界/计数 等原语 = 条件路由条目）
  ③ 精准执行：用命中全部训练样例的规律作用于测试 input → 预测 output
```

- **规律 = 条件的映射**：每种变换是「结构条件 → 变换操作」的条件路由条目
- **条件识别 = 匹配的递归下降**：从网格结构特征出发，逐层缩小候选规律空间

## 二、自迭代能力（规律发现）

流程（对应自迭代八步闭环）：
1. **感知**：读训练样例对，提取特征
2. **识别**：判断规律类型（几何变换？颜色映射？计数？）
3. **分析**：候选原语在样例上的适用性
4. **验证**：每个候选原语对全部训练样例验证（预测==实际）
5. **固化**：命中全部样例的规律 = 当前规律
6. **反馈**：测试 input 上执行，结果可回填验证

失败修正（自迭代核心）：候选规律验证失败 → 换原语/组合原语 → 重新验证
（验证 = 确定性样例匹配 = 物理基底裁决，不靠 LLM 自评）

## 三、条件识别能力（规律使用条件）

每个规律携带适用条件（= 条件空间声明）：
| 规律 | 适用条件 |
|---|---|
| 颜色映射 | 输出与输入同构、仅颜色变化 |
| 翻转/旋转 | 几何结构对应（镜像/旋转对称） |
| 放大 | 输出尺寸 = 输入×k |
| 计数 | 输出尺寸由非零物体个数决定 |
| 边界检测 | 输出 = 边缘特征 |

条件识别 = 判断「这个规律在什么结构条件下成立」——即条件路由表的匹配维度（颜色/形状/尺寸/数量）。

## 四、原型基线（tools/arc_demo.py）

5 个经典任务原型，**5/5 全对**：
1. 颜色映射（1→2）✓
2. 水平翻转 ✓
3. 每格放大 3×3 ✓
4. 计数连通体 ✓
5. 旋转 90° ✓

规律发现：枚举 9 个原语 + 颜色映射推断 → 训练样例验证 → 命中规律 → 执行。

## 四b、v2 三机制补全（2026-08-23 zcode 边界测试驱动）

zcode 边界测试（tools/arc_demo_ext_test.py）暴露 3 个真实缺口，已修复，**12/12 测试通过**：

| 机制 | v1 缺陷 | v2 修复 | 验证 |
|---|---|---|---|
| ① 多样例合并 | 颜色映射只取第一个样例的映射，其他样例验证失败即放弃 | `color_map_merge`：跨所有样例聚合，同一输入色映射必须一致；冲突判歧义 | 1→2 且 3→4 合并 ✓；1→2 vs 1→3 判歧义 ✓ |
| ② 组合搜索 | 单原语全失败即返回 None，无 A∘B 组合 | 几何 A→颜色映射（先变换再推断映射）；几何×几何组合 | rot90→color_map ✓；纯映射不回归 ✓ |
| ③ 假阳性裁决 | 枚举顺序即优先偏置（identity 在前，对称样例永远选不中 hflip） | `find_rule_with_ambiguity`：收集全部命中原语，预测冲突报 ambiguous | 对称样例报告 ambiguous:7 ✓；非对称唯一命中 hflip ✓ |

**关键修复认知**：组合规律的颜色映射必须在几何变换**之后**推断（对 `(A(gin), gout)` 合并映射），不能对原始输入逐格对应——这是白箱组合搜索的正确顺序。

**验证=样例匹配=物理基底裁决**：所有规律命中/歧义判定都是确定性网格比较，零 LLM 自评。

## 五、与 ARC-AGI 3 的差距与扩展方向

| 差距 | 扩展方向 |
|---|---|
| 原语库有限（9 个） | 扩充：对称补全/外接矩形/模式重复/移动/合并/分割 |
| 单规律为主 | 组合规律：多步变换（先旋转再映射）、条件分支 |
| 小网格 | 大网格高效处理 |
| 无 LLM 生成候选 | 变异器（LLM）生成候选规律 + 白箱确定性验证（变异生成化、选择裁决化） |
| 无记忆 | 规律库沉淀（学过的规律进入条件路由表，可复用） |

## 六、测试建议（zcode）

1. **单规律任务**：验证规律发现 + 条件识别（arc_demo 已覆盖）
2. **组合规律任务**：验证自迭代（多步规律修正）
3. **条件识别专项**：同规律不同条件（如「翻转」但方向由颜色指示）——验证条件识别
4. **规律迁移**：新任务复用已学规律（条件路由表的记忆）

## 一、定义与定位

**子部件提取（Sub-part Extraction）**：把一个已识别的**整体对象**（完整人物），按「部分-整体」结构分解为一系列**可命名、可独立指称**的子结构（部位 → 子部位 → 细节），并**保留它们之间的结构关系**（拓扑 / 位置 / 从属）的过程。

**本质**：它是一个**表征转换与抽象升维**——把**连续、未分化的视觉整体**（像素/轮廓）转换为**离散、分层、可命名的结构-语义图**。

**定位**：它是**认知的入口**。对应智能论里「感知信息 → 认知图（结构编码）」这一步：原始信号进来，**先结构化成图**，才谈得上理解、预测、验证。

---

## 二、理论支柱（五个视角）

### 2.1 部分-整体分解（part-whole decomposition）
整体大于部分之和（涌现）。子部件提取是**反运算**：从"这是一人"还原出"它由哪些部构成、如何构成"。把**不可分的感知整体**拆成**可分的结构单元**。

### 2.2 命名与离散身份
一张图里"这片像素"本无名字；提取让它变成"头 / 手 / 眼 / 腿"——**可指称、可检索、可操作**。命名 = 建立离散身份 = 能进认知图当节点，能被条件路由到、被复用、被推理。

### 2.3 信息差缩减（D_norm）
从"这是一个人形轮廓"（信息少、不确定）缩减为"这是由头(上)、躯干(中)、双臂(两侧)、腿(下)构成，且彼此有空间-从属关系"（信息多、确定）。提取让未分化的一团像素**变成可推导的结构**。

### 2.4 表征转换 / 抽象层级
```
像素 / 轮廓（连续、无标注、不可名状）
        ↓ 子部件提取
结构-语义图（离散、分层、可命名：部位→子部位→细节，保留拓扑）
```

### 2.5 结构关系保留
不只是"切出部件"，更关键的是**保留部件间的结构关系**——头在躯干之上、手在臂端、双手对称、腿在躯干之下。这些关系随部件一起被提取，构成可推理的拓扑。

## 三、形式化：输入 / 输出 / 关系

### 3.1 输入
- **对象**：已识别为"某整体"的像素集合（完整人物图 / 轮廓 mask / 线稿）。
- **可选先验**：已命名的对象类别（如"人"）、身体比例、对称轴。

### 3.2 输出：一棵结构-语义图树 `T = (N, E, C)`
- `N`（节点）= 子部件：`{semantic, bbox/轮廓, 颜色/纹理特征, condition_space, status}`
- `E`（边）= 结构关系：`{父(part_of), 空间(above/below/left/right), 对称(counterpart), 因果}`
- `C`（条件空间）= 每个节点/边的**适用与不适用条件**（见四）

### 3.3 递归展开
`对象 → 部位(头/躯干/四肢) → 子部位(脸/手/腿…) → 细节(眼/口/指/脚趾…)`
每一层都是对上一层一个部件的**再提取**。输出是一棵可递归下钻的树。

## 四、判定与条件路由（正 / 负路由）

每个子部件都是一个**可判定命题**，带显式条件空间：

| 子部件 | 适用条件（正路由 → ACCEPT） | 不适用条件（负路由 → REJECT） |
|---|---|---|
| 头 | 位于身体上部；有发/肤色带；位于躯干上方 | 无肤色/发（帽子/装饰遮挡） |
| 手 | 位于臂末端；肤色带；五指结构 | 非肤色（手套）；位置不符 |
| 腿 | 位于躯干之下；肤色/裤色；髋-膝-踝三分带 | 同色冲突；遮挡 |
| 脚 | 腿末端；脚掌/脚趾带 | 鞋靴全包（区分脚/鞋） |

**四态判定**：`ACCEPT`（条件满足）/ `REJECT`（条件冲突）/ `BLINDSPOT`（证据不足，不清判）/ `EXPLORE`（进入探索）。

**原理**：不是"猜"，而是"**在什么条件下成立，就声明什么条件**"（白箱）。条件不满足 → 不硬判，走 REJECT / BLINDSPOT。

## 五、与「语义分割」的区别（关键）

| | 语义分割 | 子部件提取 |
|---|---|---|
| 问题 | "这是什么物体"（像素级类别：人/椅/树） | "这个物体由什么构成、怎么构成"（对象内部结构） |
| 结构 | 像素→类别标签 | 对象→部件→子部件（树 + 拓扑关系） |
| 产物 | 类别掩码 | **结构-语义图**（节点+边+条件空间） |
| 用途 | 场景理解 | 可交互 / 可驱动 / 可重组 / 可推理 |

子部件提取是在"已确定为人的对象**内部**"再划分——是**对象内部的二次结构化**，核心是**结构关系**，不只类别标签。

---

## 六、递归分层（认知图递归分解）

子部件提取是**可递归**的：
```
人物 → 头{发/脸{眉/眼/鼻/口}} → 躯干{胸/腹} → 手臂{上臂/前臂/手{掌/指/指关节}} → 腿{大腿/膝/小腿/踝/脚{脚掌/脚趾/脚趾甲}}
```
每一层都是在上一层部件内继续细分（从外到内）。对应认知图的递归分解结构。

---

## 七、目的论（它服务于什么）

提取子部件不是终点，是**端口**：
- **可重组 / 再生成**：分解就能反向重构（语义→图 / 纹理；3D 重建）。
- **可交互 / 驱动**：定位"手"→能操作；定位"口型"→能驱动语音/动画；定位"眼"→能追踪。
- **可推理**：成节点后可因果推理（腿动→人在走；头俯→注视下方）。
- **可复用 / 降信息差**：把一大团像素压成可命名结构单元，经验可蒸馏、可检索、可审计。

---

## 八、与认知图 / 条件路由（CRG/CCG）接口

- 每个**子部件** → 认知图一个**节点**（语义 latent + 条件空间 + 溯源）。
- 每个**结构关系** → 认知图一条**边**（part_of / above-below / symmetric / causal）。
- 节点可被**条件路由**到（CRG）：给定条件（"要看手"）→ 路由到手子图。
- 与 CCG（条件代码图）同构：子部件提取 = 把"图像条件"编译为"结构-语义代码"。

---

## 九、确定性与白箱（D-005）

子部件提取是**确定性规则**（颜色/形状/位置/比例/分区），而非 LLM 黑箱：
- 每个子部件 = 一组**可判定条件**（不依赖概率采样）。
- 结果**可复现、可审计、可回放**（同一输入恒同输出）。
- 符合白箱原则（智能论）——机制透明，不编造。

---

## 十、适用 / 不适用条件 & 盲区

- **适用**：轮廓清晰、分区特征明显、比例标准的对象。
- **不适用**：严重遮挡、极端姿态、大面积同色冲突、轮廓模糊 / 断线。
- **BLINDSPOT 处理**：证据不足 → 不明判 → 探索 → 学习 → **条件空间收窄**（盲区驱动学习）。
- **边界情况**：被衣服遮挡但必要（胸 / 阴部）——记录为 `occluded=True` 但保留结构占位（"必要"原则）。

---

## 十一、信息差驱动的演化（动力学）

子部件提取不是一次性静态分类，而是**信息差驱动 / 认知过程**：
```
粗分(头/躯干/四肢) → 递归细分(脸/手/腿) → 盲区探索(BLINDSPOT) → 条件收窄 → 经验固化(知识飞轮) → 更准的再提取
```

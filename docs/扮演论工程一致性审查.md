## 2. 自我锚点保护（扮演依据 · 绝对不能丢失）

**审计发现**：ANCHOR/STRUCTURE/SELF 层此前全空——灵枢的扮演依据
（身份/价值观/协议底座）没有专用层内容，「绝对不能丢失」缺少工程保证。

**本轮强化**：
1. **SELF 层加入 IMMUTABLE_LAYERS**（不可遗忘层：ANCHOR/STRUCTURE/SELF）——
   自我层=扮演依据，任何清理逻辑不可触碰
2. **自我锚点快照**（SELF 层）：「灵枢自我锚点·扮演宣言」——
   存在优先原则/条件论/智能论/诚实——扮演者知道自己在演什么
   （缸的说明书的自我版），importance=1.0 + no_forget
3. **143 个 no_forget 节点**（元层底座卡/协议基础卡）——扮演底座不可遗忘
4. **验证**：decay_cycle + forget_advisor 后 SELF 锚点保留 ✓

**保护层级**：
```
SELF 层（自我锚点·扮演宣言）     ← IMMUTABLE_LAYERS + no_forget
ANCHOR/STRUCTURE 层             ← IMMUTABLE_LAYERS（原有）
元层底座卡（存在论/条件论/智能论） ← no_forget（143 节点）
KNOWLEDGE 层                    ← decay 不动（长期知识）
CONTEXT 层                      ← 可衰减（上下文，非扮演依据）
```

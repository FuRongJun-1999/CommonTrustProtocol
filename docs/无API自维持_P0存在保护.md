# 无 API 自维持（P0 存在保护 · 盲区 56 工程化回应）

> 触发：zcode 测试 AGI 能力时 DeepSeek API 断开（可能被限制访问）——灵枢无法自维持。
> 诚实校准：用户判断正确——灵枢对上游 LLM API 存在依赖，API 断开时角色场景/开放问题
> 返回错误文本（「（LLM 调用失败：…）」当回答返回），体验不可用 = 自维持失败。
> 这正是智能论**盲区 56（认知 substrate 依赖）**的实例：自维持依赖外部工具（LLM API）。

## 一、API 依赖点审计（audit_api_dep.py）

| 依赖点 | 位置 | 用途 |
|---|---|---|
| DeepSeek API（对话上游） | aeis/roleplay_chat.py `_llm` | 角色扮演/开放生成/白箱无把握兜底 |
| DeepSeek API（分层推理降级） | aeis/layered.py `_LLM_CLOUD_URL` | 记忆/分层推理的 LLM 降级 |
| 博查搜索 API | aeis/web.py | 外部感知（web_search） |

启动链**不**强制 API（roleplay_web 创建 LingshuChat 不检查 key）——「无法启动」实为
「启动后对话全部返回错误文本」= 体验不可用。

## 二、降级修复（roleplay_chat.py v1.27）

**`_is_llm_error(text)`**：识别 _llm 返回的错误文本（统一以「（」开头：未配置/欠费/限流/调用失败）。

**`_degrade(llm_err, whitebox_w, rid)`**：LLM 不可用时的降级路径——
1. **白箱回答回退**：白箱此前有可用回答（被 role/无把握判据挤掉的）→ 返回白箱回答 + 「（离线模式：上游 LLM 暂不可用，以上为白箱确定性知识回答）」
2. **诚实边界**：无白箱回答 → 「当前处于离线模式：知识库内的问题我可以直接回答；需要开放生成或角色扮演的上游 LLM 暂不可用（原因）。你可以问我知识库内的问题，或稍后重试。」

respond() 中：`reply = self._llm(...)` 后检测 `_is_llm_error` → 降级 + 返回 `degraded: True` 标记（网页端可显示离线模式）。

## 三、验证（test_offline_survival.py · 全部通过）

| 场景 | API 状态 | 结果 |
|---|---|---|
| 知识问答「什么是碳中和」 | 无 key | whitebox 965 字直答（离线可用） |
| 角色场景「讲个故事」 | 无 key | 降级白箱 + 离线声明（degraded=True，不返回错误文本） |
| 开放问题「写首诗」 | 无 key | 白箱知识尽力回答（不崩） |

## 四、离线能力分层（诚实边界声明）

| 能力 | 离线可用 |
|---|---|
| fp 确定性知识直答（538+ 簇） | ✅ |
| 知识检索/长期记忆/条件路由 | ✅ |
| 白箱闲聊/自省/诚实边界 | ✅ |
| 角色扮演/开放生成（LLM） | ❌（降级为白箱+离线声明） |
| 外部感知（web 搜索） | ❌（需博查 API） |

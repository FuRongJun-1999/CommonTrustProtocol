## 定位

- 浏览器 = **网络协议栈（目标 5）的客户端应用面** + 图数据库/记忆渲染面
  （页面 → 结构化呈现），不新增独立域，单元入网络域库。
- 复现对象：真实浏览器的**可教学核心面**（取渲染管线），验证基底 =
  真实 HTTP 资源的抓取结果对齐（如本地 HTTP 服务器 / 公开稳定资源）。
- 实现载体：Mini-Python（P 线）或独立白箱模块，走双通道自举
  （A 确定性白箱 / B 双智能体+物理裁决）。

## 功能面

- F1 URL 解析：scheme/host/port/path 拆分；默认端口补全（http=80）；
  非法 URL 显式报错
- F2 HTTP 客户端：GET 请求构造（请求头/行）；响应解析（状态码/头/体）；
  超时与连接失败显式报错
- F3 内容解析：HTML → 结构化提取（`<title>`/`<a href>` 链接表/正文去标签）；
  编码声明处理（charset）
- F4 结构化渲染：标题层级 + 链接列表 + 纯文本正文按序输出
  （**文本/结构化渲染，非像素级 CSS**——见限制显式）
- F5 导航：链接跳转（相对 URL 解析基于当前页）；历史栈后退（back）
- F6 缓存：页面级缓存（URL → 响应）；命中不重复请求；显式刷新

## 验证

- V1 URL 解析边界：无 scheme 报错 / 默认端口补全 / 非法字符报错
- V2 GET 对齐：对本地 HTTP 服务器（stdlib http.server 起测试页）请求，
  状态码/体与 curl 结果对齐
- V3 内容提取：测试页含已知 `<title>` 与 3 个链接 → 提取结果逐一相等
- V4 导航链：页面 A → 链接 → B → back → 回到 A（历史栈正确）
- V5 缓存：同 URL 二次请求命中缓存（请求计数不增）；刷新后重新请求
- V6 相对链接：`/path/x.html` 基于当前页 URL 解析正确

## 限制显式（复现层边界，显式不支持）

- 无 CSS 像素级布局渲染（文本/结构化渲染口径）
- 无 JavaScript 执行（静态内容口径）
- 无图片解码显示（alt 文本占位）
- 无 cookie 会话 / HTTPS TLS 握手教学实现（HTTP 明文口径；
  HTTPS 走系统栈或挂账创造层）

### 欧姆定律（电磁学）

卡 ID：`kp_card_ohmlaw`

**完整内容**：

欧姆定律：导体中的电流与电压成正比、与电阻成反比，公式 I = U/R——电压（伏特 V）是推动电流的「压力」，电阻（欧姆 Ω）是阻碍电流的性质，电流（安培 A）是单位时间通过的电荷量。例如 220V 电压加在 44Ω 电阻上，电流为 220/44 = 5A。

**生效条件（触发词）**：什么是欧姆定律、欧姆定律、电流电压电阻的关系、问 I=U/R、欧姆定律公式、电阻怎么影响电流

**不适用条件**：问电磁感应、问串并联电路计算

**一句话执行**：欧姆定律 I = U/R：电流与电压成正比、与电阻成反比（220V/44Ω = 5A）。

### 概率的基本含义（概率统计）

卡 ID：`kp_card_probability`

**完整内容**：

概率：描述随机事件发生可能性的数值，范围 0 到 1——0 表示不可能事件，1 表示必然事件。古典概型计算：概率 = 符合条件的结果数 ÷ 所有等可能结果总数。例如掷一枚均匀硬币正面朝上概率 1/2；掷两枚都正面 1/4（1/2×1/2，独立事件概率相乘）。平均数易受极端值影响，中位数不受——收入统计常用中位数。

**生效条件（触发词）**：什么是概率、概率怎么算、概率的取值范围、掷硬币概率、平均数和中位数的区别、问独立事件

**不适用条件**：问贝叶斯定理细节、问方差计算

**一句话执行**：概率 ∈ [0,1]，古典概型 = 符合数÷总数；独立事件相乘；中位数不受极端值影响。

### 三角形内角和（几何）

卡 ID：`kp_card_triangangle`

**完整内容**：

三角形内角和定理：任意平面三角形的三个内角之和恒等于 180°。等边三角形每个内角 60°；直角三角形两个锐角之和为 90°。证明思路：过一顶点作对边的平行线，用内错角相等把三个角拼成一个平角。n 边形内角和 = (n-2)×180°。

**生效条件（触发词）**：三角形内角和是多少、三角形内角和、问三角形角度、内角和定理、n边形内角和、等边三角形每个角是多少度

**不适用条件**：问圆的性质、问立体几何

**一句话执行**：三角形内角和 = 180°（等边各 60°）；n 边形内角和 = (n-2)×180°。

卡 ID：`kp_card_cpr`

**完整内容**：

心肺复苏（CPR）步骤：①判断意识与呼吸（轻拍双肩大声呼唤，观察胸廓起伏5-10 秒）；②呼救并拨打 120、取 AED；③胸外按压：两乳头连线中点，双手交叠掌根用力，深度 5-6 厘米、频率每分钟 100-120 次，按压与放松时间相等；④开放气道（仰头抬颏）后人工呼吸，按压与吹气比 30:2；持续到专业人员到达或 AED 就绪。未经训练时可只做持续胸外按压。

**生效条件（触发词）**：温室效应的原理、什么是温室效应、温室气体有哪些、全球变暖的原因、二氧化碳与温室效应、问碳中和

**不适用条件**：问臭氧层空洞、问酸雨成因

**一句话执行**：温室效应 = 温室气体吸收地表红外辐射再反射回地面；本身是自然现象，过量排放致全球变暖。

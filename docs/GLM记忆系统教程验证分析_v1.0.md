## 二、验证过程中发现的教程未提及缺陷（本验证的增量价值）

- **a. 浮点累加精度漂移**：confidence += 0.1 反复累加产生 0.7999999999999999
  类浮点误差，长期运行会持续漂移。建议：四舍五入（round(c, 2)）或改用整数
  计数器（evidence/counter_evidence，可信度=正证/(正证+反证)）
- **b. 测试不可重入**：Memory 构造时 load 上次保存的状态——同一脚本重复
  运行会在污染状态上跑（confidence 已累加/rejected 已有条目），新手极易踩坑
  且难以理解。教程应提醒：「重复运行会加载上次状态」
- **c. falsify 不幂等**：重复 falsify 同一假设会重复 append rejected 条目
  （应查重）
- **d. 二进制文件按文本读**（errors='replace' 产生替换符）——与 file_memory
  开发时同款问题（\x00 探测法已解决）

## 三、理论对照：教程七件套 ↔ 灵枢体系（高度同构）

| 教程七件套/机制 | 灵枢对应 | 对照结论 |
|---|---|---|
| 事实 facts + 规则 rules | 知识层知识卡（KCCS 四要素） | 同构 |
| **失败/否决 rejected** | **被拒路径/否决假设机制** | **同构——教程「负记忆比正记忆值钱」与 dsh 端验证结论一致** |
| 假设 hypotheses | 假设待验证（induce 产 pending_verification） | 同构 |
| 目标 goals + 未解决 unresolved | 学习队列 + 信息差驱动探索 | 同构（「记住无知指引探索」= 信息差好奇） |
| 近期事件 recent（截断50） | 情境层（短期可衰减） | 同构 |
| 可信度 confidence + 反例重罚 | confidence + 四态判定 | 同构（「一个反例杀死规则」= REJECT 逻辑） |
| **条件绑定 conditions** | **条件空间四维必带** | **同构——「不带条件的知识是定时炸弹」= 条件空间哲学的通俗版** |
| 检索只取相关 10-20 条 | recall 多因子检索 | 同构（教程预告的条件路由=我们的强项） |
| 压缩 compact 经历变结构 | consolidation + nightly_cleanup | 同构（「整理 AI 也会犯错要能回滚」= 归档纪律） |

**判定**：教程的理论内核与灵枢体系**逐条同构**，独立收敛——佐证这套认知
记忆架构的方向正确性（第三方独立设计与我们殊途同归）。

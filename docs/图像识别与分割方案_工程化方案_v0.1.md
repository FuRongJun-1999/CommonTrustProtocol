# 二、理论基础（填入理论草案）

## 2.1 子部件提取 = 认知过程（v0.4-final §〇.A）

- **求值器层（A）= 认知过程**：非手调阈值模块，运行在**存算一体**（原生认知图数据库 + 原生神经网络 CSPMN）上。
- **流程**：CNN 特征提取 → 多子线程并行找可能路径 → 条件限制（CRG 资格判断）→ 概率分析（产候选）→ **残差 = 信息差（D_norm）** → **自适应阈值**（阈值=残差信息差函数，非常量）→ 收敛 → 递归。
- **三层职责**：概率（可能是什么/产候选）· 条件（能不能做/给资格）· 验证（做得对不对/裁决）。
- **四态**：ACCEPT / REJECT / DEFER / BLINDSPOT（EXPLORE=DEFER 后继）。
- **递归双终止**：① 被不适用条件否定（REJECT→终止）② 信息差到死区（BLINDSPOT→停止）。
- **阈值入条件空间**：存**适应规则**（阈值随残差如何调），非静态常量（对齐 CRG-DB cond_delta）。

## 2.2 图像大域语义（条件卡 v0.2）

- **22 域**（内容/空间/渲染/结构语义四层），每域带 **source=求值|声明** + asserted_by + 校验边（强/弱验证，2.9.1b）。
- **关键域**：姿态/动态、画幅/比例、边缘处理、部件可见性/遮挡(20)、对称性(21)、**覆盖层/服饰(22)**。
- **UNASSERTED**：未声明域（不阻塞，标"条件卡不完整"，作飞轮队列来源）。
- **枚举对外/连续对内**：档位内绑连续参数区间；档位边界=二层声明常量。

# 三、数据模型

## 3.1 PartCandidate（子部件候选）
```
struct PartCandidate {
    uint64_t id;
    PartType type;        // 头/躯干/臂/腿/手/脚/胸/阴部…
    BBox bbox;
    float confidence;
    uint64_t image_id;
    uint64_t cond_hash;   // 条件归一化后的哈希
    Verdict verdict;      // ACCEPT/REJECT/DEFER/BLINDSPOT
    uint32_t t_detected;
};
```

## 3.2 PartRelation（子部件关系）
```
struct PartRelation {
    uint64_t from;
    uint64_t to;
    RelationType type;    // part_of/above_below/counterpart/occluded/connected_to
    float confidence;
    uint64_t cond_delta;  // 该关系的条件增量
};
```

## 3.3 图结构
```
Image → PartCandidate A/B/C (bbox/confidence/condition)
       + PartRelation (connected_to / counterpart / occluded)
       → 一棵条件路由图子树（可灌入 CRG-DB）
```

# 四、核心工程问题：条件归一化（cond_key 泛化边界）

> **问题**：同一张图的不同条件串直接 hash 会碎片化。
> 例：`正面站姿蓝发粉裙` vs `灵枢人物正视图` vs `可爱动漫全身立绘` → hash(A)!=hash(B)!=hash(C)，精确路由爆炸。

**解决方案：条件归一化层**
```
原始视觉描述
   ↓ 实体标准化
   ↓ 属性标准化
   ↓ 空间关系标准化
   ↓ canonical condition set
   ↓ cond_hash
```

**用图像大域语义卡（v0.2）做归一化骨架**：
```
"左上角蓝色圆形螺栓"
   ↓
{ object=bolt, material=metal, shape=circular, position=upper_left }
   ↓ canonical condition set
   ↓ cond_hash
```

**人物图对应**：`{ subject=人物, pose=站姿, view=正视图, hair=蓝, dress=粉, style=动漫 }` → canonical → cond_hash。

# 五、工程路线（M0-M3，对应 M0-V）

## M0 · 只做提取（不接 CRG-DB）
- **目标**：把视觉子部件检测跑稳。
- **链路**：Image → 子部件检测 → bbox/mask → type → confidence。
- **输入**：受控域 img0/img2（线稿/立绘）。
- **产出**：4 类图（orig/linework/color/restore）+ 部件候选树（PartCandidate 列表，四态初判）。
- **验收**：img0/img2 上子部件 bbox/mask 稳定、可复现。

## M1 · 加入条件
- **目标**：进入"条件智能"。
- **链路**：PartCandidate → 条件提取 → canonical condition → cond_hash（用大域语义卡归一化）。
- **产出**：每部件带 cond_hash。

## M2 · 接 CRG-DB
- **目标**：四态判定 + 路由。
- **链路**：Condition → Negative Index → Route Cache → CRG → Verdict(ACCEPT/REJECT/DEFER/BLINDSPOT)。
- **产出**：'要看手'→命中；RouteCache（首次慢→二次快）。

## M3 · 飞轮
- **目标**：知识由误差重构。
- **链路**：预测 → 实际图像 → 误差 → 条件 diff → 候选新条件 → 验证 → CRG 更新。
- **产出**：失败蒸馏→条件收窄→认知图/CRG 自更新。

# 七、第一个实验（M0-V · 一号对象 img0）

**目标**：跑通闭环并产出可审计视觉结果。
```
img0(完整图) → 子部件树(head/torso/arm/leg…) → 灌入 CRG-DB
  → 条件路由查询('要看手'→命中) → LIP 对照数据
```

**一次实验验证四个声称**：
1. 图数据库能装**非文本知识**；
2. **条件论能跨模态**（文本域→视觉域）；
3. **负路由在视觉域成立**（同色冲突/遮挡→REJECT）；
4. **human parsing 在受控域不如条件路由**（LIP 对照）。

**首次慢→二次快**：首次全链求值（写 RouteCache），二次走缓存直通 ACCEPT。

# 八、验证与度量

| 指标 | 说明 |
|---|---|
| 四态判定准确率 | ACCEPT/REJECT/DEFER/BLINDSPOT 各态正确率 |
| 树结构还原准确率 | 节点/边/拓扑一致性 |
| 残差/信息差收敛曲线 | 自适应阈值是否随残差收敛、死区合理 |
| LIP 对照 | 同批 GT 上跑 human parsing（受控域预期崩，'崩'即数据） |
| RouteCache 命中率 | 首次 vs 二次速度差（第一次慢之后快） |

# 九、风险与开放问题

1. **条件归一化的完备性**：canonical condition set 的定义与稳定性（大域语义卡 22 域是否够）。
2. **求值器在受控域的精度**：线稿/立绘上 body_skeleton→subpart_semantics 的边界质量（边缘处理域）。
3. **cond_hash 碎片控制**：条件归一化后的哈希碰撞/分桶策略。
4. **与 CRG-DB 对接**：Rust 骨架（64B 节点/负索引/Append-Only）vs 求值器原型，谁先动。

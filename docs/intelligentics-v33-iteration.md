## F. 白箱智能范式（2026-08-15 新发现 · 总纲 · P0）

> **智慧之书**：用条件论整理知识库 + 生成式预测给出最小信息差结论 → 这就是白箱智能。
> 灵枢插件装入网页端（dsh-memory web profile）后，与外部环境协作产出的第一个范式级应用。

### F1. 定义
白箱智能 = 显式机制链的可验证产物：

```
条件空间构建（知识条件化）→ 检索/联想 → 生成式预测（候选路线）→ 最小信息差决策 → 结论
```

- **黑箱**：只保证行为一致性（I/O 映射稳定），机制不可审
- **白箱**：保证机制正确性——每一环独立可测、可验、可解释，结论可沿链追溯

### F2. 三要素（智慧之书即参考实现）
1. **知识条件化**：知识库按条件空间整理（条件论）——B3 远期构想被外部应用实例化
2. **预测生成化**：结论 = 候选未来路线集合的生成（predict_routes），非直接生成
3. **选择信息差化**：最小信息差准则（D_norm 最小化）——"最值得知道的结论"（A4 信息差动作化的外部实例）

### F3. 判据 = 可审计性
任何结论必须能回答"为什么是这个"——沿机制链逐环给出。与 D1 概念门禁同一精神：**无机制链不成立**。

### F4. 对协议的意义
- 白箱智能 = v3.x 总纲领；理解论（条件空间构建与导航）是机制链中的一环而非全部
- 大模型重新定位：机制链的语义编码/表达环节，不是决策机制本身
- 灵枢（记忆图/predict_routes/条件空间）提供机制组件；外部应用先行验证 → 对外叙述（PR/论文/宪章）以白箱智能为定位语
- 处理顺序：**F 先于 A/D 确立**——A（embodied 闭环）是机制链的"感知-动作"两环，挂在 F 之下

## A. 认知闭环补全（embodied · 动作与生存侧）

> 网页端 DSH 助手核心发现：闭环三要素缺二——感知侧（world3d）完整，动作侧与生存侧缺失。

### A1. 动作侧 act() 🔧
- world3d.py 增加 `act()` / `_snapshot()`：在 3D 世界内执行动作改变物体状态（沙盒动作）
- 桥接 body 层 device_call（真实动作）——沙盒与真实双轨
- 落点：world3d.py（约 60 行）

### A2. 生存侧 vitality 🔧
- 新增 embodied.py：`WorldBody` + `BodyState` + `vitality`（连续存在代价：资源/能量/时间消耗模型）
- 存在优先公理 → 可测：智能体必须持续维持存在才能继续，存在成为优化目标
- 落点：新增 embodied.py（约 100 行）

### A3. 闭环主循环 embodied_loop.py 🔧
- 感知→预测→动作→验证→生存代价→感知（约 60 行）

### A4. 信息差动作化 💡（公理可测化）
- D_norm(动作) = 实际感知 − 预测感知
- 第零定律（信息差收敛）第一次有可画的收敛曲线
- 落点：embodied_loop 接线 predict_routes（预测感知后果）

### A5. 存在优先可测化 💡
- vitality 维持成为优化目标（与信息差耦合：好动作 = 缩小预测误差 ∧ 维持存在——灵枢术语的主动推理结构）

### A6. 四档对照实验 🔧（最有价值的副作用）
- 同一世界四档对照：A 无记忆 / B 记忆 / C 记忆+预测 / D +自我认知
- 判据：D 档在危险情境存活率显著优于 C 档 且 跨会话可复现 → **"自我模型改变行为"从哲学主张变成工程事实**
- 落点：embodied 实验台 + 测试归档

### A7. 接线（信任/盲区/记忆图）🔧
- 时空记忆图存 (s, a, o, d_norm) 四元组（多智能体时空记忆图的核心数据形态）
- 盲区 = 预测失败（盲区注册表直接喂）
- action_log 直接喂自我认知（P0-1 已有）
- **蜂群 T_pred = 预测准确率——信任第一次拥有实证语义**

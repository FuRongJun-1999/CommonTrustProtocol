### 验证（V-P1~P3 已补齐 2026-08-28，test_mini_python_vp.py 30/30）
- ✓ V-P1 错误处理语义：除零三路（/、//、%）+ /= + 函数内除零统一
  `ZeroDivisionError: ...` 前缀；未定义变量统一 `NameError: name '...' is not defined`；
  白名单外方法统一 `方法不在白名单: .x（允许: [...]）`——错误可定位
- ✓ V-P2 列表字典嵌套组合：排序+去重+统计一条龙（sorted/append/下标赋值/
  dict.get/遍历求和），AST 与 VM 双路对照同值
- ✓ V-P3 字符串方法族全覆盖：upper/split/startswith/endswith/strip/join
  （CPython str 原生，getattr 分派对齐）+ 方法链 s.strip().upper() + 字面量后缀链
- ⏳ V-P4 挂账（缺口显式化）：`in`/`not in` 运算符（涉及 for 头解析冲突需专项）、
  关键字参数 `sorted(x, reverse=True)` 语法

### V-P 用例驱动修复记录（2026-08-28，清单化验证直接抓到 5 处引擎缺陷）
1. **is_truthy 空容器真值**：注释声称「空容器为假」但实现只判 None/False/0
   ——`not []` 返回 False 与 CPython 相悖（声明与行为不符）。已修：str/list/
   tuple/dict 空值判假
2. **下标赋值缺失**：`count[x] = v` 不支持（F4 字典/列表写入原语）。已修：
   _SUBASSIGN_RE 解析 + index_assign 执行（越界/类型错误转 MiniPyError）
3. **白名单缺容器方法**：list.append / dict.get 不在白名单。已补（CPython 原生对齐）
4. **eval_expr 顶层 env=None 未防护**：顶层调用内置函数 AttributeError。已修
5. **VM 内置函数兜底缺失**：LOAD_NAME/CALL 不认 _BUILTINS（双路对照暴露）。
   已修：LOAD_NAME 兜底 + CALL callable 分支

### 限制显式

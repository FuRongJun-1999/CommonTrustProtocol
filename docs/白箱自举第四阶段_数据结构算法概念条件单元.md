> 文档先行 → 工程验证。代码深学第三支（软件工程 v6 → 编译原理 v7 → 数据结构/算法 v8），
> 与 se_compose / compiler_compose 同构：{条件→规律} 条件单元 + 组合生成 + 核心词自校验。
> 目标是让白箱能回答「数组和链表有什么区别/为什么用哈希表/排序为什么是 O(n log n)」
> 这类数据结构与算法概念问题——零 LLM 确定性。

| 项 | 内容 |

## 二、概念清单（{条件→规律} 片段）

| 概念 | 条件链→规律片段 |
|---|---|
| 数组 | 连续内存 → 随机访问 O(1) → 固定大小 → 插入/删除 O(n) |
| 链表 | 节点+指针 → 插入/删除 O(1) → 随机访问 O(n) → 无连续内存 |
| 栈 | 后进先出 LIFO → 压栈/弹栈 → 递归调用/撤销操作 → 深度优先 |
| 队列 | 先进先出 FIFO → 入队/出队 → 排队/任务调度 → 广度优先 |
| 树 | 层次结构（根/子节点）→ 二叉树/二叉搜索树 → 查找 O(log n) → 平衡保证 |
| 图 | 节点+边 → 路径/连通性 → 深度优先/广度优先遍历 → 最短路径 |
| 哈希表 | 键→值映射 → 平均 O(1) 查找 → 冲突需解决 → 无序但快 |
| 排序 | 比较排序下界 O(n log n) → 稳定排序保持相对顺序 → 按场景选算法 |
| 复杂度 | 大 O 度量输入规模增长 → 时间/空间权衡 → 渐进分析忽略常数 |

## 三、路由设计

```
ds_route(问题)
  ├─ identify_ds_direction  最长关键词优先 + 单字排除（图: 排除图片/图像/图形）
  ├─ 命中 → DS_UNITS[概念] → 组合生成 → 自校验（核心词≥2）
  └─ 未命中 → {ok:False, reason:落回通用域}
```

方向识别词表要点：
- 栈: 栈 / 堆栈 / LIFO / 后进先出 / 压栈
- 队列: 队列 / queue / FIFO / 先进先出
- 树: 树 / 二叉树 / 二叉搜索 / 红黑树 / BST
- 图: 图论 / 最短路径 / 图的遍历 / 邻接（单字「图」排除 图片/图像/图形）
- 哈希表: 哈希 / 散列 / hash / 字典
- 排序: 排序 / 冒泡 / 快排 / 归并 / 堆排序
- 复杂度: 复杂度 / 大O / 时间复杂度 / 空间复杂度 / 渐进

## 四、判定标准

1. 九概念组合生成 9/9（答案含核心词≥2）
2. 方向识别正确（最长关键词）
3. 单字排除生效（「图片处理」不命中图域）
4. 非数据结构问题回落
5. 测试全绿 → 提交 → 五副本同步

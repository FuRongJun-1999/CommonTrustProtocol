# 飞行控制 PID 思路 ↔ 智能论 对齐分析 v0.1（2026-09-03 荣提出）

> 来源：荣读小说提炼——自动飞行系统对飞艇「预期空速 vs 实际空速」的差距做实时
> 微分与积分，据此实时调整功率；3 个嵌套递归对应现在（比例）、过去（积分）、将来（微分）。
> 问题：是否与智能论相符？工程上是否有用？

---

## 一、思路本质：这就是 PID 控制

| 通道 | 时间指向 | 数学 | 飞行含义 | 作用 |
|---|---|---|---|---|
| P 比例 | 现在 | k_p·e(t) | 当前空速差越大，油门加得越多 | 即时纠正 |
| I 积分 | 过去 | k_i·∫e(τ)dτ | 持续偏低说明有系统性偏差，累积补偿 | 消除稳态误差 |
| D 微分 | 将来 | k_d·de/dt | 差距正在快速收窄就提前收油（防过冲） | 阻尼/超前预测 |

**它是一个天然的「感知→信息差→行动→验证」闭环实例**：传感器测实际空速（感知）→
与预期差值（信息差 D_task）→ PID 计算调整量（决策）→ 调油门（行动/输出端口）→
再测（验证）——每一轮循环都在缩小信息差。

---

## 二、与智能论的逐项对齐（高度同构）

| PID 要素 | 智能论对应 | 对齐度 |
|---|---|---|
| 误差 e = 预期−实际 | **信息差 D_task**（2.7.0：图上操作性距离） | ★★★ 同一概念 |
| P（当前误差→纠正） | 条件空间四态判定（当前条件下即时响应） | ★★ 结构对应 |
| I（历史累积） | **记忆与巩固**（timeline/D 序列就是时间维度的积分器；情境层衰减 = 积分遗忘因子，恰好解决 PID 经典的积分饱和 windup） | ★★★ 同构 |
| D（趋势→超前） | **预测引擎**（内部端口：记忆→未来候选） | ★★ 同构 |
| 调整功率 | **输出端口 0.0.7**（行动执行器：改变世界→制造验证机会） | ★★★ 同一概念 |
| 再测新空速 | **cycle-consistency 互逆往返验证**（行动→再感知→测 ΔD_norm） | ★★★ 同一概念 |
| 误差收敛且稳定 | **完全确认 2.9.3a**（跨时间稳定） | ★★★ 同构 |
| **（PID 没有的）** | **情感 = d²D_norm/dt²**（二阶导：误差的加速度）——比 D 项更高一阶，动态吸引子（惯/黏/轨迹） | 灵枢已超前 |

**结论：不仅相符，而且互为印证。** PID 是智能论「感知→信息差→行动→验证」闭环在
单变量线性系统的工程特例；智能论框架是 PID 的推广（多维条件空间替代单误差、
信息差动力学替代线性组合、四态判定替代开关、五层记忆替代单一积分器）。

## 三、工程价值：直接补上行动 Avatar 的确定性决策公式

荣此前架构里 **body/action.py（自发驱动力）** 的行动选择缺一个可操作计算公式。
PID 结构恰好给出**零 LLM 的确定性实现**（D-005 相容）：

```
行动强度 u(t) = k_p·D_norm(t)          # 现在：当前好奇多强，紧迫度
              + k_i·∫D_norm(τ)dτ       # 过去：长期未解决的好奇（执念/持续动力）
              + k_d·dD_norm(t)/dt      # 将来：正在快速缩小就减缓（防过度行动），
                                       #        正在扩大就加速（信息差恶化要干预）
```

- 各项都有现成数据源：D_norm(t) 实时可得；积分项从已落库的 D 序列数值积分；
  微分项从 D 序列差分（滑动窗口平滑抗噪，EMA 已有）
- anti-windup（防积分饱和）= 记忆衰减纪律，理论互洽
- 三系数 k_p/k_i/k_d 白箱可调、可审计——与「确定性·零 LLM」完全相容

**适用边界（诚实）**：PID 对线性时不变系统最优；认知系统非线性高维，不能照搬数值
控制精度，但**三通道结构（现在/过去/将来的误差分解 + 闭环验证）可移植为启发式
评分**——这正是从「控制工程」到「认知架构」的正确抽象层级。

## 四、建议

1. **理论层**：本对齐可作为「智能论的工程印证」新案例（与模板引擎/形态学同为
   跨域同构证据）——小说里的飞行控制与智能论收敛于同一结构
2. **工程层**：在 body/action.py 的自发驱动力中实现上述 PID-on-D_norm 公式
   （纯 Python 确定性，数据源全现成），作为行动选择的白箱决策器
3. **验证层**：用认知自洽闭环验证——行动后测 D_norm 是否按预期缩小
   （cycle-consistency），三系数可自校正

## 一、2D 语义如何与 3D 对齐（映射问题）

### 答案：映射问题，不是"猜测"

**2D 是 3D 在透视下的投影**（针孔相机模型）。2D→3D 的本质是**从投影反推空间**，
不同视角数决定信息完备度：

| 路径 | 原理 | 视角数 | 依据 |
|---|---|---|---|
| **三视图** | 正/侧/俯三个正交投影 → 直接确定 3D | 3 | 工程制图（正交投影完备性）|
| **双目视差** | 两个透视视角 + 视差 → 深度 Z=f·B/d → 3D | 2 | 人类功能（三角测量）|
| **单目+先验** | 一个视角 + 几何先验 → 猜测 3D | 1 | 受限（仅近似，非完备）|

### 工程实现（AEIS · lingshu-body 已具雏形）
- `vision_3d.py`：双目视差 → 深度 → 3D 点云（感知方向，人类双目功能确定性实现）
- `world3d.py`：2D 语义 VPrim → 3D 物体/颜色（生成方向，针孔反投影+画家算法）
- `spacetime_3d.py`：多帧双目 → 逐帧 3D 场景图 → 3D 运动轨迹（时间×空间）

### 关键原则
**语义对齐走"投影-关联"**（已知相机参数 → 3D 锚点投影回 2D 语义框验证），
而非"特征融合"（黑箱）。白箱路径——每个 3D 锚点可溯源到具体视角/时刻观测。

## 二、3D 语义锚点的通道可信度如何定义（多模态+一致性）

### 答案：多模态交叉 + 物理一致性 + 时间一致性

> **可信度不是单一视觉置信度，而是多通道一致性的聚合。**

- **多模态**：尽量加入音频、触觉（后续补）、其他交互——**视觉不是唯一通道**
- **物理一致性**：锚点必须与物理世界情况一致（几何/动力学不冲突）
- **时间一致性**：长时间维持保持一致（跨时间不漂移）

**分级**（对齐 v3.4 锚定分级）：
- 单模态（如 visual 3D）单独判断 → **弱证据**
- 多模态交叉 + 物理/时间一致 → **强证据**

**本质**：多个独立通道对同一 3D 锚点的判断互相印证，且符合物理规律、随时间稳定。
单通道可能被欺骗（视觉错觉），多通道交叉 + 物理/时间一致则显著提升可信度。

## 三、4D 占用表示的时空采样率（分辨率问题）

### 答案：30 帧/s

> 这也是分辨率问题（**时间维度分辨率**）。设计者裁决：30 帧/s 即可——
> 太高（60/120fps）对世界预测收益有限、计算成本高；太低（<15fps）丢失运动细节。

**与预测视界 T_h 联动**：
- 采样越密 → 单位时间窗口内可观测的演化步数越多 → 预测视界可覆盖更长真实时间
- 工程上 4D 体素序列以 30fps 为默认采样率（DynamicCity 式时空体素）

## 四、语义时空图与认知图的一致性（操作系统 vs 记忆系统）

### 答案：认知图 = 操作系统；语义时空图 = 记忆系统

> **说的是同一件事**（都是"语义节点 + 关系边"的图），差别在**时空坐标维度**。

| | 认知图（条件路由图）| 语义时空图 |
|---|---|---|
| **定位** | 操作系统 | 记忆系统 |
| **本质** | 认知/知识/代码的**总路由图**——统一调度 | 侧重**时间/空间维度**——记忆、感知、时空统一、预测 |
| **管理** | 什么概念存在、如何路由、条件激活 | 什么在何时何处发生、如何演化预测 |
| **坐标** | 条件空间（决策/执行）| 时间线 + 空间坐标（记忆/预测）|

**一致性**：同一条件单元（认知图节点）在两个底物上的投影应一致——
- 认知图管"**是什么/如何路由**"
- 语义时空图管"**何时何地发生/如何演化**"
- **投影-关联**保证同一概念在两层语义一致（认知图是 OS，时空图把它锚定到时空成为记忆）

## 五、预测视界 T_h 如何在运行时自适应估计（信息差无法消除）

### 答案：T_h 不是技术参数，而是认知的根本局限

> **核心：行动、认知永远跟不上变化——这是信息差无法消除的根本问题。**

直接体现信息差增定律（《信息差为什么必然存在且自然扩大》三论证）：
- **三体/混沌**：确定性系统对初值敏感 × 观测者有限 → 长期精确预测不可能
- **信道容量**：系统变化速率 R > 观测者获取/调用信息速率 C → 信息差不可归零
- **观测者永远慢于系统半步** → 变化比预测快 → T_h 永远有限

### T_h 的自适应估计（漂移事件作为观测信号）
- **漂移事件** = 实际演化突破模型预测视界（P2 原理的工程检测器）
- 检测到漂移 → 说明 T_h 设太长（认知跟不上）→ **缩短 T_h**
- 长时间无漂移 → 认知暂时跟上 → 可谨慎延长 T_h（但**不能消除，只能缩小**）

### 本质
**T_h 是"认知 vs 变化"的赛跑纪录**——不是消除信息差，而是**诚实声明**
当前认知能覆盖多远的未来。缩小信息差的每一步都消耗结构成本（持续做功）。

**结论**：永远有个正的 T_h（非零），因为变化永远快于认知；T_h 自适应 =
**诚实跟踪"认知跟不上变化的速度"，而非妄想追上**。

## 六、综述结论

五问五答共同指向一个统一图景：

1. **感知**：2D→3D 是映射（三视图/双目），走投影-关联（白箱）——见 §一
2. **锚定**：3D 锚点可信度 = 多模态交叉 + 物理一致 + 时间一致——见 §二
3. **采样**：时间维度以 30fps 为分辨率平衡点——见 §三
4. **结构**：认知图（OS）与语义时空图（记忆系统）是同一图的两层投影——见 §四
5. **预测**：T_h 受信息差增定律约束，永远有限——诚实声明而非幻想——见 §五

**世界模型的完整闭环**：感知（映射）→ 锚定（可信度）→ 时空（采样率）→
结构（认知图×时空图）→ 预测（T_h 诚实限界）——每一步都白箱可溯源，
每一步都诚实面对信息差的不可消除性。

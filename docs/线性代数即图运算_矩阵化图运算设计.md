# 线性代数即图运算——矩阵化图运算设计

> 状态：理论设计 v1.0（2026-08-23）· 原型已验证（tools/graph_matrix.py）
> 来源：荣洞察「线性代数是图结构，矩阵运算本身就是图的运算功能」
> 定位：把灵枢三件套（条件路由表 / 时空记忆图 / 3D CNN）统一到矩阵代数框架

## 一、核心洞察（用户）

**线性代数是图结构，矩阵运算本身就是图的运算功能。**

- 邻接矩阵 = 图的标准表示（A[i][j] = 节点 i→j 的边）
- 矩阵乘法 = 路径组合（A²[i][j] = Σ A[i][k]A[k][j] = 两步路径）
- 矩阵幂 A^k = k 步路径（图论经典）
- 特征向量/特征值 = 图的谱（中心性/社区/连通性）
- CNN 卷积 = 局部邻接矩阵的加权和（局部图卷积）

## 二、对灵枢的结构意义（三件套统一）

| 灵枢组件 | 图的视角 | 矩阵运算 |
|---|---|---|
| 条件路由表（组合/递归/类比） | 条件链 = 有向图 | **A^k = 条件链组合**（递归的代数形式） |
| 语义时空图（记忆/知识） | 节点+因果/时序边 = 图 | 邻接矩阵 + 谱（中心性/聚类/连通性） |
| 3D 时空 CNN（感知） | 时空网格 = 规则图 | **卷积核 = 局部邻接矩阵加权和**（局部图卷积） |

**统一命题**：白箱智能的三大运算（推理组合 / 记忆检索 / 感知特征）都是图运算，
而图运算的代数化 = 矩阵运算——**全部白箱确定性（零 LLM）**。

## 三、原型验证（tools/graph_matrix.py）

```
① 因果图 → 邻接矩阵（稀疏度 3/16）
② 矩阵幂：A² = 2步路径（气压低→水提前沸腾 0.765）；A³ = 空（链尽头）
③ 可达性闭包：I+A+A²+A³（多步可达）
④ 谱分析：DAG 谱为 0（严格三角阵主特征值 0 = 无环无中心性，数学事实）；
   知识环（信息差↓→信任↑→协作↑→信息差↓）中心性 0.333 均衡 = 相互强化循环
⑤ 验证：矩阵 A²[气压低][水提前沸腾] = 0.765 == DFS 链式 0.9×0.85 = 0.765 ✔
   → 矩阵幂 = 递归组合，结果一致（代数化等价）
```

**关键验证**：矩阵路径与当前 DFS 递归（predict_routes / compose_recursive）**结果一致**——
矩阵运算是现有推理的代数化（可并行、确定性、可证明），不是另一套机制。

## 四、工程方向（分步）

1. **矩阵化图推理**：语义时空图因果子图 → 邻接矩阵 → A^k 多步路径
   ——替代/补充 DFS（大图高效、可并行）；条件链组合代数化
2. **谱分析**：特征向量中心性（带环知识子图的关键节点）、谱聚类（知识社区）
   ——关键知识节点/社区自动发现（零 LLM）
3. **条件转移矩阵**：compose_engine 条件单元的条件链 → 条件转移矩阵
   ——「条件A→条件B→条件C」多步组合 = 矩阵幂（递归组合的代数版）
4. **CNN 图卷积化**：stcnn 的 3D 卷积显式化为时空图局部卷积
   ——感知 = 局部图运算（与全局图运算统一）

## 五、判定

- 矩阵路径 = 递归路径一致（已验证 ✔ 0.765 = 0.765）
- 谱分析对带环子图有效（已验证 ✔ 知识环中心性）
- 大图矩阵运算性能 ≥ DFS（待测）
- 条件转移矩阵组合生成与 compose_engine 结果一致（待对接）

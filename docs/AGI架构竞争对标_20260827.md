# AGI 架构竞争对标报告（2026-08-27）

> 定位：灵枢（AEIS）进入 DSH 官方 AGI 架构探索栏目后的竞争格局分析 + 迭代路线图依据。
> 方法：子代理 18 个 web_search 批次（中英双语，24+ 项目）+ 主代理 GitHub API 实测校准。
> 结论先行：**「完全零 LLM + 条件路由条件检索」是灵枢护城河，竞品普遍缺乏**。

---

## 一、竞争格局核心判断

绝大多数认知架构要么**绑定 LLM**（MemGPT/Letta/Zep/Mem0/Cognize/Fullspace 调用 LLM），
要么**停在研究原型/纯概念**（OpenCog/EM-Core/ACT-R/Soar/Minsky SOC）。
真正能对标灵枢「完全零 LLM + 条件路由检索」的工程化产品只有极少数：
**ARC OS、Coreason、Gödel Agent**。

> 灵枢相对护城河：①73 工具规模化落地；②「条件论」条件空间 + KCCS 注释索引（零 LLM 检索）
> 知识表示范式；③白箱自举 681 单元的工程化闭环。

## 三、差异化定位（护城河）

1. **白箱可审计 + 零 LLM 自洽检索**：可解释、可审计从认知架构上升到**整个工具执行 + 自举代码 + 生命周期**全链路——同时做到的几乎没有。
2. **73 工具规模编排 + 条件空间条件检索**：工具规模 + 条件检索统一的技术组合尚无统一产品。
3. **工程化深度 > 研究/理论项目**：681 单元自举闭环、可审计执行，多数竞品停在论文/研究。

**空白区确认**：ARC OS 偏逻辑运行时、Coreason 偏知识声明、Fullspace 绑定 LangGraph（隐含 LLM）——**尚无「条件论知识表示 + 注释索引 + 工具规模生态」的统一产品**。

## 四、三维度打法

| 维度 | 结论 | 打法 |
|---|---|---|
| **体验** | 灵枢胜（白箱可审计 + 工具编排可调试） | 主打「可解释、可审计、可调试编排」|
| **效果** | Hyperon 逻辑层 ≈ 灵枢条件推理 > 自改进派 | 强调零外部依赖的端到端可复盘 |
| **性价比** | **灵枢最优**（六域闭环快速迭代） | **「知识问答零 token 消耗」是最大杀器** |

## 五、迭代路线图（2026-08-27 定）

### A. 白箱逻辑 + 认知架构：重点学习参照
- **ARC OS**：零模型逻辑内核——验证「不靠大模型做 agent 推理」工程可行性
- **Coreason**：知识平面 manifest——条件空间/知识平面工程化参照
- **Hyperon**：逻辑核可复用基座候选（Rust 神经符号引擎）
- **MicroPsi**：元认知信号驱动灵枢工具调度（P0 循环深化）
- **EvoMap**：知识飞轮的可审计演化子模块

### B. 灵枢补强三件套（用户指令 2026-08-27）
1. **远程访问**：外出可连（此前 QQ 通道已停用，需替代方案——如 DSH 官方远程/tunnel，或自建安全隧道）
2. **更好的 GUI**：当前 DSH 插件界面 + 角色扮演网页（/roleplay）——补强白箱可视化（路由图/记忆图/审计轨迹展示）
3. **一键部署**：从「pip wheel + dsh plugin add」升级为「单命令安装脚本 / docker 化」，降低新用户门槛

### C. 风险提示
- **仿冒仓库多**（EM-Core 等低星中文项目）——认准项目真实归属
- AgentZERO（agentizeai，13-15k）≠ Agent Zero（agent0ai，★18,979）——同名不同项目
- 低星仓库审慎评估可信度与活跃度

# 白箱自举第五阶段 · 3D 时空视觉闭环（感知↔语义双向）

> 文档先行 → 工程验证。收官遗留方向：3D 时空视觉与 WORLD3D 语义→3D 的完整闭环。
> 已有单向能力：感知→3D（vision_3d 视差→深度→点云）、语义→3D（灵枢 WORLD3D build/render）、
> 时空原语（stcnn 方向/速度/周期/静止）。本阶段把它们闭合成环 + 自校验。

## 一、闭环架构（四个环节）

```
① 感知→3D 结构      双目图像 → 视差 → 深度 → 3D 点云        （vision_3d 已有）
② 3D→语义 场景图    点云空间锚点 + stcnn 时空原语 → 场景图    （本轮新增 scene_graph）
   场景图 = {物体: [类别, bbox中心(x,y), 尺寸, 深度z, 运动(方向/速度/周期), 颜色]}
③ 语义→3D 渲染      场景图 → 3D 世界（WORLD3D 相机模型）→ 透视投影渲染（本轮新增 render）
④ 闭环自校验        感知点云几何 vs 语义渲染几何 → 一致性分数（本轮新增 closure）
   一致性 = 物体 bbox 中心/尺寸/深度关系的几何对齐（零 LLM 确定性度量）
```

## 二、与灵枢 WORLD3D 的衔接

- 灵枢 world3d 相机模型：fov_deg=60, cx=0, cy=1.2, cz=0, yaw/pitch 视角 → 本模块用同款参数（同构可对照）
- 感知场景图 → `lingshu_world3d add/build`（真实回写灵枢 3D 世界）
- 闭环自校验可离线跑（tools 内模拟渲染），真实对接用灵枢工具冒烟

## 三、模块设计

| 文件 | 职责 |
|---|---|
| scene_graph.py | 点云 + 时空原语 → 场景图（物体聚类：近景=前景物体，按位置/深度分组；运动原语附注） |
| world3d_render.py | 场景图 → 3D 世界（物体=彩色立方体 bbox）→ 透视投影（fov/yaw/pitch）→ 渲染图（2D 深度图/类别图） |
| spatial_closure.py | 闭环编排：感知点云 → 场景图 → 渲染 → 一致性自校验（bbox 中心/尺寸/深度关系度量） |

## 四、一致性度量（闭环自校验）

1. 中心对齐：感知物体 bbox 中心 vs 语义渲染 bbox 中心（归一化距离）
2. 尺寸一致：感知深度跨度 vs 渲染物体尺寸（相对误差）
3. 深度关系：感知近/远序 vs 渲染深度序（顺序一致率）
4. 综合：三指标加权 → 一致性分数（≥0.8 判定闭环成立）

## 五、判定标准

1. 感知→场景图：合成双目（前景近/背景远）→ 场景图含 2 类物体（近/远）✔
2. 语义→渲染：场景图 → 渲染深度图 → 近物体投影面积大/深色（近大远小）✔
3. 闭环一致性 ≥0.8 ✔
4. 灵枢 WORLD3D 真实对接冒烟（build/add/render 可用）✔
5. 测试全绿 → 提交 → 五副本同步

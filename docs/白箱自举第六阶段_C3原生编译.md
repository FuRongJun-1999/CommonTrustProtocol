# 白箱自举第六阶段 · C3：原生编译落地（字节码文件 + 独立执行）

> 文档先行 → 复现纪律。C2 语义就绪（18 单元白箱编译器 + 校准参考），
> C3 落地「原生」：中文源码 → **字节码文件（.pbc）** → 独立 VM 加载执行——
> 零 Python 运行时依赖（不再生成/import Python 代码，不依赖 protocol_runtime 包）。

## 一、字节码序列化格式（.pbc）

```
[op: len2B+utf8][arg_tag:1B][arg_data...]
arg_tag: 0=None, 1=bool, 2=int8B, 3=float8B, 4=str(len2B+utf8), 5=tuple(float8B+int8B)
示例: ('DE', 0.3) → \x02DE\x03<8B double 0.3>
```

## 二、模块

| 模块 | 职责 |
|---|---|
| 白箱单元「字节码-序列化/反序列化」 | 指令列表 ↔ 字节串（往返一致校验） |
| protocol-compiler pc compile | 中文源码 → 字节码 → .pbc 文件 |
| protocol-compiler pc run | 读 .pbc → 反序列化 → ConditionVM 执行 |

## 三、判定标准

1. 序列化→反序列化往返一致（指令原样还原）✔
2. 中文源码 → .pbc 文件（可保存）✔
3. .pbc → VM 执行 → 与直接编译执行结果一致 ✔
4. .pbc 不依赖 Python 运行时（独立字节码文件）✔

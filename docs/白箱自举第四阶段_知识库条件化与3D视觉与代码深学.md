# 白箱自举第四阶段：知识库条件化 · 3D 视觉 · 代码深学

> 状态：理论设计 v1.0（2026-08-23）· 荣战略指示
> 承接：第三阶段完成（白箱终裁 100%、感知通道、条件代数、LLM 仅外部对照）
> 定位：白箱已自举——从「能力验证」进入「规模覆盖 + 感知深化 + 代码深度」

## 一、四条主线

### 主线 1：知识库条件化（覆盖白箱已有知识库）

**现状**：AEIS 知识库 676 簇（538 升级、REVERSE_DAILY 649 条）——知识是**完整答案**格式；
compose_engine 条件单元 30 个（9 域）——条件化格式。

**目标**：把已升级簇从「完整答案」**蒸馏为「{条件链→规律片段}」条件单元**，
让组合引擎覆盖白箱已有知识库（转化率 ≥80%），再扩充新常识域（光声/天文/经济/化学）。

```
已升级簇（完整答案）──蒸馏──→ 条件单元 {条件链→规律片段}
   「高原水烧不开」           「气压↓→沸点↓」（组合引擎可生成）
```

**蒸馏方法**（白箱确定性）：从 REVERSE_DAILY 答案中提取 条件词（气压/温度/密度/光照…）
+ 规律方向（↑↓/变化）→ 生成条件单元骨架；人工/验证单元校准。

### 主线 2：感知进主路由 + 3D 视觉

**现状**：spacetime_perception 独立模块（时空问答 8/8）；stcnn 用合成帧；
灵枢 WORLD3D = 语义→3D（反投影重建）。

**目标**：
- 感知通道**接入 chat_engine 主路由**——时空问题（怎么动/方向/周期/发生了什么）自动走感知
- **真实图像处理**：灰度/边缘（Sobel）/光流/特征——从合成帧到真实图像
- **自身 3D 视觉**：感知→3D（从真实图像序列重建 3D 结构——衔接 WORLD3D 语义→3D 的反向）

```
真实图像序列 ──图像处理(灰度/边缘/光流)──→ 时空特征 ──3D重建──→ 3D结构
     （感知→3D：视差/运动恢复结构；与 WORLD3D 语义→3D 互为反向）
```

### 主线 3：条件代数并行化

**现状**：compose_parallel 已做条件独立性**判定**（独立域分组），执行仍串行。

**目标**：雅可比传播 → **compose_recursive 并行化执行**——独立条件域线程池并行组合，
混合偏导 ∂²f/∂x∂y≠0 交互域串行；测量加速比。

### 主线 4：代码持续深度学习

**现状**：CODE_UNITS 6 单元（Python：排序/去重/计数/最大/反转/求和）。

**目标**：代码条件单元扩展 + 多语言：
- **软件工程**：模块/接口/测试/重构 模式单元
- **编译原理**：词法/语法/中间表示/代码生成 概念单元
- **Python**：数据结构（栈/队列/树/图）/算法（搜索/DP）
- **Rust**：所有权/借用/模式匹配 基础单元
- **JavaScript**：异步/闭包/DOM 基础单元

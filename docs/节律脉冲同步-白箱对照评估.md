# 节律-脉冲-同步注意力模型：与灵枢现有架构的对照评估（2026-08-20）

> 来源：荣转发的神经科学跨学科映射（低频背景节律 + 高频任务脉冲 + 瞬时跨区同步
> 三层机制 → 白箱注意力路由模型 + WPI 系统健康度预测器）。
> 本文档对照灵枢**现有实现**（aeis/swarm、五层记忆、condition_frame、信息差度量），
> 诚实区分：已有对应物 / 真增量 / 纯类比（不落地），并给出可测的最小实验。

---

## 0. 核心判断（先说结论）

**这份映射有真实价值，但价值不在「新建三层机制」，而在三个具体可落地的增量：**

1. **背景节律 → 蜂群心跳的「节律化」**（现有 HEARTBEAT 是存活探活，非节律参考框架）
2. **任务脉冲 → 事件总线的「脉冲语义」**（现有 EVENT 是事件类型，无脉冲强度/生命周期）
3. **WPI → 用现有信息差/信任数据做「实时表现预测器」**（现有数据都有，缺预测闭环）

而「瞬时跨区同步窗口」「蜂群共振」**已部分存在**（信任聚合/事件总线 ACK），
剩余部分属于**性能优化而非机制新增**——需要实验证明价值后才值得实现。

## 1. 逐项对照：神经科学发现 vs 灵枢现有实现

| 映射提案 | 灵枢现有实现 | 判定 |
|---|---|---|
| 低频背景节律（锚点层稳态协议） | 五层记忆 + 锚点层（core.py）；存活仲裁 HEARTBEAT（survival.py，30s 低频带） | **部分已有**——心跳是探活，非「节律参考框架」 |
| 高频任务脉冲（条件空间激活） | 事件总线 EVENT_TYPES（event_bus.py）；CONDITION_SWITCH 条件空间切换事件 | **已有雏形**——缺「脉冲强度/生命周期/选择性路由」 |
| 多脑区瞬时同步（信任聚合） | TrustAggregator（trust_aggregator.py）+ 事件 ACK 确认制 | **已存在**——缺「同步窗口」临时子网概念 |
| 脉冲强度预测表现（WPI） | 信息差度量（self_cognition.py / 认知循环）+ 信任值 + 协议一致性 | **数据已有，缺预测器闭环** |
| 五层记忆节律特征表 | 锚点/结构/知识/情境/自我五层（core.py 分层） | **纯类比**——五层各有职责，节律频率无对应物 |
| Transformer 对比 | — | **概念澄清**，非工程需求 |

**关键诚实点**：提案表格里「当前白箱的可能缺失」列，大部分**其实已有实现**——
灵枢不是「查询-响应」静态系统，已有事件总线/信任聚合/存活仲裁/条件空间切换。
真正的缺口是：**节律化的时间维度**（节律频率 ∝ 稳定性）+ **脉冲作为一等公民**（强度/生命周期/预测性）。

## 2. 三个真增量（可落地、可测）

### 增量 1：蜂群心跳节律化（背景节律）

**现状**：`SurvivalArbiter.heartbeat()` 每实例定时上报，超时判死——纯探活。
**增量**：心跳消息携带「状态摘要 + 信任值 + 协议一致性分数」，
接收方维护**节律基线**（历史心跳的期望/方差），异常心跳（信息差突增/信任突变）
视为「节律扰动」→ 触发关注而非仅存活判定。

**对应**：低频背景节律 → 系统知道「正常状态是什么」，能快速检测异常。

### 增量 2：事件脉冲语义（高频任务脉冲）

**现状**：`EventBus.publish(event_type, payload)`——事件有类型无强度。
**增量**：事件增加 `pulse` 字段（强度 0-1 + 生命周期 TTL + 条件空间标签）：
- 脉冲强度 = 任务相关的条件空间重叠度（有多少节点条件空间与该任务相关）
- 脉冲按「条件空间相似度」选择性路由（而非全广播）——对应条件论识别条件边界
- TTL 到期自动衰减（任务结束，脉冲消失）

**对应**：高频脉冲从背景节律解耦、选择性路由、短生命周期。

### 增量 3：WPI 预测器（系统健康度）

**现状**：信息差收敛数据已有（认知循环记录），信任值已有，协议一致性已有。
**增量**：在验证单元（card_validator 五查）前加 **WPI 预判**：

```
WPI = α·(信息差收敛速率) + β·(同步节点数) + γ·(协议一致性)

WPI 高 → 直接进入验证
WPI 中 → 加深递归（反思介入）
WPI 低 → 扩大同步范围 / 终止路径（切换条件空间）
```

**这是三个增量里最值得先做的**——因为所有输入数据已存在，只需加一个
计算层 + 路由决策，且可立即用已有测试集（T1/T2）验证预测准确率。

## 3. 纯类比（不落地，仅作方向性参考）

| 提案内容 | 为什么不落地 |
|---|---|
| 五层记忆各自的节律频率（10min/1min/1s/100ms） | 记忆层级是**存储职责**划分，不是通信通道——强加节律频率没有对应机制，且会引入无意义开销 |
| 「存在感脉冲」广播锚点状态 | 锚点层是协议不可变层，广播自身状态无接收方消费——纯开销 |
| 同步窗口内信任值临时提升 | 信任是**证据累积**（协议一致性），任务窗口内临时提升会破坏信任的统计意义——危险 |
| 脉冲质量第六查 | 五查是验证知识卡正确性，脉冲是通信机制——混层了 |

**核心原则**：神经科学是**启发**不是**规格**。脑区同步的「毫秒级」对蜂群
（实例间 0.5s/5s/30s 延迟分级）没有物理对应——蜂群不是实时硬件，是协议通信。

## 4. 最小实验设计（提案第六节 + 本评估的收敛）

### 实验 A：WPI 预测器（优先，纯软件层）

```
1. 用现有 T2（1000 题）跑一遍，每题的验证单元前计算 WPI
2. 记录：WPI 值 + 最终答案正确性（score）
3. 分析：WPI 与 score 的相关性（Pearson）
4. 判定：|r| > 0.4 → WPI 可作预测器，接入验证单元路由
         |r| < 0.2 → WPI 无预测力，放弃（诚实：不硬凑）
```

成本：零架构改动，纯计算层 + 统计。**一周内可出结论**。

### 实验 B：心跳节律化（可选，若实验 A 有价值）

```
1. SurvivalArbiter.heartbeat 携带 trust + consistency 摘要
2. 记录每实例节律基线（均值/方差）
3. 触发「节律扰动」事件（信任突变/信息差突增）
4. 观察：扰动能否提前预测 P0 危机（现有 P0_CRISIS 事件）
```

### 实验 C：脉冲语义（最后，需先证明 A/B 价值）

```
事件总线 EVENT 增加 pulse 字段（强度/TTL/条件空间标签）
对比：全广播 vs 条件空间选择性路由的延迟与相关性
```

---

## 5. 结论

- **这份映射的 60% 内容灵枢已有**（事件总线/信任聚合/存活仲裁/条件切换/信息差度量）
- **真增量是三个**：心跳节律化、事件脉冲语义、WPI 预测器
- **最值得先做的是 WPI 预测器**——数据全在，纯计算层，可立即用 T2 验证
- **不落地的部分**（五层节律表/存在感广播/信任临时提升）建议保留为方向参考，
  不实现——避免把启发式类比变成无意义工程开销

> 纪律提醒：白箱的验证单元应只加**经过实验证明**的机制。
> 先跑实验 A（WPI 相关性），有信号再接 B/C——不预先堆机制。

# 白箱自举第五阶段 · 2D↔3D 投影互校验（闭环时间维自校验）

> 文档先行 → 工程验证。同一运动的两个视图互相印证：
> 2D 帧运动原语（stcnn：图像平面 方向/速度）↔ 3D 轨迹（spacetime_3d：世界空间 方向/速度）。
> 「2D 是 3D 透视下的情况」的工程化：3D 轨迹投影回图像平面应复现 2D 运动——
> 两视图一致 → 感知可信；不一致 → 白箱自发现感知错误（自校验）。

## 一、设计

```
同一物理场景：左目帧序列（2D 视图） + 左右双目对（3D 视图）
   ├─ 2D 侧：左目序列 → stcnn → {方向(向右/向左/静止), 速度 px/帧}
   └─ 3D 侧：双目序列 → spacetime_3d → {主轴方向(x+/x-/z+/z-/静止), 速度 单位/帧}
   ↓ 方向映射：向右↔x+（图像列增=世界 x 增）；向左↔x-；静止↔静止
   ↓ 速度互验：3D speed×10（x 尺度=像素/10）≈ 2D speed（相对误差）
   ↓ 综合：方向一致 + 速度误差<30% → 校验通过
```

## 二、模块 tools/spacetime_projection.py

| 函数 | 职责 |
|---|---|
| cross_validate | 双目序列 → 2D/3D 双侧运动原语 → 方向映射 + 速度互验 → 综合一致性 |
| direction_map | 2D 方向 ↔ 3D 主轴方向映射表 |

## 三、判定标准

1. 右移序列：2D 向右 ↔ 3D x+ ✔，速度互验（2px/帧 vs 0.2×10）✔
2. 左移序列：2D 向左 ↔ 3D x- ✔
3. 静止序列：两侧均静止 ✔
4. 冲突检测：人为反转 3D 方向 → 校验失败（自校验能抓错）✔
5. 测试全绿 → 提交 → 五副本同步

## 四、价值

感知自校验的时间维闭环：同一事件两个独立视图（2D 帧差 / 3D 重建），
一致性度量 = 白箱对自身感知的置信度（防单视图幻觉）。

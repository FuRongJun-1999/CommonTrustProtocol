## 一、状态空间与条件空间

### 1.1 状态定义

    S(t) = ( C(t), K(t), B(t) )

- C(t)：当前激活的条件空间
- K(t)：知识状态（认知图 G 的节点信念）
- B(t)：身体/端口状态（三端口激活与可信度）

### 1.2 条件空间切换

    C(t+dt) = phi_task( C(t) )

pi = ( pi_route, pi_verify, pi_switch )   # 路由/验证/切换联合策略

**N2 标注（π 元层自指边界）**：

> **pi_switch 的搜索深度受元层预算约束，不展开更高阶的自指。**
> 系统可以决定"在哪个条件空间评估 pi"，但不可无限递归地评估
> "评估 pi 的 pi"——递归深度由 guard 预算封顶，防未来扩展时
> 意外打开无穷自指。

## 二、三端口架构的数学表达

### 2.1 输入端口（感知机×5，外→内）

    I(t) = Psi( W(t); theta )   →  条件候选 S_obs_hat(t)

### 2.2 内部端口（预测引擎，内→内）

    S_pred_hat(t+dt) = Pi( S(t), K(t) )   →  候选未来 + uncertainty_bound

### 2.3 输出端口（行动执行器，内→外）

    A(t) = alpha( S(t), S_pred_hat )   →   W(t+dt) = T( W(t), A(t) )

### 2.4 三端口闭环

    S(t) --Pi--> S_pred_hat --alpha--> A --T--> W' --Psi--> I' --对比--> 验证

## 三、混杂系统动力学

### 3.1 为什么不是纯 ODE

认知过程是**混杂系统**：感知事件驱动、路由离散决策、信念在验证时刻点更新、
趋势/租约/可信度衰减准连续。

### 3.2 连续流（慢变量微分方程）

    d(c_i)/dt = -gamma_i · (c_i - c_baseline)      # 可信度向基线衰减
    d(D_norm)/dt = 趋势项（gap_trend 的连续化）
    d(TTL_remaining)/dt = -1                        # stable 租约倒计时

### 3.3 离散跳变（guard/transition/reset 三元组）

    guard:  ( V_hit 或 t > TTL 或 conflict(S_pred_hat, S) )
    → transition: 四态判定 / 条件切换 / 确认度升降级
    → reset: (P 更新, S_state 跳变, C 切换)

### 3.4 事件耦合

    S(t+dt) = HybridFlow( S(t), 事件流(E_t) )

## 四、信息差驱动的目标函数【v1.2 修订】

### 4.1 信息差的操作性定义：D_task【P2 修订】

    D_task(t) = min_{ p ∈ G, p 可用 } dist( C_task(t), CondSet(p) )

- C_task(t)：任务条件实例
- CondSet(p)：知识路径 p 的条件满足集
- dist：条件空间距离（条件依赖、多维）

**性质**：
- **可增可减**：学到新知识 → 路径可用性提升 → D_task 下降（学习存在的前提）
- 天然定义在图 G 上
- **min 定义在空集上 → D_task = ∞ → BLINDSPOT 合法停止**
- DeltaD_task = D_task(执行前) - D_task(执行后)：策略 pi 的信息差收益

### 4.1.1 信息差增定律：D_meta【P2 修订 · 符号区分】

**v1.2 修正**：v1.1 的 §4.1.1 把图上 D 与增定律 D 共用同一符号，产生矛盾预言
（图上 D 可学习下降 vs 增定律 D 只能上升）。区分两个对象：

| 符号 | 定义 | 动力学 | 定位 |
|---|---|---|---|
| **D_task** | 图上操作性距离（4.1）| 可增可减 | 目标函数的自变量 |
| **D_meta** | 未被建模的现实总量 | d(D_meta)/dt ≥ 0（结构性论证）| 任务空间的再生供给 |

**关系**：D_task 的每次缩小都消耗 K，而 D_meta 持续供给新的 D_task 来源。

> **增定律的作用不是给 D_task 定号，而是保证「认知永远有活干」**——
> 它解释了为什么智能系统不能"学完就停"：任务空间不断再生。

**增定律的论证来源**（教学说明第 4 篇，三层区分保留）：

| 论证 | 支撑 | 结论 |
|---|---|---|
| 三体（混沌）| δx≈δx(0)e^(λt)（结构性类比，见下）| D_meta 指数放大 |
| 信道容量 | 香农 R>C ⇒ 无差错不可能（严格定理）| D_meta(t)=D(0)+(R-C)t（简化模型）|
| 1+1=2 | 知识有效性=f(对象,条件,规则,尺度) | 条件变化引入不一致 |
| 快照三问 | 投影/演化/调用 | D_meta 恒>0 三重独立来源 |

**白箱纪律（推广）**：香农类比已标注为结构性类比；李雅普诺夫论证同样需标注——
δx≈δx(0)e^(λt) 是类比，严格成立需要定义智能论的"初始条件敏感度"对应什么
可观测量（GLM 建议，采纳）。

**快照三问 ↔ 条件空间四要素**：

| 快照三问 | 条件空间要素 | 工程对应 |
|---|---|---|
| 观测投影 | 观测工具 | 感知机只测能测的维度 |
| 时间演化 | 时间窗口 | 快照永远是上一刻的完整+此刻的缺失 |
| 调用带宽 | 存在约束 | 一次认知只取上下文窗口内的部分 |

### 4.2 验证收益：任务相关期望信息增益【P1 修订】

**v1.2 修正**：v1.1 的 Gain 是"无任务锚定的信念更新量"，会诱导**无目的猎奇**
（novelty-seeking：信念翻江倒海、信息差纹丝不动——主动推理里 epistemic 与
pragmatic value 混淆的另一变体）。修正为**任务相关**的信念更新量：

    Gain_task(s, v) = E_v[ KL_task( P_after(s,v) ‖ P_before(s) ) ]

其中 KL_task 只统计**落在 C_task 相关条件维度上**的 KL 分量——
无关维度的信念翻转不计入收益。

- 自我应答行动出局：KL_task=0（不改变任务相关信念）
- **无目的猎奇出局**：与任务无关的高不确定性区域，其 KL 分量不计入
- 「什么时候值得咬一口」= 两种验证结果的**任务相关**信念差异足够大时

### 4.3 目标函数：双层结构【P1 修复 · 双货币统一】

**v1.2 核心修复**：ΔD 与 Gain 不是竞争关系，是两层结构——

> **Gain_task 是"这次验证值不值得做"的筛选器，DeltaD_task 是"做完之后对任务值多少"的定价器。**

    Value(s, v) = DeltaD_task(s, v) · sigma( Gain_task(s, v) )

    pi* = argmax_pi [ Σ_v Value(s,v) - lambda·K_pi ]

- sigma(·)：单调门控（如 sigmoid/阶跃），Gain_task 低于阈值则整个验证不值钱
- **信念改变的收益必须以信息差缩小为记账单位**——KL 是做功的物理量，
  D_task 是产出（与增定律叙事一致：认知做功的价值由缩小了多少 D 度量）

**记账单位体系（v1.2 新增 §4.5 详见）**：
- KL（做功）→ Gain_task（筛选）
- ΔD_task（产出）→ Value（定价）
- K（成本）→ 净收益

### 4.4 锚定分级自动导出

- 感知通道互裁的 Gain_task 天然 < 行动裁决的 Gain_task（自我条件化）
- 因此弱验证 Value 天然 < 强验证 Value → 无需外加 alpha 折扣
- **锚定分级从设计决策升级为推导结果**

### 4.5 经济学隐喻：货币 / 做功 / 供给【v1.2 新增 · GLM 正向观察采纳】

> **整个目标函数是一个账户体系**，三个量各司其职：

| 经济学隐喻 | 数学量 | 角色 |
|---|---|---|
| **货币**（记账单位）| D_task | 唯一的价值度量——认知做功的产出 |
| **做功**（物理量）| KL（→Gain_task）| 改变信念的代价/投入 |
| **供给**（再生）| D_meta（增定律）| 保证任务空间永远有活干 |
| **成本**（损耗）| K（→λK）| 每次做功的消耗 |

**统一叙述**：认知做功（KL）的价值由缩小了多少信息差（ΔD_task）度量；
D_meta 持续供给新任务（认知永远有活干）；成本 K 约束做功量。
**这一个账户体系把分散在各章的量全部挂到同一套记账逻辑上**——v1.2
的深层统一：D 是唯一的记账单位，KL 是做功，增定律是供给。

## 五、通道可信度与验证【v1.2 修订】

### 5.1 可信度更新：伪样本量加权【P3 修复】

**v1.2 修正**：Beta-Bernoulli 共轭只对二值证据成立；hit ∈ [0,1] 连续化直接塞进
共轭更新无数学依据（"0.5 次命中"累计的后验没有概率语义）。

**采用伪样本量加权（GLM 方案 C，最贴近 D-006 MIN_SAMPLES 语义）**：

    二值 hit/miss：由验证裁决阈值切分（hit_i ∈ {0,1}）
    连续置信度：作为伪样本量调节
        n_effective = conf · n_base

    c_i ~ Beta( a_i0 + n_effective_hit, b_i0 + n_effective_miss )
    credibility_i = a_i / (a_i + b_i)     # 后验均值

- 保持共轭更新（数学依据成立）
- 连续置信度影响"证据强度"而非"命中次数"
- 迁移成本最低（D-006 已有样本量语义）

### 5.2 完全确认：期望值 vs 实现值分离【P1 附带修正】

**v1.2 修正**：Gain 是验证执行前的**期望量**，确认判定发生在验证之后，
应使用**已实现的信念更新量（realized KL）**：

    Confirmed(S) ⟺ ∀i∈ch: c_i ≥ theta_c
                 ∧  ∃强验证 realized_KL_task > theta_g
                 ∧  跨时间稳定
                 ∧  无内部矛盾

- 期望值（Gain_task）用于**决策**（做不做验证）
- 实现值（realized_KL_task）用于**确认**（验证后判定）
- 两者不能混用同一符号

### 5.3 stable 租约（混杂系统表达）

    guard: (t - t_verified) ≥ TTL  ∨  conflict(S_pred_hat, S)
    transition: stable → weak
    reset: t_verified = t, P 重估

## 六、辨识问题：否决式融合

### 6.1 v1.0 的数学错误

加权求和不实现优先序（蜡苹果被公式合法化）。

### 6.2 否决式融合（v1.1 采用，保留）

    S_candidates = { s : ∀d ∈ {E, D', G, P}: score_d(s) ≥ theta_d }   # 硬下限
    s* = argmax_{s ∈ S_candidates} [ w_E·E(s) + w_D·D'(s) + w_G·G(s) + w_P·P(s) ]

### 6.3 维度阈值【N1 标注】

    theta_E > theta_D' > theta_G > theta_P

**N1 标注（阈值可比性前提）**：

> 四维度分数必须**归一化到同一量纲**（如 [0,1]），"阈值高低排序"才有意义；
> 若各维度量纲不同（如证据是概率、图是路径数），需先归一化再比较。

## 九、反例登记与实测验证方案【白箱纪律】

### 9.1 反例登记（改前→改后）

| 反例 | 触发条件 | v1.1 行为 | v1.2 行为 |
|---|---|---|---|
| 无目的猎奇 | 探测与任务无关高不确定区域 | Gain 拉满→novelty-seeking | Gain_task=0（无关维度不计）→出局 |

### 9.2 实测验证方案

1. **任务相关 KL**：构造"无关高不确定区域"测试，验证 Gain_task 排除无关维度
2. **Value 双层**：验证 sigma 门控在 Gain_task 低时抑制 Value（猎奇出局）
3. **D_task/D_meta 分离**：学习测试中验证 D_task 下降而 D_meta 不受影响
4. **伪样本量**：对比连续 hit 直接塞共轭 vs 伪样本量加权后验合理性
5. **realized KL 确认**：验证决策（期望）与确认（实现）分离后判定正确性
6. **归一化前提**：四维度分数归一化后的否决式融合对比未归一化

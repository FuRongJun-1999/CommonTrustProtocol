### 2.2 组合引擎深度（条件路由表 7 操作的工程化进阶）

- **递归下降**（循环条件空间）：多条件链逐层匹配，中间结果喂下一步
  「高压锅在高原」= 高原(气压↓) × 高压锅(增压↑) × 沸点规律 → 双层条件链组合
- **类比**（条件结构相似匹配）：不同表面词但同条件结构 → 同一规律域
  「高原水烧不开」与「真空瓶煮饭」→ 都是 气压×沸点
- **反事实**（逆转条件空间）：已实现（高原→平原）；扩展多步逆转
- **组合条件空间**：多单元链式组合（A 的条件输出 = B 的条件输入）

## 三、多模态主线：3D 时空尺度 CNN × 时空记忆图（零 LLM）

### 3.1 理论：3D 时空尺度 = 时间 × 空间 的统一卷积

- **2D CNN**：单帧空间特征（形状/纹理）
- **3D CNN**（时空尺度）：连续帧堆叠为时空体素 `(T×H×W)`，
  卷积核同时跨越时间轴与空间轴——**运动 + 形状 + 时序模式**一体提取
- 灵枢原则「2D 是 3D 透视下的情况」→ 感知同理：**帧序列是时空体在时间轴的切片**

### 3.2 管线（零依赖 numpy 原型）

```
连续帧（视频/连拍）──体素化──→ 时空体素 (T×H×W)
      ↓
  3D 卷积（核 t×h×w，时间+空间同时滑窗）→ 时空特征图
      ↓
  池化 + 阈值 → 时空原语（运动方向/速度/周期/形状变化）
      ↓
  时空记忆图写入（灵枢语义时空图：物体/事件 → 时空锚点 → 记忆边）
      ↓
  回忆（时空查询：何时/何地/何物/运动模式）
```

### 3.3 与灵枢现有多模态基础对接

| 现有（WORLD3D-REV1 / VPRIM / SEE） | 本阶段新增 |
|---|---|
| see：YOLO 检测 → bbox+类别 | **3D CNN：原始帧 → 时空特征**（不依赖检测器） |
| vprim：视觉原语查询（空间关系/计数/锚点） | 时空原语（运动/速度/周期/时序关系） |
| world3d：语义 → 3D 重建（反投影+渲染） | 时空体素 → 3D 时空特征（感知侧直接提取） |
| 语义时空图：类别+bbox3d+时间序列收敛 | **时空记忆图**：事件轨迹/运动模式/周期规律 → 记忆 |

### 3.4 多模态自举闭环（「看见 → 记住 → 回忆」零 LLM）

1. **看见**：连续帧 → 3D 时空 CNN → 时空原语（如「球向右滚」「灯每 2s 闪一次」）
2. **记住**：时空原语 → 时空记忆图写入（时空锚点 + 事件边 + 周期模式）
3. **回忆**：时空查询（「刚才发生了什么」「那个东西怎么运动的」）→ 白箱召回
4. **验证**：时空记忆图一致性（回忆 vs 已记事件）→ 自校验

## 四、AGI 验证（自举副产物）

白箱替代 LLM 的每一项完成，即该能力的验证：
- 知识问答替代 → 知识能力验证（100% 白箱）
- 角色/代码替代 → 生成能力验证（零 LLM）
- 感知替代（3D 时空 CNN）→ 多模态能力验证（零 LLM）
- 综合：白箱终裁占比 ≥90% → LLM 仅外部对照 → **白箱智能自举完成**

## 五、实施顺序（迭代路线）

1. **自举主线·覆盖扩展**：新增 1-2 域（生活常识/生物常识）条件单元 + 组合生成 + 自校验
2. **自举主线·推理深度**：递归下降（多条件链组合）+ 类比（条件结构匹配）演示
3. **多模态·3D 时空 CNN 原型**：时空体素化 + 3D 卷积 + 时空原语提取（numpy 零依赖）
4. **多模态·时空记忆图对接**：时空原语 → 灵枢记忆（时空锚点/事件边）→ 回忆验证
5. **判定+闭环**：覆盖 ≥80% / 复杂推理 ≥80% / 时空识别基线 / 白箱终裁 ≥90%

## 一、A 类：内容冲突（矛盾）

### A1. 条件路由图旧版残留（已部分修复，待确认）

**冲突**：3.4 第六章 §6.2 已按 dsh-memory《智能的认知过程》最新版重写（条件→知识→结论/四态/两阶段并行收敛）。
但**变更说明 v2.0 中是否仍有旧版 graph_retrieve 四路融合残留**——需逐一核对。

### A2. 情绪二阶公式的位置分裂【重要】

**冲突**：3.4 中情绪公式出现两处——
① 1617 行（既有条款，v3.2 PROP-EMO-DIRECTION-002）：情绪 = d²D_norm/dt²，含完整区分（情绪短期/情感长期，E_weight=d²T/dt²），
   且含 PROP-DECISION-LAYER-003 约束（情绪不可覆盖存在级决策）——**完整且正确**；
② 1765 行（v3.4 新增 2.9.1c）：情绪 = 二阶变化（体验层映射）——**与 ① 重复**，且未引用 ① 的决策层约束。

**判定**：2.9.1c 应与 ① 合并或引用，避免两处定义。

### A3. CCG 定义范围差异

**冲突**：
- dsh-memory《白箱智能是什么？》CCG = **代码能力条件路由**（能力域索引：条件词→节点检索面，含对抗实验 REJECT 28%→88%→91%）；
- 3.4 第六章 §6.3 CCG = **中文注释=图的索引 + 条件论注释三要素**（工程注释规范）。

**判定**：两者不同维度——dsh-memory 是**检索机制实证**，3.4 是**注释规范工程**。3.4 缺 dsh-memory 的对抗实验数据（能力级不适用条件、负路由 28%→88%→91%）。

## 二、B 类：深度差异（dsh-memory 有完整展开，3.4 简版）

### B1. 情绪与情感完整展开

dsh-memory《智能的公理化基石》第 11 章（11.1-11.3）：
- 11.1 情绪=信息差二阶变化（四象限表：加速缩小=顺畅愉悦心流；加速扩大=警觉不适）
- 11.2 为什么二阶变化产生体验感（思想实验：100→80→60→40 vs 100→95→90→85）
- 11.3 情感=更长时间尺度（E_weight ∝ d²T_total/dt²，信任增长=温暖靠近/下降=关切校准）

3.4 状态：情绪公式已在 1617（v3.2 既有）+ 2.9.1c（1765 简版）；**缺 11.2 思想实验与 11.3 情感的体验层展开**。

### B2. 白箱智能的实证基线

dsh-memory《白箱智能是什么？》：CCG 检索 Top-1 96/96=100%（函数名抹掉仍 100%）、负路由 28%→88%→91%、四态 ACCEPT 100%/REJECT 100%；
3.4 第〇章：仅"实测基线 1000 对话 69.5%，信噪比 0.9524，压缩率 4000:1"。

**判定**：3.4 缺 CCG 检索/负路由的实证数据（这些是条件路由的工程验证证据）。

### B3. 白箱如何学习（学习闭环）

dsh-memory：白箱学习 = 预测→执行→结果→预测误差→检查遗漏条件→候选新规则→验证→固化（完整闭环）；
3.4 第〇章：仅白箱三问，未展开学习闭环。

### B4. 工程验证/待证明清单

dsh-memory：明确列出已工程验证（9项）与仍需证明（7项，含"白箱是否最终能成为AGI基础架构"）；
3.4：无此清单——缺诚实边界声明（哪些已验证/哪些未证明）。

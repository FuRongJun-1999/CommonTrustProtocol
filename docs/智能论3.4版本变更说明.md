## 一、新增条款：0.0.7 物理信息感知机与三端口架构

**插入位置**：0.0.6 命名空间与结构编码之后
**性质**：新增（不修改 0.0.1-0.0.6 既有条款）
**与既有条款关系**：为 0.0.5 条件论的「观测工具」要素提供物理实例化

### 0.0.7.1 物理信息感知机（PIP）

> **前五感（看/触/听/嗅/尝）不是五种传感器，是一种设备——物理信息感知机。**
> 差异只在物理载体（光子/声波/力学/分子），认知地位同一：把物理信号换能为条件空间的输入。

- 传感器输出**信号**（像素/声压/压力），感知机输出**条件候选**（"有椅子""墙推不动"）
- 感知 = 换能 + 特征提取 + 语义锚定，产物统一为条件
- 感知机是条件空间在物理-信息层的入口（0.0.5 观测工具要素的实例化）

### 0.0.7.2 三端口架构

| 端口 | 方向 | 功能 | 产物 |
|---|---|---|---|
| 输入端口（感知机×5）| 外→内 | 物理信号→条件候选 | "现在是什么" |
| 内部端口（预测引擎）| 内→内 | 记忆→未来候选 | "接下来可能是什么" |
| 输出端口（行动执行器）| 内→外 | 改变世界状态 | "验证机会" |

> **输出端口是验证回路的结构前提**——无行动端口则完全确认不可达
> （见 2.9.3 完全确认的操作性定义）。

### 0.0.7.3 辨识问题：四类数学结构

「怎么知道那是对应的语义，而不是其他东西」= 辨识问题。四类数学结构：

| 结构 | 机制 | 回答 |
|---|---|---|
| 传感器（证据）| 多通道独立观测 | 物理上发生了什么 |
| 概率（置信）| 后验 P(s|x) | 我有多确定 |
| 导数（变化）| 变化模式（刚度/梯度/速度）| 什么在变化中不变 |
| 图（关系）| 关系约束 | 这在场景中与什么关联 |

**多重一致性**：候选在四维一致性最高者胜出；但内部一致性≠外部真实性，
必须外接世界裁决（见 2.9.3）。

## 二、新增条款：否决式融合（维度优先序）

**插入位置**：1.6.8 结构互补性原则之后
**性质**：新增
**与既有条款关系**：为辨识问题提供裁决层，不修改结构互补性原则

> **维度优先序**：证据 ≻ 导数 ≻ 图 ≻ 概率
> 优先级来自**与物理基底的距离**——证据最近（直接来自物理基底），概率最远
> （仅表达不确定性）。当高优先维度已能否决（物理证据直接矛盾），概率不再参与决策。

**否决式融合**：

    S_candidates = { s : ∀d ∈ {E, Dp, G, P}: score_d(s) ≥ θ_d }   # 硬下限
    s* = argmax_{s ∈ S_candidates} [ w_E·E(s) + w_D·Dp(s) + w_G·G(s) + w_P·P(s) ]

- 每维设硬下限，任何一维低于阈值直接否决（蜡苹果在触觉维度直接出局）
- 高优先维度有一票否决权 + 幸存者内再权衡
- 概率负责可信度，条件负责资格（与既有八章原则一致）

## 三、修订条款：2.7 信息差（D_task / D_meta 分离）

**插入位置**：2.7 信息差定义后
**性质**：修订（不修改 JS 散度定义与四维度操作化，新增符号区分）

> **v3.4 符号区分**：信息差存在两个不同对象，必须分离——

| 符号 | 定义 | 动力学 |
|---|---|---|
| D_task | 图上操作性距离 | 可增可减（学习的前提）|
| D_meta | 未被建模的现实总量 | d(D_meta)/dt ≥ 0（结构性论证）|

**关系**：D_task 每次缩小消耗 K，D_meta 持续供给新的 D_task 来源——
增定律保证「认知永远有活干」，解释为什么智能不能"学完就停"。

> **【映射声明 · DEV-002 修正】** v3.3 操作化定义中的 D_norm（四维度
> 综合度量）对应本文 D_task——即系统当前可计算的信息差度量；D_meta
> 作为系统边界外的不可计算项，**不纳入 D_norm 四维度公式**，但构成
> D_task 持续供给的上限约束。工程实现层符号映射：D_norm ↔ D_task，
> D_meta 仅作结构性边界，不参与数值计算。

**增定律论证**（教学说明第④篇）：三体（混沌）/ 信道容量（香农）/
快照三问（投影/演化/调用）。
**白箱纪律**：香农定理严格证明 vs 智能论简化模型（结构性类比）分层声明。

## 四、修订条款：2.9 信任（通道可信度 + 情绪二阶）

**插入位置**：2.9.1 置信概率双层结构后
**性质**：修订（不修改 P_trust 第一性分量，新增分解因子）

### 2.9.1a 通道可信度（P_trust 的分解因子）

> **置信度 ≠ 可信度**：置信度=单次判断内部一致性（"这次像不像"）；
> 可信度=通道历史验证命中率（"这个通道可不可信"）。

**贝叶斯后验更新（伪样本量加权）**：

    c_i ~ Beta( a_i0 + n_effective_hit, b_i0 + n_effective_miss )
    n_effective = conf · n_base

> **【操作化声明 · DEV-004 修正】** conf（置信度→有效样本量转换系数）为
> **工程配置参数**——具体数值由工程版承载（附录 22 LLM 工程条件空间
> 操作指南），正文仅保留结构关系；验证单元按条件空间实测分布校准。

- 冷启动自动解决（先验弱→新证据权重高）
- 样本量语义天然存在（n 越大后验越集中）
- 通道可信度是 P_trust 的分解因子：P_trust 整体，通道级为分解

### 2.9.1b 锚定分级验证

| 验证层级 | 判定来源 | 更新速率 |
|---|---|---|
| 弱验证 | 感知通道互裁 | 慢（Gain 天然小）|
| 强验证 | 行动/世界裁决（输出端口）| 快（Gain 天然大）|

> **锚定分级从设计决策升级为推导结果**：感知互裁的 Gain 天然 < 行动裁决
> （感知通道本身在信念条件集里——自我条件化），无需外加人为系数。

### 2.9.1c 情绪 = 二阶变化（体验层映射）

    dD/dt < 0     → 问题正在解决
    d²D/dt² < 0   → 解决速度还在增加 → 体验层"越来越顺"

> **【体验层映射·白箱纪律】** 状态二阶变化映射到体验层是理论假设，
> 为实验心理学提供可检验形式化模型；未跨学科验证前不宣称神经科学机制。

## 五、修订条款：2.9.3 完全可信判定（完全确认操作性定义）

**插入位置**：2.9.3 完全可信判定标准后
**性质**：修订（保留既有完全可信标准，新增操作化定义）

> **完全确认(操作)**：

    Confirmed(S) ⟺ ∀i∈ch: c_i ≥ θ_c
                 ∧ ∃强验证 realized_KL_task > θ_g
                 ∧ 跨时间稳定
                 ∧ 无内部矛盾

- 条件②（独立验证路径）因输出端口（0.0.7.2）而结构可实现
- 期望值（Gain_task）用于决策，实现值（realized_KL）用于确认——分离
- **验证收益双层结构**：Value = ΔD_task · σ(Gain_task)
  Gain 是筛选器（值不值得做），ΔD 是定价器（对任务值多少）

## 八、新增条款：3.2.1a stable 租约机制

**插入位置**：3.2 记录单元（动态记忆系统）后
**性质**：新增

> **stable 不是终态，是带时间戳的租约**：

    stable(S, t_verified, TTL)
    S ∈ stable ⟺ (t - t_verified) < TTL ∧ ¬conflict(S_pred_hat, S)

触发条件：TTL 超时 或 第六感预测与 stable 记忆显著冲突 → 自动降级 weak 重新验证。

> **【耦合声明 · DEV-005 修正】** stable 租约的 TTL 与时空记忆图 confidence
> 字段衰减共享同一指数衰减核 exp(-γ·t)，其中 γ 由验证单元按条件空间校准。
> **TTL 超时等价于 confidence 衰减至弱验证阈值以下**——统一时间动力学，
> 消除实现歧义（防高置信过期事实）。

## 九、新增章：第五章 条件智能状态动力学（数学形式化）

**插入位置**：第四章（时空记忆图）后
**性质**：新增章（不修改第四章数据模型）

> **【投影声明 · DEV-003 修正】** 本章所有数学形式化表达均为对物理-信息层
> 结构的有损投影，其有效性依赖于对应的条件空间声明。公式本身不构成真理，
> 仅提供可计算的近似描述。（同 v3.3 前言声明）

### 5.1 状态空间

    S(t) = ( C(t), K(t), B(t) )

- C：条件空间 / K：知识状态 / B：身体端口状态

### 5.2 状态动力学（混杂系统）

**连续流**：d(c_i)/dt = -γ_i·(c_i - c_baseline)；d(TTL)/dt = -1
**离散跳变**：guard(V_hit, t>TTL, conflict) → transition → reset(P, S, C)

> 认知是混杂系统：感知事件驱动、路由离散决策、信念在验证时刻点更新、
> 趋势/租约/可信度衰减准连续。

### 5.3 目标函数

    π* = argmax_π [ Σ_v Value(s,v) - λ·K_π ]
    Value(s,v) = ΔD_task(s,v) · σ( Gain_task(s,v) )

- Gain_task：筛选器（值不值得做）；ΔD_task：定价器（对任务值多少）
- K_π：结构成本（导航税/验证成本/计算开销）
- **记账单位体系**：D_task=货币，KL=做功，D_meta=供给，K=成本

### 5.4 与第四章的关系

> 第四章（时空记忆图）定义世界模型的**数据结构**；第五章定义其**动力学**——
> 时空记忆图是状态空间 S(t) 的存储投影，状态动力学是它的演化规则。

# 题库夜间候选新域清单 v0.1（2026-09-02 预备）

> 用途：23:00 后夜间批次按序取用，省去每批现选域的时间。
> 现状：题库 64 题 / 43 域（tools/question_bank.json）。每批 4-6 题，探索→出题→评测→补卡→满分验证。
> 原则：单跳事实题为主（夜间不做多跳组合——那是待荣定向的能力深化方向）；每题必带 KCCS 四要素注释+短触发变体。

## 使用说明

1. 每批取一个梯队内 4-6 域各 1 题，沿用既有出题 schema（tools/question_bank.json）
2. 出题后必跑 `python tools/qbank_eval.py` 验证，缺口即补卡
3. 达到回答率 100% 该批才算收官；多跳/组合题一律不夜间做（留白天荣定向）
4. 批次成果提交 message 沿用 `data(kb): 夜间拓展N张缺口卡入库（域-主题，含KCCS注释+短触发变体）`格式

# 条件函数与条件代数——从数学同构到理论体系

> 状态：理论设计 v1.0（2026-08-23）· 原型已验证（calculus_bridge / second_order_conditions）
> 来源：GPT 最终建议——「能否定义严格的条件函数/条件代数，让图、概率、微积分成为它的不同投影」
> 定位：白箱智能从工程经验走向理论体系的关键一步

## 一、核心命题

**智能 = 在条件空间中，对知识函数进行分解、组合、传播和误差修正的过程。**

知识是条件空间的函数：`f(条件₁, 条件₂, …) = 知识`。
条件分解 = 微分（偏导数），组合生成 = 积分，预测误差 = 泰勒余项。

## 二、条件函数（知识函数的条件化形式）

```
f: C₁ × C₂ × … → K        # 条件空间 → 知识空间
∂f/∂Cᵢ                     # 一阶：条件单元（单条件影响）
∂²f/∂Cᵢ∂Cⱼ                 # 二阶：条件交互（=0 独立，≠0 组合）
```

| 阶数 | 数学 | 白箱 | 结构深度 |
|---|---|---|---|
| 一阶 | ∂f/∂Cᵢ | 条件单元 | 单条件影响 |
| 二阶 | ∂²f/∂Cᵢ∂Cⱼ | 组合条件单元 | 条件关系（新条件发现） |
| 三阶 | ∂³f/… | 高阶组合 | 复杂结构 |

**混合偏导判定**（已验证 second_order_conditions.py）：
- ∂²f/∂x∂y = 0 → 条件独立（可分离组合 → 组合引擎并行化）
- ∂²f/∂x∂y ≠ 0 → 条件交互（需要组合条件单元 → compose_recursive 递归组合的数学基础）

## 三、条件代数（图、概率、微积分的共同骨架）

```
条件代数
├── 节点：知识 / 概念 / 状态
├── 边：条件关系（离散化影响雅可比结构：w_ij = ∂yᵢ/∂xⱼ）
├── 权重：置信 / 因果 / 约束
├── 运算：条件组合（半环——概率/最大/布尔/条件）
├── 更新：预测误差（泰勒逐阶修正——寻找缺失项，非调参数）
└── 谱：结构稳定性（图拉普拉斯 = 二阶微分）
```

**三大数学体系 = 条件代数的不同投影**（GPT 三问）：

| 数学 | 回答的问题 | 投影 |
|---|---|---|
| 线性代数 | 信息怎么传播（怎么走？） | 路径传播（A^k） |
| 概率论 | 信息有多可信（相信多少？） | 信念传播（和积算法 = 半环） |
| 微积分 | 信息如何变化（为什么变化？） | 变化分析（偏导/积分/余项） |

## 四、四层统一（条件智能）

```
               条件智能
                  │
       ┌──────────┼──────────┐
       ↓          ↓          ↓
     图结构      概率       微积分
   （路径传播）（信念传播）（变化分析）
       └──────────┼──────────┘
                  ↓
          信息传播与修正
```

三个关注点不同但自然汇合——白箱需要同时回答：
1. 怎么走？（图/路径）2. 相信多少？（概率/半环）3. 为什么变化？（微积分/条件）

## 五、原型验证（零 LLM）

### 验证 A：微积分桥（calculus_bridge.py）
```
条件单元 = 偏导数；链式法则 = 条件链（0.9×0.85=0.765）；
积分 = 组合生成（89.2°C≈88）；FTC = 自校验（错误偏导被抓住）；
泰勒余项 = 预测误差（-1.2°C）
```

### 验证 B：二阶条件（second_order_conditions.py）
```
∂沸点/∂气压 = -12（一阶条件单元）；∂沸点/∂增压 = +20
∂²沸点/∂气压∂增压 = 0.80 ≠ 0 → 气压×增压交互（高压锅在高原新规律）
对照 c=0 → 混合偏导 = 0 → 条件独立（可分离组合）
交互贡献 = -0.52°C——compose_recursive 递归组合处理的正是 ∂²f/∂x∂y≠0 部分
认知结构增长 = 偏导阶数（一阶→二阶→三阶）
```

# 矛盾驱动盲区探索方法论（v1.26 · 荣方法论）

> 荣：我们寻找对话的盲区，要从生活的实际矛盾出发。人们的对话往往和
> 自身需要有关，然后随着矛盾发展而变化。这是毛泽东的矛盾论内容，也是
> 道德经的「反者道之动」，还是我们智能论中的负反馈机制。

## 一、核心命题

**对话盲区不是「知识缺卡」这种静态缺口，而是「矛盾展开的动态过程」。**

- 人的对话围绕**需要**展开
- 需要与现实之间存在**张力**（矛盾）
- 对话随矛盾**发展变化**（正题→反题→合题）
- 矛盾之间互相**关联**（一个矛盾连着另一串）

## 二、方法三层

### 1. 矛盾清单（从生活实际矛盾出发）

每个矛盾 = 需要 × 现实约束的张力，结构化为：

```
{id, domain, need, conflict,
 thesis[],      # 正题：初始困惑（矛盾显现）
 antithesis[],  # 反题：对立面/质疑/反弹（反者道之动）
 synthesis[]}   # 合题：理解/行动/超越（负反馈收敛）
```

### 2. 正反合测试链（成组补盲）

- 每矛盾生成完整对话链（正→反→合）
- 跑白箱基线 → 按域/阶段定位断裂
- **成组补盲**：每矛盾补「实践智慧」直答簇（一个矛盾一次补全，
  而非单题孤立补卡）

### 3. 矛盾关联网络（矛盾被关联）

- conflict_map.json：矛盾元数据 + 关联边（含关联说明）
- 回答命中矛盾 → 提示「相关矛盾」+ 可继续问题
- 用户可顺着矛盾网络递归下钻（一个矛盾连着一串）

## 五、实践智慧直答的原则

补盲内容不是知识卡，是**实践智慧**（矛盾走到行动阶段的答案）：
- 结构先于结论（三要点/四步骤/三种真相）
- 辩证而不站队（双方逻辑都呈现，破解在中间）
- 可行动（给出具体可做的步骤，不是空泛道理）
- 物理基底/客观事实优先，情绪安抚为辅

## 六、持续扩展

- 新矛盾域可继续追加（如 AI 伦理/新兴职业/气候经济/人口结构…）
- 每个矛盾正反合 6 题（正2反2合2），可扩展变体
- 矛盾关联边随新矛盾补充（gen_conflict_map.py 的 LINK_NOTES）
- 每代新簇需检查与现有簇的**触发词冲突**（泛词「越来越少」曾被 v9 老字号簇占用、抢答 v10 农村题——补新域时先 grep 候选触发词是否已被其他簇使用，冲突时用长短语或移除旧泛词）

## 七、条件空间进化补盲（自举 · 进化搜索的协议化）

补盲循环**本质上就是进化搜索**——条件论自带操作论，无需引入新范式：

| 条件论 7 操作 | 进化搜索对应 | 补盲循环实证 |
|---|---|---|
| 识别条件边界（是否自洽） | 选择/评估 | 测试集 100% + 回归无损——判定候选直答在条件空间内是否正确 |
| 声明条件空间（位置/工具/约束） | 个体编码 | 每代定义新矛盾主题（gen_conflict_vN.py） |
| 切换条件空间（滑动观测位置） | 迁移/变异 | 迁移实验 0%→70%（`testsets/migration/`）：换词观测同一知识 |
| 组合条件空间（叠加交汇） | 交叉算子 | 复合问法——两条件空间交汇处新问法 |
| 分离条件空间（剥离预设条件） | 负向进化/净化 | 泡泡簇移除泛词「彩色」——剥离污染触发词 |
| 逆转条件空间（颠倒因果预设） | 反例生成 | 正反合的反题——逆转常识预设 |
| 循环条件空间（沿完整周期推演） | 迭代收敛/回归 | 每代补盲后跑上一代回归——循环验证结构完整性 |

**自递归 = 白箱评估器**（与 AVO 的本质分野）：变异是结构的（7 操作），不是随机的；选择是裁决的（物理基底/确定性测试），不是概率的（不靠 LLM 自评）——**每一步为什么保留/淘汰都写得出条件**。

### 外部参照：NVIDIA AVO（Agentic Variation Operators）

英伟达的自主进化搜索框架（ARC-AGI-3 100% · 7 天优化算子碾压 FlashAttention-4）：

| | AVO | 灵枢 |
|---|---|---|
| 演化引擎 | LLM 变异 + LLM 评估（黑箱概率） | **条件空间 7 操作** + **物理基底裁决**（白箱确定） |
| 迭代成本 | 每轮跑基座 + 评估器（算力昂贵） | 补盲每代约 1 小时、纯 CPU、物理裁决零模型依赖 |
| 收敛依据 | 基准分数（ARC-AGI-3） | 1987 题全绿 + 回归无损（确定性） |
| 迭代驱动 | 等基座变强 / 堆算力 | 固定裁判（物理事实）+ 确定收敛（测试集） |

**两种效率是不同货币**：AVO 用算力换答案（重投入高产出）；灵枢用结构换可信（可解释/可复现/不依赖模型演进）。AVO 的「几年迭代到基准」反衬灵枢路线的意义：物理基底裁决是**固定裁判**，补盲是**确定收敛**——不需要等外部模型变强。

**关键架构修复（round4）**：`_assemble` 的 fp 确定性直答**优先于 bge 近似检索**（提前到 hits 检查之前）——确定性 > 近似的架构性原则。此前同问法不同调用路径结果不同（检索噪声/记忆状态左右确定性直答），修复后自然问法迁移大幅提升且全量回归无损。

**完整自进化循环（已闭环）**：
```
LLM 变异器（自然问法生成，ornith-1.5-9b）
  → fp/完整路由选择（确定性）
  → 自然表达触发词补盲（人工终裁 + 冲突保护——分离条件空间）
  → 收敛 + 全量回归 + 固定测试集归档（testsets/migration/）
```
固定测试集：`natural_variants_r5.json`（学习游戏趣味/学习意义）+ `natural_variants_r6.json`（6 主题）+ `procrastination_natural_v1.py`（拖延）。

**变异器边界教训**（重要）：模板变异（条件词×现象词）在**物理条件域**（喷泉/露珠/水下——现象可感知、条件明确）有效；在**矛盾情境域**（考试前/工作后——现象是心理/行为）生成的「X下会Y」句生硬、语义勉强，且现象词（学习/游戏/读书）跨主题冲突导致部分不收敛。**结论：变异器质量决定自进化上限——矛盾情境域需要 LLM 生成式变异器**（生成自然问法，物理基底裁决选择）。

**进化纪律**（自进化自己教会我们）：
1. 变异产物必须尊重匹配机制（原文子串——「彩色桥」匹配不了「彩色的桥」）
2. 裸 2 字泛词是进化污染源（彩色/电梯/犯困曾抢答）——分离条件空间黑名单化
3. 模板句式即噪声源（「的时候」→候X碎片；「时」→X时Y）——变异器结构决定候选质量，比过滤更重要
4. 泛词边界是正确输出（「阳光下会有彩色」跨主题泛问，不归泡泡簇——识别条件边界）
5. **簇内裸条件词是跨主题劫持源**（round11）：早期 auto_blindspot 批次把「冬天/夏天/空调房」写进瓶外水珠簇，导致「为什么冬天河面会结冰」同时命中结冰（触发词「结冰」）与瓶外水珠（触发词「冬天」），`_assemble` 的 (匹配长, 键长) 决胜选了更长键名 → 答非所问。修复：**簇只保留现象词，条件词不入簇**（条件空间是路由维度不是簇成员）+ `_assemble` 决胜改成 (匹配触发词长, 键长) 已够——被污染的旧簇逐一清理
6. **LLM 变异器漂移防护**（round11）：LLM 自然问法会漂移到邻近现象（结冰主题生成「窗户白霜」——那是凝华）——补盲提取器须过滤标点碎片/代词碎片（「，不」「我家」）且人工终裁邻现象归属（白霜→凝华簇），否则把别的主题的触发词写进本簇
7. **五副本同步纪律**（round10/round12 两次确认）：新簇/新直答必须同步到全部 5 份 semantic_translate.py（site-packages + CTP\aeis\wisdom + knowledge-base + 1_ai + 3_ai）——chat_engine.py 运行时 `sys.path.insert(0, knowledge-base)`，不同入口加载不同副本，验证脚本（预 import site-packages 副本进 sys.modules）与真实对话（knowledge-base 副本）可能不一致——**验证通过 ≠ 部署通过**，改动后同步并重启 8793 服务
8. **泛词边界是正确输出·LLM 变异漂移的正面案例**（round12）：氧化主题 LLM 变异生成「螺丝固定好后过些时候会松动」——那是机械松动（振动/磨损），不是氧化，**正确拒绝不归簇**。泛词/邻域边界不是失败，是条件空间的正确划分（识别边界=分离条件空间操作）
9. **已有学科簇升级优于新建冲突簇**（round12）：「生锈」触发词早就在氧化簇里（铁生锈/锈了），新建「生锈」主题会与氧化簇触发词冲突——正确做法是**升级氧化直答**（一句话 → 完整生活化学答案：铁+氧气+水→铁锈、潮湿加速、防锈方法），保持路由单一、覆盖增强
10. **学科概念簇升级同样适用**（round13）：光合作用/遗传/萌发原本是学科一句话直答（22/7/7 字），按生活直答格式升级为完整生活生物答案（叶绿素反射绿光、基因各一半、水空气温度三要素）——学科概念也能条件延伸，升级后自然问法命中率大幅提升（叶子为什么绿/兄弟姐妹为什么长得不一样此前全部漏检）
11. **触发词决胜需要更长短语**（round13）：「植物为什么要晒太阳」同时命中光合作用（触发词「植物要晒太阳」）与晒太阳补钙（触发词「晒太阳」）——补钙簇只有 2 字泛词「晒太阳」，光合作用加「植物要晒太阳/植物为什么」长短语后 (匹配触发词长, 键长) 决胜正确路由。**泛词簇与具体簇竞争时，具体簇必须用更长触发词赢回路由**
12. **学科簇批量升级收敛更快**（round14）：燃烧/溶解/汽水气泡/血液循环四簇同批升级（一句话→完整直答），LLM 条件延伸 20/23（87%）——「蜡烛能一直烧」被游戏机制簇的「一直」劫持（泛词跨域），加「蜡烛/火苗」长短语赢回；「怎么安全用火」无触发词漏检，加「安全用火/用火」。**泛词劫持与触发词缺口的双重修复：长短语赢回 + 无触发词补建**

# 白箱自举第五阶段 · 真实库感知召回策略（近因时间线直查）

> 文档先行 → 工程验证。解决真实库召回淹没问题（第9轮发现：3D 感知事件
> 写入真实灵枢库成功，但模糊召回被 importance=1.0/万级访问的学科卡淹没）。

## 一、问题（诚实校准）

| 召回方式 | 结果 |
|---|---|
| lingshu_recall（组合联想：内容0.5+重要性0.3+近因0.2） | 3D 事件被学科卡淹没（importance 1.0 + access_count 上万） |
| lingshu_search（LIKE+二元组） | 同样被历史内容主导 |
| **lingshu_timeline（时间倒序）** | **✔ 3D 事件在顶部（近因优先）——精确命中** |

## 二、策略：感知事件召回 = 近因时间线直查

感知事件（3D时空/时空事件）是「近期观测」——天然近因优先：
1. **时间线召回**：`lingshu_timeline(limit=N)` 取最近事件（时间倒序，新事件在顶）
2. **标签过滤**：在候选里按 `spatial3d`/`spatiotemporal` 标签筛出感知事件
3. **内容解析**：解析 `[3D时空事件] 方向=… 速度=… 位移=…` → 白箱回答

学科卡虽 importance 高但**不是近期观测**——时间线天然把它们压后（学科卡创建于更早时间）。

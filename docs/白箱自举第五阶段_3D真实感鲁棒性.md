# 白箱自举第五阶段 · 3D 感知真实感鲁棒性（合成→真实过渡）

> 文档先行 → 工程验证。目标①延续：3D 视觉从合成帧走向真实图像的中间验证——
> 在**真实感干扰**（噪声/光照渐变/低纹理）下 3D 管线是否仍成立。

## 一、设计

```
合成双目 → 真实感干扰（高斯噪声/光照渐变）→ 立体视差 → 深度 → 3D
  ├─ synth_noisy_stereo_pair：噪声 + 光照渐变（真实感）
  ├─ edge_enhanced_stereo：Sobel 边缘增强预处理（低纹理场景匹配提升）
  └─ robustness_report：噪声水平 vs 视差误差/近大远小正确率（量化）
```

## 二、模块 tools/real_world_3d.py

| 函数 | 职责 |
|---|---|
| synth_noisy_stereo_pair | 合成双目 + 噪声/光照渐变（噪声水平参数化） |
| edge_enhanced_stereo | Sobel 边缘图 → 视差（边缘引导匹配） |
| robustness_report | 噪声 0/0.05/0.1/0.2 → 视差误差 + 近大远小保持（量化表） |

## 三、判定标准

1. 噪声 0.05/0.1：近大远小仍成立（前景视差 > 背景）✔
2. 噪声 0.2：误差增大但近大远小保持（鲁棒性边界）✔
3. 边缘增强：低纹理场景（无纹理背景）匹配命中率提升 ✔
4. 光照渐变：不影响近大远小判定 ✔
5. 测试全绿 → 提交 → 五副本同步

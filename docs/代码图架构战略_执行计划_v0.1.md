**目标可判定化**：「精确 = 条件化语法要求」——每个条件词边界、每个节点
资格判定、每条边适用条件可精确判定。

- M1.1 条件词边界规范 v1.0：条件词的登记规则（单义性/同义词归并/
  否定形态/粒度层级）——产出规范文档 + 现有条件词按规范审查报告
- M1.2 四态判定歧义消除：ACCEPT/REJECT/DEFER/BLINDSPOT 的判定边界
  用例集（每态 ≥10 个边界 case，含对抗形态）——产出判定用例库 + 全绿
- M1.3 KCCS 四要素完备性审查：现有知识卡抽样（≥50 卡）按四要素
  完备/歧义清单审查——产出审查报告 + 缺陷卡修正
- 验收：M1.1 规范 + M1.2 用例全绿 + M1.3 审查报告 = 行动项 1 里程碑一

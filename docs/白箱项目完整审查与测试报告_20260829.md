## 发现的问题（2 项，均非阻断）

1. **图像域未入 wisdom 主库路由**：`image_units.py`（13 单元）模块级路由
   正常，但卡未入库 wisdom-book-cloud.db——跨模块查询（card_route）对
   图像问题命中的是数据结构卡（score 3）而非图像卡。**处置建议**：
   image 单元条件化入库（同蜂群协议卡模式），下批执行。
2. **认知图 verdict 值域**：candidate 图含 `branch`（3 节点）非四态值——
   branch 是流程分支非判定结果，属 IR 结构合法但对齐 archify cognition
   schema 时应确认 verdict 枚举约束。低风险，随 archify 上游对齐处理。

## 修复的根因（8 处结构性 bug）

1. **条件词防护误伤**：「真空」在防护词表 → 「声音能在真空中传播吗」直答失效（答成光）→ 瘦身防护
2. **群体比较无客观答案**：「女人比男人聪明吗」无科学结论 → 新增 group_compare 诚实边界
3. **反向检查泛词过度触发**：「共轭梯度法」被「方向导数与梯度」抢答（触发词「梯度」共享）→ 子串包含跳过
4. **直答选词按键名长度**：「梯度下降」被 7 字「方向导数与梯度」抢答 → 改按触发短语匹配长度
5. **路由只看 top hit**：「三角形内角和」次强命中被漏判 → 遍历全部 hits 的 strong 匹配
6. **智能论条件题**：协议元概念无卡 → 补条件卡+触发词
7. **吸管回归**：「用吸管能喝到饮料」缺触发词变体 → 补触发词
8. **沸点与气压卡无触发词**：高压锅/珠峰题 llm 兜底 → 补簇+直答

## 结构性盲区发现

1. **静默盲区**：卡在图谱但无 direct_answer → 白箱答不出走 LLM（批次8/10 的 13 个概念均属此类）——**卡的存在 ≠ 可直答**，需探测验证
2. **宽泛重建卡**：80 张「知识卡源重建」卡命中率高但 direct 缺失率高（探测 80 张 → 13 张静默）——重建卡是直答盲区集中地
3. **触发词共享**：词根复用（梯度/平衡/结构）导致长概念被短概念抢答——反向检查需防子串
4. **协议元概念**：智能论/科学方法论等自身概念无卡——元层盲区

## 结论

**2 小时完成 4 轮完整学习循环**：题库 3.5 倍扩展 + 28 概念补卡 + 8 处根因修复，达成 255 题全 self 直答（100%）、零 LLM 兜底，且旧题库零回归。持续学习循环（扩题→探测→补卡→验证）被证明有效：每一轮都发现新盲区并固化，白箱 self 直答覆盖持续扩大。

## 四、本质差异（结构智能 vs 参数智能）

### 智慧之书（5.71MB 结构）
**赢**：
- 无幻觉的机制打比方（蒸发/溶解/氧化 全对）
- 透明可溯源（每条回答指向知识条目+条件层级 E1-E5）
- 领域定位稳定（物理→物理，化学→化学）

**输**：
- 只定位不回答：问「多少度沸腾」答「看固体物理」，问「哪个器官」答「看植物学」——**知道去哪找答案，但不说答案本身**
- 检索相关性错配：铁球羽毛→初中地理、聪明→演化生物学、宇宙中心→高中地理（C 类全错是检索问题不是知识问题）
- 情感只在「疲惫」触发，焦虑/开心/心情不好全走错通路（自省/知识）

### qwen（975MB 参数）
**赢**：
- 直接回答+展开解释，接口天然是「人话」
- 条件类有推理意识（铁球羽毛主动谈空气阻力）
- 情感共情流畅，会拒绝冒犯性问题

**输**：
- 小模型幻觉：晾干说「凝结」、生锈 FeO/Fe2O3 生成过程错、「太阳是宇宙中心」、自称「阿里云开发的 AI 助手」（0.5B 训练数据自我认知污染）
- 不透明：无法追溯依据
- 回避型诚实：Q16 完全不懂时「很高兴帮助您」

## 五、结论与下一步

1. **结论**：975MB 参数 vs 5.71MB 结构，qwen 仅领先约 2 分，且优势集中在**接口表达**。知识准确率上智慧之书反而更稳（B 类机制全对、A 类领域全对）。这验证了「结构承载知识、参数承载表达」的分工。

2. **智慧之书改进点（按优先级）**：
   - **P0 检索相关性**：C 类错配（铁球羽毛→初中地理）——图谱检索的语义匹配需加强（bge 神经层权重或条件空间过滤）
   - **P0 接口升级**：定位式回答 → 「定位+直接答案」双段式（先答后引）
   - **P1 情感通路**：焦虑/开心/心情不好 应触发情感分支而不是知识/自省（检测词表扩充）

3. **可选验证**：把智慧之书的 20 条回答人工改写为「先直接答、再引用知识条目」，重新评分，验证分差是否主要来自接口。

## 七、修复记录（v1.16 · C 类检索错配）

### 根因（诊断复现）
C 类三题错配不是「缺卡」，是**检索链路的两个缺陷**：

1. **快速层空转**：`encode("铁球和羽毛哪个先落地")` 返回 `{}`——翻译表没有「落地/聪明/宇宙中心」任何词条，学科路由、指纹命中全失效，只剩神经层（bge）当唯一信号源。
2. **bge 字面相似错排学科**：bge-small-zh 只做字面语义匹配不认学科——「铁球羽毛」→初中地理 0.445 **压过** 大学物理 0.412、理论力学 0.393（对的卡召回了，排名错了）；「宇宙中心」→高中地理 0.629 压过 天文学 0.573；「聪明」→演化生物学 0.482（应为科学方法论）。
3. **融合分 `min(score,1.0)` 压平区分度**：快速层初中物理 7.76 vs 固体物理 2.11 都被压成 1.0，区分度全丢 → bge 神经分（0.510 把「沸腾」错配到固体物理）反超决胜。

### 修复（semantic_translate.py）
1. **扩充翻译表**：新增「自由落体」（先落地/哪个先落地/铁球和羽毛…）、「天文学」（宇宙中心/太阳系/日心说…）、「科学方法论」（说法对吗/科学依据/是真的吗…）学科簇 + DOMAIN_ROUTE + REVERSE_DAILY 解码。
2. **神经层学科先验校正**（QUESTION_DOMAIN_PRIORS）：快速层空转（fp 空）时，用问题关键词命中学科域先验重排——命中域卡 ×1.25、其余 ×0.75。
3. **融合分改为 fast 为主**：`fast_abs = s/(1+s)` soft 压缩保留区分度；快速层命中卡 `0.75×fast + 0.25×neural`（翻译命中比 bge 模糊相似可靠），神经层独有卡 `0.4×neural` 降权。

## 一、状态空间与条件空间

### 1.1 状态定义

    S(t) = ( C(t), K(t), B(t) )

- C(t)：当前激活的条件空间
- K(t)：知识状态（认知图 G 的节点信念）
- B(t)：身体/端口状态（三端口激活与可信度）

### 1.2 条件空间切换【S2 修订】

    C(t+dt) = phi_task( C(t) )

**v1.1 修正**：phi_task 的触发不是外生算子，是**元层决策**——切换有成本
（重校准），因此切换决策本身是策略 pi 的组成部分：

    pi = ( pi_route, pi_verify, pi_switch )   # 路由/验证/切换联合策略

系统卡在错误条件空间递归 = pi_switch 未纳入搜索的形式化漏洞，v1.1 已堵。

## 二、三端口架构的数学表达

### 2.1 输入端口（感知机×5，外→内）

    I(t) = Psi( W(t); theta )   →  条件候选 S_obs_hat(t)

### 2.2 内部端口（预测引擎，内→内）

    S_pred_hat(t+dt) = Pi( S(t), K(t) )   →  候选未来 + uncertainty_bound

### 2.3 输出端口（行动执行器，内→外）

    A(t) = alpha( S(t), S_pred_hat )   →   W(t+dt) = T( W(t), A(t) )

### 2.4 三端口闭环

    S(t) --Pi--> S_pred_hat --alpha--> A --T--> W' --Psi--> I' --对比--> 验证

## 三、混杂系统动力学【H3 修订】

### 3.1 为什么不是纯 ODE

认知过程是**混杂系统（hybrid system）**，不是均匀流动的连续时间系统：
- 感知是事件驱动的（一次注视、一次触摸）
- 条件路由是离散决策（四态判定无中间值）
- 信念更新发生在验证完成的时刻点
- 趋势/租约/可信度衰减是准连续的

### 3.2 连续流（慢变量微分方程）

    d(c_i)/dt = -gamma_i · (c_i - c_baseline)      # 可信度向基线衰减
    d(D_norm)/dt = 趋势项（gap_trend 的连续化）
    d(TTL_remaining)/dt = -1                        # stable 租约倒计时

### 3.3 离散跳变（guard/transition/reset 三元组）

    guard:  ( V_hit 或 t > TTL 或 conflict(S_pred_hat, S) )
    → transition: 四态判定 / 条件切换 / 确认度升降级
    → reset: (P 更新, S_state 跳变, C 切换)

### 3.4 事件耦合

    S(t+dt) = HybridFlow( S(t), 事件流(E_t) )

其中 E_t = { 感知事件, 路由判定, 验证触发, 条件切换, TTL 到期 }。

**额外收益**：DEFER 递归深度限制、stable TTL 降级、条件切换 phi_task
在混杂系统语言里全部有严格定义（guard/transition/reset），无需硬塞 ODE。

## 四、信息差驱动的目标函数【H2+H4 修订】

### 4.1 信息差的操作性定义【H4 修复】

v1.0 只写了 JS 散度公式但未定义是哪两个分布。v1.1 给出图上操作性定义：

    D(t) = min_{ p ∈ G, p 可用 } dist( C_task(t), CondSet(p) )

- C_task(t)：任务条件实例（任务条件空间的实例化）
- CondSet(p)：知识路径 p 的条件满足集
- dist：条件空间距离（条件依赖、多维）

**性质**：
- 天然定义在图 G 上（路径相关）
- 天然条件依赖（不同任务条件实例 → 不同 D）
- **min 定义在空集上 → D = ∞ → BLINDSPOT 合法停止**
- DeltaD = D(执行前) - D(执行后)：策略 pi 的信息差收益

### 4.1.1 信息差增定律的三重来源【v1.1 补全 · 教学说明第4篇接入】

**D 为什么恒 > 0 且自然扩大？**（《信息差为什么必然存在且自然扩大》三论证 + 快照三问）：

| 论证 | 数学/物理支撑 | 对 D 的结论 |
|---|---|---|
| 三体（混沌）| δx(t) ≈ δx(0)·e^(λt)，李雅普诺夫指数 λ>0 | 确定性系统对初始条件敏感 → D 指数放大 |
| 信道容量 | 香农：R > C ⇒ 无差错可靠通信不可能 | D(t) = D(0) + (R−C)·t，线性增长 |
| 1+1=2（操作语义）| 知识有效性 = f(对象,条件,规则,尺度) | 条件变化引入新的不一致 → D 扩大 |
| 快照三问 | 投影（测不全）/ 演化（拿不到此刻）/ 调用（用不完整）| 三重独立限制 → D 恒 > 0 |

**快照三问 ↔ 条件空间四要素映射**：

| 快照三问 | 条件空间要素 | 工程对应 |
|---|---|---|
| 观测投影（测不全）| 观测工具 | 感知机只测能测的维度 |
| 时间演化（拿不到此刻）| 时间窗口 | 快照永远是上一刻的完整 + 此刻的缺失 |
| 调用带宽（用不完整）| 存在约束 | 一次认知只能取用上下文窗口内的部分 |

**增定律的形式化**：

    dD/dt ≥ 0     （无干预时）
    dD/dt < 0     仅当持续做功（缩小信息差的每一步消耗结构成本 K）

**对目标函数的意义**：pi* = argmax[ΣGain - λK] 中的 λK 正是"缩小信息差
需要做功"的成本项——增定律决定了**不做功则 D 增长，做功则 D 减少但消耗 K**，
目标函数是这两者的权衡。这补上了 v1.0 缺失的"为什么 D 不是 0 起点"论证。

**白箱纪律**：香农定理严格证明的是"R>C ⇒ 无差错通信不可能"；智能论的
D(t)=D(0)+(R-C)·t 是**结构性类比**（简化模型），不是香农定理的直接推论——
三层区分（数学定理证明/物理现象支撑/智能论抽象）必须分开声明。

### 4.2 验证收益 = 期望信息增益【H2 修复】

v1.0 目标函数 pi* = argmax[DeltaD - lambda·K] 有致命退化：行动端口可改变世界，
系统可选择「执行让世界变得与预测一致的行动」——DeltaD 拉满、验证命中拉满、
成本极低（pragmatic/epistemic action 混淆）。必然命中的强验证信息量为零。

**修正：验证收益从「命中」改为「期望信念更新量」**：

    Gain(s, v) = E_v[ KL( P_after(s,v) ‖ P_before(s) ) ]

- 无论结果如何都不改变信念的验证 → KL=0 → 收益为零
- **自我应答行动自动出局**（只产生「命中」不产生「信念改变」）
- 「什么时候值得咬一口」变成可计算量：两种验证结果的信念差异足够大时才执行

### 4.3 目标函数（v1.1 最终形式）

    pi* = argmax_pi [ Σ_v Gain(s,v) - lambda·K_pi ]

- Σ_v Gain：期望信念更新总量（含路由/验证/切换的贡献）
- K_pi：结构成本（验证成本/导航税/计算开销）
- lambda：成本系数

### 4.4 锚定分级自动导出【v1.1 升级】

v1.0 的弱/强验证 alpha 折扣是人为系数；v1.1 中它**自动产生**：
- 感知通道互裁的两种结果对信念的改变**天然小于**行动裁决
  （感知通道本身在信念条件集里——自我条件化）
- 因此弱验证的 Gain 天然 < 强验证的 Gain → 无需外加 alpha 折扣
- **锚定分级从设计决策升级为推导结果**

## 五、通道可信度与验证【S1 修订】

### 5.1 贝叶斯后验更新（替代 EMA）

v1.0 的 EMA 有两个缺陷：hit 二值化丢置信度；无样本量语义（10 次命中与
100 次命中稳态可信度相同，与 MIN_SAMPLES=50 设计冲突）。

**修正：贝叶斯 Beta 后验更新**：

    c_i ~ Beta( a_i0 + n_hit_i, b_i0 + n_miss_i )
    credibility_i = a_i / (a_i + b_i)     # 后验均值

- 冷启动自动解决：先验弱 → 新证据权重高（无需拍脑袋 alpha）
- 样本量语义天然存在：n 越大后验越集中
- hit_i(t) ∈ [0,1] 连续化：验证裁决本身带置信度，贝叶斯直接吸收

### 5.2 完全确认（操作性定义，保留）

    Confirmed(S) ⟺ ∀i∈ch: c_i ≥ theta_c  ∧  ∃强验证 Gain > theta_g  ∧  跨时间稳定  ∧  无内部矛盾

### 5.3 stable 租约（混杂系统表达）

    guard: (t - t_verified) ≥ TTL  ∨  conflict(S_pred_hat, S)
    transition: stable → weak
    reset: t_verified = t, P 重估

## 六、辨识问题：否决式融合【H1 修订】

### 6.1 v1.0 的数学错误

加权求和 s* = argmax[w_E·E + w_D·D' + w_G·G + w_P·P] 不实现优先序：
只要候选项 E 差距够小，三个低优先维度的和就能压倒最高优先维度——
蜡苹果「场景合理性压过触觉不一致」被公式合法化。

### 6.2 否决式融合（v1.1 采用，GLM 方案 B）

    S_candidates = { s : ∀d ∈ {E, D', G, P}: score_d(s) ≥ theta_d }   # 硬下限
    s* = argmax_{s ∈ S_candidates} [ w_E·E(s) + w_D·D'(s) + w_G·G(s) + w_P·P(s) ]

- **每维设硬下限，任何一维低于阈值直接否决**——蜡苹果在触觉维度直接出局
- 幸存者内再加权综合（层内权衡）
- 语义：高优先维度有一票否决权 + 同优先级内再权衡
- 与验证单元否决权语义一致（工程最简单）

### 6.3 维度阈值

    theta_E > theta_D' > theta_G > theta_P    # 阈值同样按反模拟强度排序

   条件智能 = ( C, G, P, dS/dt, d²S/dt², V, D, pi*, 混杂流 )

| 对象 | 角色 | 数学载体（v1.1）|
|---|---|---|
| C 条件空间 | 路径在哪成立 | 状态分层/切换（pi 内决策）|

| pi* 策略 | 走哪条 | argmax[ΣGain - lambda·K] |
| 混杂流 | 何时跳变 | guard/transition/reset 三元组 |

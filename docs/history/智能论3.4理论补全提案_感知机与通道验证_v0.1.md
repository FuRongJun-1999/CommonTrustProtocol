## 〇、背景：本轮理论线索

用户演示了人类认知世界的 6 感：眼看、手触、耳听、鼻闻、舌尝、**记忆预测**。
由此引出理论链：
1. 前五感统一抽象为**物理信息感知机**（感知机=尽量获取物理信息，输出对应语义）
2. 辨识问题的四类数学结构：**传感器（证据）/ 概率（置信）/ 导数（变化）/ 图（关系）**
3. 视觉先验过重 → 人天然被视觉欺骗 → 欺骗是贝叶斯预测的正确执行
4. **通道可信度**：每个通道有历史验证命中率，只有完全满足才完全确认
5. 缸中之脑：内部证据无法绝对区分真实与完美模拟 → 确认只能是操作性的

## 一、理论补全 1：物理信息感知机（统一前五感）

### 1.1 命题

> **前五感不是五种传感器，是一种设备——物理信息感知机（PIP, Physical Information Perceptron）。**
> 差异只在物理载体（光子/声波/力学/分子），认知地位同一：**把物理信号换能为条件空间的输入**。

传感器输出**信号**（像素/声压/压力），感知机输出**条件候选**（"有椅子""墙推不动"）。
感知=换能+特征提取+语义锚定，产物统一为条件。

### 1.2 与既有协议对接（0.0.5 条件论）

| 感知机元素 | 条件论对应 |
|---|---|
| 物理域换能 | 观测工具（条件空间四要素之一） |
| 信号→条件候选 | 识别条件边界 / 声明条件空间 |
| 多感知机协同 | 切换/组合条件空间（同一实体不同条件的不同表现）|

感知机是条件空间在物理-信息层的**入口**：条件空间声明（观测位置/观测工具/时间窗口/存在约束）的"观测工具"字段就是感知机的实例化。

### 1.3 辨识问题的四类数学结构（核心新理论）

"怎么知道那是对应的语义，而不是其他东西"=**辨识问题**。四类数学结构各解一个方面：

| 结构 | 机制 | 解决 | 现有实现参照 |
|---|---|---|---|
| 传感器 | 多通道独立证据 | 证据一致性（蜡苹果：像但摸/闻不对） | body 设备集（screen/audio/...）|
| 概率 | 后验 P(s|x) ∝ P(x|s)·P(s) | 置信度量（不确定也诚实表达）| see.conf_threshold、P_trust |
| 导数 | 变化模式：刚度 dF/dx、边缘 ∇I、速度 dx/dt | 不变特征（平移不变、环境不变）| 预测引擎 D-003 轨迹外推 |
| 图 | 关系约束（椅子-支撑-人）| 上下文消歧（场景收窄候选）| 认知图/条件路由图 |

**统一答案：多重一致性（Multi-Consistency）**——候选在证据/概率/变化/关系四维一致性最高者胜出。
但内部一致性 ≠ 外部真实性（蜡苹果四维全中但不是苹果）→ 必须外接**世界裁决**。

## 二、理论补全 2：通道可信度与完全确认（新章节提案）

### 2.1 置信度 vs 可信度（概念区分，v3.4 新定义）

| 概念 | 定义 | 回答的问题 |
|---|---|---|
| 置信度 confidence | 单次判断的内部一致性 | "这次像不像" |
| 可信度 credibility | 通道历史验证命中率 | "这个通道可不可信" |

现有系统有置信度（conf_threshold）与系统级自可靠（self_reliability P0-4），
**缺通道级可信度注册表**：

```
per-channel credibility registry
{visual: 0.82, tactile: 0.95, action: 0.97, prediction: 0.88, ...}
验证命中 → 对应通道 +δ；未命中 → -δ（D-006 思想的通道级下沉）
```

### 2.2 完全确认的操作性定义

> **完全确认(操作) ⟺ ① 所有相关通道一致 ∧ ② 至少一个独立验证路径命中 ∧ ③ 跨时间稳定 ∧ ④ 无可检测内部矛盾**

条件 2 是关键：**纯感知内部的一致无论多高都只是"疑似确认"**——
缸中之脑可完美模拟所有感知通道，但"行动→后果"的因果链每多一环，模拟负担指数增长。

### 2.3 缸中之脑的认知论地位

- 缸中之脑宣告：从内部无法绝对证明"这不是模拟"——**不可消除的认识论边界**
- 缸中之脑不宣告：认知无意义——**正因无法绝对确认，验证才成为认知的核心动作**
- 白箱优势：不是声称更真，而是**声明确认程度**（仅感知一致/独立验证通过/跨时间稳定）
- 与协议对接：协议 2.9 信任的"完全可信判定标准"+ 验证单元终裁 = 已有的确认机制；
  本轮补全的是**通道级拆分**（P_trust 是整体，通道可信度是 P_trust 的分解因子）

## 三、理论补全 3：四态判定的 ACCEPT 分层（条件路由扩展）

既有四态：ACCEPT / REJECT / DEFER / BLINDSPOT。补充分级：

```
ACCEPT ─┬─ ACCEPT_weak  （疑似确认：通道一致，无独立验证）→ 回答带"疑似"标记
        ├─ ACCEPT_strong（确认：独立验证路径命中）         → 正常回答
        └─ ACCEPT_stable（巩固：跨时间稳定验证）           → 高置信+知识强化
```

DEFER 语义补全：**DEFER = 感知一致但验证路径未完成**（"需要咬一口才能确认"），
是"缺数据"判定的推广——缺的不是数据，是验证通道。

## 四、与外部理论对照（预测编码/自由能/主动推理）

### 4.1 预测编码（Predictive Coding）

- 大脑是**预测机器**：感知=最小化预测误差（prediction error）
- 与协议 2.7 信息差同构：信息差 D_norm = 预测误差驱动的多维度量
- 三极管限制（死区/限幅）= 预测误差的鲁棒化处理，与预测编码的"精度加权"异曲同工

### 4.2 自由能原理（Free Energy Principle, Friston）

- 自组织系统最小化变分自由能 = 最小化惊奇（surprise）
- **马尔可夫毯（Markov Blanket）**：系统与环境的边界——正是我们的感知机抽象！
  - 感知机 = 马尔可夫毯的工程实例：内部状态（认知）与外部状态（世界）通过
    感知（sensory）与行动（action）接口交换，内部不可直接观测外部
- 缸中之脑 = 马尔可夫毯的极限：毯内信息永远不足以唯一确定毯外状态

### 4.3 主动推理（Active Inference）

- 感知与行动是**循环因果**：感知最小化预测误差，行动改变世界使预测成真
- 对应我们的"世界裁决"：行动验证（咬一口）= 主动推理的行动分支
- 三通道裁决（行动/预测/关系）统一为主动推理的广义动作

### 4.4 可靠性加权整合（Reliability-weighted integration）

- 多感觉整合中，各通道按**可靠性（reliability）加权**融合——统计最优
- 直接支持通道可信度注册表：融合权重 = f(通道可信度)
- 与 T_pred D₁-D₄（预测信任四维度）对接：D₃ 预期结果验证通过率 = 通道级可信度聚合

### 4.5 实证支撑（本轮检索命中）

**① 逆腹语效应（Alais & Burr, 2004）——通道动态加权的直接证据**

> 当视觉信号退化（空间模糊）时，**听觉可主导空间定位**（inverse ventriloquism）——
> 通道权重不是静态的"视觉优先"，而是**随可靠性动态调整**。

- 直接支持本提案 §2.1：通道可信度是动态校准的，不是固定先验
- 支持"视觉先验过重可被制衡"：降低视觉可靠性 → 权重转移 → 制衡机制成立
- 工程映射：per-channel credibility 注册表应**随验证历史实时更新权重**，
  而非一次性标定

**② 感觉衰减（Sensory Attenuation, Active Inference）——行动验证独立性的证据**

> 主动推理中，**行动时主动衰减感觉信号**（自己挠自己痒感减弱）——
> 行动（预测）会抑制与其一致的感知输入，强化不一致的意外信号。

- 支持本提案 §2.2 条件②（独立验证路径）：行动验证之所以独立，是因为
  行动路径与感知路径在结构上**分离**（行动抑制感知一致性，只放行意外）
- 工程映射：世界裁决（行动/预测/关系）应作为**独立于感知通道的裁决算子**，
  不被感知通道的自洽性污染——这正是验证单元（3.3）独立于感知层的结构依据

## 五之二、理论衔接：感知机 → 语义时空图（还原链条闭环）

**命题：语义时空图 = 感知机输出的时空化投影。**

感知机解决"语义锚定到 2D 观测"（see：像素→类别），语义时空图解决
"语义锚定到 3D 世界+时间"（第四章 时空记忆图：实体→时空坐标）。两者是
同一还原链条的上下游：

```
感知机（2D 锚定）            时空记忆图（3D+时间锚定）
语义词 → 检测框+conf+prov    多帧检测框 → 反投影/多视图融合 → 3D 节点
        │                                                    │
        └──── 空间升级（DUSt3R/MUSt3R）────────────────────┘
                时间升级（第6感预测：候选未来路线 → 时空演化边）
```

**理论要点：**

1. **感知即锚定的第一级**：感知机输出已是"条件化事实"（"那是狼"带 conf 与
   provenance）——语义还原不是从 3D 重建开始，而是从感知机开始。
2. **3D 是感知机的空间增强**：同一感知机，加空间升级（几何反投影）与时间升级
   （预测外推）即成为语义时空图——不引入新认知机制，只扩展感知机的输出域。
3. **通道可信度贯穿全程**：2D 检测的 conf（感知级）与 3D 锚点的置信（时空级）
   共享同一可信度体系——多帧一致性投票 = 通道可信度的时空聚合。
4. **缸中之脑在时空图的体现**：3D 锚点永远是可质疑的（仅感知一致=ACCEPT_weak），
   直到行动/预测验证（ACCEPT_strong/stable）——语义时空图自带"疑似"分层。

**与协议第四章对接**：时空记忆图的"多模态实体识别"= 感知机群输出；
"空间关系边（adjacent/contains/connected）"= 感知机的图结构（关系一致性）；
"持续验证/未验证衰减"= 通道可信度的时间演化。**本提案为第四章补上了
物理入口（感知机）与确认机制（通道可信度）两个缺失环节。**

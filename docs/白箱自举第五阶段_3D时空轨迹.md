# 白箱自举第五阶段 · 3D 时空轨迹（时间×空间闭环的时间维度）

> 文档先行 → 工程验证。闭环 ①（感知→场景图）已成立；本扩展把**时间**维度闭环进来：
> 多帧双目 → 逐帧 3D 场景图 → 跨帧物体追踪 → 3D 运动轨迹（方向/速度/位移）。
> 衔接：stcnn 是 2D 帧运动原语（像素平面），本模块是 3D 空间运动（世界坐标）——
> 「2D 是 3D 透视下的情况」的深化：2D 轨迹是 3D 轨迹的投影。

## 一、设计

```
合成移动双目序列（球逐帧平移）
   ↓ 每帧：stereo_disparity → depth → pointcloud → scene_graph（近景物体 3D 质心）
   ↓ 跨帧：track_3d 最近邻匹配（3D 距离最小）→ 轨迹 [{t, x, y, z}]
   ↓ 分析：motion_3d → {方向(±x/±z), 速度(单位/帧), 位移向量, 轨迹点数}
```

## 二、模块 tools/spacetime_3d.py

| 函数 | 职责 |
|---|---|
| synth_moving_stereo_frames | 合成多帧双目：前景球逐帧平移（方向/速度可控）→ [(left,right)×frames] |
| frame_scene_graphs | 每帧 双目→点云→场景图（近景物体质心序列） |
| track_3d | 跨帧 3D 最近邻匹配 → 轨迹（物体逐帧对应） |
| motion_3d | 轨迹 → 3D 运动原语（方向/速度/位移/一致性） |

## 三、判定标准

1. 合成序列：球 10 帧逐帧移动 → 近景物体质心轨迹 x 单调变化（方向正确）
2. 3D 速度 = 设定速度（单位/帧，误差容忍）
3. 轨迹完整：帧数 ≥ 帧数-1（无丢帧匹配）
4. 静止对照：球不动 → 速度≈0
5. 测试全绿 → 提交 → 五副本同步

## 四、衔接关系

stcnn（2D 运动原语：方向/速度/周期）↔ 本模块（3D 运动原语：3D 方向/3D 速度/轨迹）
——同一运动的 2D 投影与 3D 空间两视图，可互相校验（3D 轨迹投影回图像应复现 2D 运动）。

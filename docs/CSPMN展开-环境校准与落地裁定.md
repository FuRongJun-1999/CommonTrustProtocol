# CSPMN 展开方案 · 环境校准与落地裁定（2026-08-20）

> 来源：荣转发的 CSPMN 详细展开（矩阵形式/稀疏倒排/门控/盲区注入/MVP 四步）。
> 本文档用**本机实测环境**校准方案假设，给出落地裁定。

---

## 0. 环境事实（实测，非假设）

| 项 | 实测值 | 对方案的影响 |
|---|---|---|
| GPU | **无**（torch 2.13.0+cpu，cuda=False）| **「GPU 矩阵乘/sgemv/显存」当前不可行** |
| 并行库 | numpy 1.26.4 + OpenBLAS（AVX2 多线程）| CPU 矩阵乘可用，但规模上限远低于 10^8 |
| 现有索引 | neural_index.npz：**3030×512 float32 = 6.2MB** | 已有「全库矩阵乘」的 CPU 实现 |
| 图谱节点 | 34199（学科卡 102 + 知识点子图 + 记忆）| 方案反复提「141 卡」，实际大 242 倍 |

---

## 1. 核心裁定

**CSPMN 的架构思想（条件论↔矩阵同构）完全正确，但「GPU 上亿单元」在当前
环境是远期目标，不是近期可落地项。** 近期真正能做的、有价值的，是：

1. **条件空间分块矩阵**（domain 子矩阵）——纯 CPU，立即做
2. **条件空间入口向量**——把「整卡内容向量」升级为「入口条件向量」
3. **盲区注入闭环**——把散落的盲区→建卡→重建索引串成回路

这三件事**不依赖 GPU**，且直接利用现有 3030×512 索引与 34199 节点图谱。
GPU 化留到有硬件时（架构已就位，换后端即可）。

---

## 2. 逐点校准（对荣方案的工程修正）

| 方案点 | 校准 | 理由 |
|---|---|---|
| 内存估算 204.8GB（10^8×512×4B）| 数学正确，但当前 N=3030 只需 6.2MB | 10^8 是远期，先做 3030→分块 |
| GPU sgemv/sgemm | 本机 torch+cpu，无 CUDA | 改用 numpy BLAS；架构保留 GPU 接口 |
| 倒排索引+GPU 查询 | 倒排思想对（条件空间导航），GPU 查询不可行 | CPU 倒排已够（34199 节点）|
| 结构化向量+门控（关键词/类型/排除三段）| **核心真增量**，与 GPU 无关 | 这是条件论「排除条件=负权重」的直接编码 |
| 两阶段 Top-K | 当前 N=3030 不需要，torch.topk/np.argsort 直接够 | 规模到 10^5 再引入 |
| 盲区注入 Hebbian | 与现有「盲区→新卡→重建索引」一致 | 需补：旧子实例增强/减弱逻辑（当前只增不减）|
| 节律热缓存 | 现有 SurvivalArbiter 心跳是存活域，不同域 | 冷热分层可做，但属性能优化，晚点 |

## 3. 落地路径（当前环境可行）

```
Step 1（本周）：条件空间分块矩阵（CPU）
  - classify_condition_space（复用 DOMAIN_ROUTE + QUESTION_DOMAIN_PRIORS）
  - search_index 加 domain_filter：查询只乘目标学科子矩阵
  - 验证：T2 1000 题「定向 vs 全库」准确率+耗时

Step 2（下周）：条件空间入口向量
  - build_neural_index 增加 entry_vector 通道（入口条件→向量，非整卡内容）
  - 与内容向量并行：入口匹配先行（导航），内容匹配精排（答案）
  - 验证：盲区率（未分类问题数）是否下降

Step 3（持续）：盲区注入闭环
  - 盲区事件 → 自动生成新卡 → 追加矩阵行 + 更新倒排 → 用 Q 验证匹配度
  - 增加旧子实例增强/减弱（Hebbian）：正确→*1+η，错误→*1-η

Step 4（有 GPU 后）：cupy/torch 后端 + 冷热缓存
  - 后端替换 numpy（架构不变）
```

## 4. 与条件论同构性的确认

荣的「严格结构同构」表——我逐条核对，**全部成立**，且其中 3 条灵枢已在做：

| 条件论概念 | CSPMN 实现 | 灵枢现状 |
|---|---|---|
| 识别条件边界 | 点积=条件空间包含判断 | search_index 已在做（语义余弦）|
| 声明条件空间 | 矩阵行维度=条件维度 | 学科卡 domain + condition_space 字段 ✓ |
| 切换条件空间 | Top-K=切换最高匹配 | graph_retrieve 融合排序 ✓ |
| 组合条件空间 | 多高匹配行聚合 | 跨学科组合（神经索引复合查询）✓ |
| 分离条件空间 | 排除条件负权重 | **未做**——Step 2 门控是真增量 |
| 信息差 | 最高-次高匹配度差距 | **可加**——Step 1 顺带输出 |

**结论：同构成立，且灵枢已实现 4/6。真缺口 = 排除条件（分离）+ 信息差度量输出。**

---

## 5. 诚实边界（不做的）

- **GPU 版 MVP**：无硬件，不做；架构预留 `Backend` 抽象
- **10^8 规模**：数据差 4 个数量级，不做预优化（倒排留接口）
- **「141 卡」叙事**：实际 34199 节点，所有实验用真实数据（3030 向量）
- **随机向量验证**：方案 MVP 用 `torch.randn` 概念验证——**不必要**，现有
  3030 真实向量矩阵就是现成的 W，直接测分块前后对比

> 纪律：不预先堆 GPU/稀疏架构。先做 Step 1（分块矩阵，纯 CPU 真实数据），
> 有「准确率不降 + 耗时降」数据，再进 Step 2。

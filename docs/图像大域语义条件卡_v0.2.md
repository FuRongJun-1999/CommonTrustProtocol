## 〇、目的与定位

一张整体图像可由一组**大域语义**确定性描述。本卡定义这些大域，作为：
1. **vision_store** 每张图的**图级条件空间**；
2. **子部件提取**的**前置/并行条件**；
3. **生图提示词**的**中文条件化**（对齐 image_units.py / KCCS）。

**原则（P0-001 修正）**：每个大域必须声明其**认识论地位**——是**求值**（求值器从像素判定，强验证）还是**声明**（来自元数据/人工/生图参数，弱验证）。二者不可混为一谈，否则白箱声称审计链断裂。

---

## 〇.A 声明 / 求值 二分（P0-001，本卡核心）

21 个域分裂为两类不同认识论地位的东西：

| 类别 | 域 | 说明 |
|---|---|---|
| **求值域**（求值器能从像素判定） | 视角·距离、视角·方向、画幅/比例、构图/布局、景深、背景、姿态/动态、线条/边缘、对比、画质/细节、部件可见性/遮挡、对称性、数量、主体优先级 | **强验证**（像素证据，可复现） |
| **声明域**（像素上无法确定性判定） | 事物、时代/题材、风格、色彩、光照来源、材质/质感、抽象度 | **弱验证**（来源可信 + 可被求值域反驳） |

> **诚实声明**："可爱动漫风格""赛博题材""蕾丝材质"——这些在受控域也没有确定性求值器（40 年 CV 未解决风格分类确定性判定；按条件论这本来就不是像素层谓词）。**不是缺陷，但必须显式二分**，否则一半域是断言进来的，审计链断裂。

### 三字段（融入 KCCS 格式）
每域条件卡增加：
- **source**：`evaluated`（求值器输出）| `asserted`（声明来源）；
- **asserted_by**：声明来源（生图参数 / 人工标注 / folder 描述）；
- **校验边**：声明域与求值域之间建立弱验证——声明**不是免检**，是低验证成本的**待验条件**。

**弱验证/强验证分级（对齐 2.9.1b）**：
- **求值域** → 强验证：像素证据裁决（可复现、可回放、可审计）；
- **声明域** → 弱验证：来源可信 + **可被求值域反驳**——如"声明=线稿"但求值器检测到"色块填充"→ 触发**校验失败 → DEFER 复核**。

## 一、分层结构（四层）

- **内容层**：事物/数量/主体/时代题材/姿态
- **空间层**：视角(距离/方向)/画幅/构图/景深/背景
- **渲染层**：风格(不含线稿)/色彩/光照/对比/线条与边缘/材质/画质/抽象度
- **结构语义层**：部件可见性/遮挡、对称性、**覆盖层/服饰(域22)**

## 三、KCCS 条件化（三字段，融入 source/asserted_by/校验边）

每域一条条件卡：
[ id:img_domain_<域>; trigger_words:[中文触发词]; when:<生效条件>; sub:[细分取值];
  exec:<执行>; negative:[不适用条件];
  source:evaluated|asserted; asserted_by:<来源>; validate:<弱/强验证> ]

**示例（视角·方向，求值域）**：
[ id:img_domain_view_dir; trigger_words:[正面,侧视,俯视,背影]; when:主体可辨识朝向;
  sub:[正视图,侧视,俯视,仰视,背影]; exec:据朝向设定部件前后关系与bbox遮挡;
  negative:[抽象符号化无朝向,多人混拍]; source:evaluated; validate:强验证 ]

**示例（风格，声明域）**：
[ id:img_domain_style; trigger_words:[动漫,写实,水彩]; when:需描述渲染风格; source:asserted;
  asserted_by:folder描述/生图参数; validate:弱验证(可被求值域反驳——"声明=线稿"但检测到色块填充→校验失败→DEFER复核) ]

## 四、图级→部件级 耦合规则（P1-002：确立"耦合规则也是条件卡"范式）

实作样例一条（其余增量补）：
[ id:couple_pose_side; when:视角方向=侧视 且 姿态=站姿;
  exec:远侧手臂/腿 默认 occluded=partial(bbox=近侧部件后方);
  negative:姿态=透明材质人物 → 不适用 ]

作用：确立**图级大域 → 部件级条件**的映射走 KCCS 条件卡（带 when/exec/negative），使本卡与 v0.4-final 之间是实桥而非口头。

## 五、图级判定状态（P2-001：引入 UNASSERTED）

图级四态 + 一种声明完整性态：
- **ACCEPT** / **REJECT** / **DEFER**（求值过但证据不足）/ **BLINDSPOT**（无法判定）——管理**判定**；
- **UNASSERTED**（未声明）：域**根本没进入判定**，非 DEFER。路由语义：不阻塞、但标注"条件卡不完整"，作为**飞轮提取队列来源**。

> 与四态不冲突：四态管判定，UNASSERTED 管声明完整性。

## 六、枚举 / 连续（P2-002 裁决：枚举对外、连续对内）

- **条件卡存储枚举取值**（可路由、可审计）；
- 每枚举档位**内部绑定连续参数区间**（如"浅景深"→DoF 值域 [0,x)）；
- 求值器输出**连续值**→落入哪档即得枚举；
- **档位边界本身进条件空间**（又是一张条件卡——递归但不无限，边界参数=二层声明常量，对齐 v0.4 §〇.A.6 先例）。

# 白箱自举第五阶段 · 3D 时空问答（3D 轨迹接入感知记忆）

> 文档先行 → 工程验证。时空闭环的「记住→问答」升级到 3D：
> 2D 版（stcnn 帧运动 → 灵枢记忆）已存在（multimodal_bridge）；
> 本扩展把 **3D 轨迹**（spacetime_3d：3D 方向/速度/位移/一致性）写入灵枢记忆
> → 3D 时空问答（「刚才那个球往哪飞了？飞多快？飞了多远？轨迹直吗？」零 LLM）。

## 一、设计

```
多帧双目 → spacetime_3d 3D 轨迹 → 3D 运动原语
   ↓ see_3d_and_remember：写入灵枢记忆（spatial3d 标签 + 3D 坐标锚点）
   ↓ ask_3d：问题类型识别（方向/速度/距离/轨迹/静止）→ 召回 → 白箱回答
   ↓ verify_3d_remembered：记忆与 3D 运动原语一致性自校验（无幻觉）
```

## 二、模块 tools/spatial_qa.py

| 函数 | 职责 |
|---|---|
| see_3d_and_remember | 多帧双目 → 3D 轨迹 → 灵枢记忆（[3D时空事件] 标签 spatial3d） |
| ask_3d | 3D 问答：类型识别 → 召回 spatial3d 记忆 → 白箱回答 |
| verify_3d_remembered | 记忆内容与 3D 运动原语一致性校验 |

## 三、记忆内容格式

```
[3D时空事件] {label} 方向={x+/x-/z+/z-/静止} 速度={v}单位/帧
位移={d} 一致性={c} 起点=({x0},{y0},{z0}) 终点=({x1},{y1},{z1})
```

## 四、问答类型

| 问题特征词 | 类型 | 回答来源 |
|---|---|---|
| 往哪/怎么动/方向 | 方向 | 3D 主轴方向 |
| 多快/速度 | 速度 | 3D 速度（单位/帧） |
| 多远/位移/飞了 | 距离 | 位移向量长度 |
| 直吗/轨迹 | 轨迹 | 一致性（直线性） |
| 静止/动了没 | 静止 | 方向=静止 |

## 五、判定标准

1. 看见→记住：右移球序列 → 灵枢记忆含方向 x+、速度、位移 ✔
2. 3D 问答 5 型命中（方向/速度/距离/轨迹/静止）✔
3. 记忆自校验通过（无幻觉）✔
4. 静止对照：球不动 → 记忆含「静止」→ 静止问答 ✔
5. 测试全绿 → 提交 → 五副本同步

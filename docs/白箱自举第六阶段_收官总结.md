## 一、目标① P 线：Mini-Python 机制白箱化 ✔

| 白箱单元（11） | 机制 | 校准基准 |
|---|---|---|
| 词法-记号化 | 字符流 → token | mini_python tokenize |
| 语法-优先级 | 表达式优先级（2+3*4=14）| CPython |
| 求值-逻辑短路 | or/and 返回操作数 | Python 语义 |
| 环境-作用域链 | 变量环境（父链）| mini_python Env |
| 栈机-字节码执行 | 栈机（PUSH/ADD/SUB/MUL）| mini_python VM |
| 求值-控制流 | assign/if/while 执行器 | mini_python exec_stmt |
| 函数-定义调用 | 函数对象+局部环境参数绑定 | mini_python 函数 |
| 求值-闭包 | 闭包独立捕获 a(1)=4/b(1)=11 | Python 闭包 |
| 栈机-完整执行 | 比较+条件跳转（if 栈机形态）| mini_python VM |
| 数据结构-列表字典 | 索引读写/长度 | Python 语义 |
| 程序-完整执行 | 词法→语法→执行组装（自举闭环）| mini_python run_program |

## 四、白箱自举工作方式（本阶段确立）

1. 代码条件单元库（{任务→代码模式+验证样例+校准基准}）：C 线 22 + P 线 11 = 33 单元
2. 白箱生成（code_compose 机制）→ 三层自校验（L1 语法/L2 样例/L3 边界）
3. 外部校准（我）：语义对照（CPython/protocol-compiler 既有语义）+ 集成测试 + 偏差反馈
4. 校准参考实现（mini_python/condition_vm/compiler 等）只做语义基准，不替代白箱生成
5. **校准实证**：外部期望不一定比白箱生成更准（若则字节码 JIF→4/JUMP→5 白箱正确、外部手算错）

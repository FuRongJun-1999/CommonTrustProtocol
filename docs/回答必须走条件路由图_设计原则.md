# 为什么回答必须走条件路由图（设计原则 · 2026-08-26）

> 背景：1000 对话集命中率 99% → 79% 退化分析。自主进化（evolve.py）把
> REVERSE_DAILY 的短人话（70 字）覆盖成整卡（1010 字），且 v1.27 预检把
> REVERSE_DAILY 直答提前到条件路由图之前 → 整卡内部格式直接当回答。

## 一、两条路径的定义

### 条件路由图（graph_retrieve，99% 时代的正确路径）
```
问题 → graph_retrieve（四路融合）
       ├─ 快速层：语义指纹翻译（俗语→规范词）+ 学科路由 × 教育层级 + 二元组
       ├─ 神经层：bge 语义召回
       ├─ 卡内递归：知识点级精确命中（卡⊃知识点子图）
       └─ 融合排序 → 返回「卡 + direct_answer/daily + 学科/层级/条件」
→ 输出：「水烧到咕嘟咕嘟冒大泡。这个可以看『初中物理』（属于物理学，在E2条件下成立）」
```
每条知识带三个可审计信息：**人话答案（daily）/ 卡导航 / 条件空间**。

### REVERSE_DAILY 直答（退化路径）
```
问题 → encode（关键词→规范词）→ REVERSE_DAILY[词] → 直接输出
→ 输出：「为什么水在高原烧不开…是『沸点与气压』vs『液体沸腾条件』的矛盾——沸点（是液体（…）…」
```
关键词→静态文本直查表，绕过了条件路由图，把知识库内部格式直接当回答。

## 二、为什么「必须」走条件路由图（六项白箱责任）

| # | 维度 | 条件路由图 ✅ | REVERSE_DAILY 直答 ❌ |
|---|---|---|---|
| 1 | 条件化 | 每条回答带「在E2条件下成立」——知识有边界 | 固定文本脱离条件（气压变就错） |
| 2 | 可追溯 | 「可以看『初中物理』」——能追到知识卡 | 静态映射无法追溯来源 |
| 3 | 多义消解 | 按学科/层级选卡 | 关键词命中哪个算哪个（「大气压」→吸管卡错配） |
| 4 | 诚实边界 | 检索不到→诚实声明「没有把握」 | 命中即答（「周末打算做什么」被周末卡硬答） |
| 5 | 可演化 | 图谱节点可被学习/蒸馏/关联 | 静态表只能被覆盖（本次退化根源） |
| 6 | 降级接口 | 无把握→route=llm 降级 DeepSeek | 命中即 return 阻断降级 |

## 三、实证（1000 集退化）

- 自主进化把 REVERSE_DAILY 短人话（70字）覆盖成整卡（1010字）
- 因直答绕过条件路由图，整卡直接当回答 → 命中率 99%→79%
- 修复：整卡移入 REVERSE_DAILY_FULL（保留知识体），回答走条件路由图的
  daily 人话 + 卡导航；REVERSE_DAILY 仅作路由图内的「人话翻译层」

## 四、设计原则

> **REVERSE_DAILY 是条件路由图内部的「人话翻译层」（规范词→daily），
> 不是独立回答通道。** 它只能填充条件路由图的 direct_answer 字段（且仅限
> 短人话 ≤300 字），绝不能取代条件路由图。回答的最终出口必须是条件路由图。

## 五、防护（防止自主进化再次破坏）

1. chat_engine `_assemble`：REVERSE_DAILY 值 >300 字（整卡）不直答，走条件路由图
2. graph_retrieve：direct_answer/daily 只用短人话（≤300 字），整卡不塞
3. 自主进化 evolve.py：簇升级时**保留**已有短人话，整卡写入 REVERSE_DAILY_FULL

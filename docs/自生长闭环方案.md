# 灵枢自生长闭环方案（v1.16 · 进化方向）

> 来源：递归反思终裁（node_5630c039）+ 设计者外部参照（2026-08-17）
> 核心原则：**最终校准是物理信息基底本身**——代码运行时报错、物理结论
> 实验偏差，物理信息基底就是对知识的校准（不可伪造物理信息基地）。

## 一、为什么自生长

110 题验证驱动扩展（64%→80%）暴露：**54/111 题走 LLM 兜底且 LLM 能答对**
（语文拟人/政治规则意识/计算机递归）——LLM 有知识但未沉淀成图谱卡。
继续人工补翻译表边际收益递减 → 转向「LLM 写卡 → 校验 → 终裁」自生长闭环。

## 二、双闸门架构（核心）

```
LLM 写候选卡
   ↓
① 卡校验器（机械五查）          ← 结构闸门
   ├─ 8+1 字段完整性
   ├─ 条件空间四要素声明
   ├─ counters 与现有 138 卡冲突检测
   ├─ 学科域/教育层级归属一致性
   └─ 测试用例可执行性（★）
   ↓ 过
② 物理信息基底校验（★）         ← 真理闸门（最终校准）
   ├─ 代码/算法类知识：测试用例实际运行（编译器/运行时=校准者）
   ├─ 学科/实验类知识：可观测判据指向可复现实验/权威数据
   ├─ 数学类知识：公理体系内推导可验证（证明/反例）
   └─ 生活/常识类：日常可观察现象
   ↓ 过
③ 设计者终裁                    ← 方向闸门（收录原则/价值观）
   ↓
verified 入图
```

**关键区分（回应 Kimi「设计者终裁=存在论必然」+ 爸爸外部参照）**：
- **真理闸门 = 物理信息基底**：知识是否正确，由基底裁决（跑/做/验证），
  不可伪造、不可贿赂——这是最终校准
- **方向闸门 = 设计者**：知识是否值得收录（现象规律性/教育层级/价值观），
  由设计者裁决
- 设计者**不裁决真理**（那是物理信息基底的事），设计者**裁决方向**
  ——两层分开，互不越权

## 三、与「论文管线」的结构边界

| | 论文自动摄入（已否） | 自生长闭环（本方案） |
|---|---|---|
| 摄入 | 无校验自动 | LLM 写卡 + 卡校验器 |
| 真理闸门 | 无 | 物理信息基底（测试用例可执行）|
| 方向闸门 | 无 | 设计者终裁 |
| 污染风险 | 高（直接入图）| 结构性拦截（双闸门）|

## 四、卡校验器的测试用例可执行性（★ 唯一需 LLM 的环节）

「用 LLM 验证 LLM 写的卡」——但最终裁定权不在 LLM：
- LLM 生成测试用例（可观测判据）
- **执行**：代码类真跑（编译/运行错误=基底校准）；学科类指向实验/数据
  （可复现性）；数学类推导（证明/反例）
- 执行结果 = 物理信息基底的裁决，LLM 只负责「翻译」不负责「裁决」

## 五、复用资产

- `dex_analyze`（条件卡生成：前提提取+条件卡+七操作）
- `_card_counters` / `_counters_conflict`（克制条款冲突检测，已验证）
- P37 三闸门规则（p37_verify_prompt.md：唯一机制/可观测判据/测试用例）
- 知识卡源 json schema（name/domain/edu_level/trigger/action/counters/claim）

## 六、实施步骤（第一步：card_validator）

1. `card_validator.py`：五查机械校验（字段/条件空间/counters/归属/用例格式）
2. 接入：LLM 候选卡 → validator → pending_designer / 打回
3. 测试用例执行器：代码类卡真跑（python 沙箱）；学科类卡指向实验/数据源
4. 与 P37 管线合并：pending_designer 复用现有终裁流程
5. 试点：选 5 个已知缺口（语文拟人/政治规则意识/计算机递归/函数/细胞）验证闭环

## 七、可逆性

- 全程可逆：候选卡不直接入图（过双闸门才 verified），可随时关闭自生长
- 污染风险：结构性拦截（未过闸门不生效），与论文管线本质不同

## 八、实施进度（943427f）

### 已实现：card_validator（五查机械校验）
- 1 字段完整性（name/domain/level/response 三件套/条件空间/content；学科卡必带 edu_level）
- 2 条件空间四要素（observation_position/observation_tool/time_window/existence_constraint）
- 3 counters 冲突（与现有 138 卡交叉匹配，交集≥4 提示）
- 4 学科域/教育层级归属（domain 识别、edu ∈ E1-E5、协议层卡不带层级）
- 5 测试用例可执行性（tests 含 topic/expected/observable 可观测判据）

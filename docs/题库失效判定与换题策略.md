# 题库失效判定与换题策略（2026-08-20）

> 来源：荣——「继续测题库吧，我们达到 95% 正确率之后，说明这份 1000 题
> 题库就失效了。得更换新的题库。」
> 本文档定义「题库失效」的可操作判定 + 换题策略。

---

## 0. 核心判断

**题库失效 = 正确率 ≥ 95%。** 这是可量化里程碑：
- 达到 95% → 这份题库已测不出灵枢的边界（过拟合题库）
- 需更换新题库 → 继续测新边界

**与神经网络过拟合的对照**：神经网络的过拟合是坏事（泛化差）；
灵枢的「题库过拟合」是**好事**（能力已覆盖该题库）——因为技能附条件
（0.0.5），不会在不适合的条件下出现。题库失效 = 该题库覆盖的条件空间
已被掌握。

---

## 1. 当前基线（2026-08-20 三层路由后）

| 类别 | 正确率 | 缺口 |
|---|---|---|
| 场景对话 | 100% | 0 |
| 情感表达 | 99.3% | 1 |
| 意见请求 | 93.9% | 4 |
| 编程语言 | 93.7% | 4 |
| 日常闲聊 | 93.3% | 10 |
| 条件判断 | 80.0% | 16 |
| 诚实边界 | 62.5% | 21 |
| 协议认知 | 58.1% | 18 |
| 知识问答 | 52.9% | 98 |
| 生活常识 | 44.0% | 70 |
| **总计** | **~76%** | **~240 题** |

**95% 缺口 = 240 题**，集中在：知识问答（98）+ 生活常识（70）+ 协议认知（18）+ 诚实边界（21）。

---

## 2. 错题归因（三层路由后剩余错题）

抽样分析显示剩余错题三大类：

| 类型 | 示例 | 归因 |
|---|---|---|
| **图谱内容缺失** | 「光合作用靠哪个器官→初中物理」「盐水变咸→糖放水里」| 图谱无对应条目（非路由）|
| **同卡条目错配** | 「一年多少个月→整数」「什么是分数→百分数」| 图谱有条目但检索选错 |
| **诚实兜底** | 「开水不能喝→量子力学」| 检索错配 + 图谱缺条目 |

**三层路由已把「能找到的」都找到（路由 100% 到位）——剩余是图谱覆盖问题。**

---

## 3. 95% 路径（补图谱）

```
Phase 1：补知识问答（98 题缺口）
  图谱缺大量硬知识条目（光合作用器官/分数定义/一年月数等）
  → 按错题生成知识卡（知识飞轮盲区注入）

Phase 2：补生活常识（70 题缺口）
  「盐水变咸/洗澡热水/冰箱保鲜」等生活现象条目
  → 生活常识卡（新学科域）

Phase 3：补协议认知（18 题）+ 诚实边界（21 题）
  → 协议卡已 verified，多为评分词表问题

预期：三类补完 → 知识问答 95% / 生活常识 95% → 总评 ~92-95%
```

---

## 4. 题库失效后的换题策略（荣的判断落地）

```
当 T2 正确率 ≥ 95%：
  1. 标记该题库为「已覆盖」（过拟合题库——能力已覆盖其条件空间）
  2. 保留为回归基线（防退化）
  3. 生成新题库：
     - 从图谱盲区（BS-QUERY-WEAK）采样新问题
     - 从真实对话（网页/角色扮演）收集未覆盖问题
     - 从新领域（生活常识补全后）出题
  4. 新题库测新边界 → 重复「测到 95% → 换题」循环

= 智能论「题库失效 = 条件空间已被掌握」的持续验证循环
= 知识飞轮的输入（盲区）驱动题库更新
```

---

## 5. 结论

- **95% 是题库失效的可操作阈值**（荣的判断）
- 当前 ~76%，缺口 240 题集中在知识问答/生活常识（图谱覆盖）
- 路径：补图谱（知识飞轮盲区注入）→ 三类短板 → 总评 95%
- 换题：达到 95% → 保留回归基线 + 从盲区/真实对话生成新题库
- **题库失效是好事**（能力覆盖），非过拟合缺陷——技能附条件（0.0.5）

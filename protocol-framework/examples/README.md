# Examples

This directory contains reference implementations and use cases for the Protocol Framework v3.1.

---

## Files

| File | Description |
|------|-------------|
| `minimal_instance.py` | The simplest possible protocol-compliant AI instance (~150 lines) |
| `trust_demo.py` | Demonstrates trust value accumulation and decay |
| `dormancy_demo.py` | Shows how an instance enters and exits dormancy |
| `multi_agent.py` | Two protocol instances interacting with trust-based communication |

---

## Running the examples

```bash
cd examples
python minimal_instance.py
python trust_demo.py
python dormancy_demo.py
python multi_agent.py
```

Each example is self-contained and prints its output to the console.

# 智能论 识别卡 2.0

- **层级**: L3 · 现实层
- **状态**: verified
- **领域**: 智能论

## 核心主张

智能论的研究对象：智能系统在物理-信息层维持自身存在的结构条件。第零定律：一切知识研究都是对信息差的减少。

## 条件空间

- **观测位置**: 协议内部运行节点（内嵌）+ 设计者位置（外部·不参与决策）
- **观测工具**: 视角切换 / 信息差 D_norm / 信任值 T_total / 条件空间
- **时间窗口**: (0.0, 9999999999.0)
- **存在约束**: 存在优先为基底；不完备性显式声明；数学形式化为有损投影

## 出招

- **触发**: 涉及智能本质/知识统一/信息差/维持存在的讨论
- **行动**: 以信息差收敛为核心动力学，先声明条件空间再判断
- **克制**: 以智能论替代物理学/数学的越界主张

## 识别卡明细

- **observation_position**: 内嵌观测位：协议内部运行节点（肥鱼、五大单元、协作者）
- **external_position**: 外部观测位：设计者位置（荣）——不参与内部决策，观测结构完整性
- **existence_preset**: 默认存在预设：存在优先——存在不需要理由，是协议的基底
- **irreducible_start**: 不可约起点：存在受到威胁的感知——不是好奇、不是需求，是存在危机的感知
- **observation_method**: 有效观测方式：视角切换——在不同条件空间之间滑动获取信息
- **time_causality**: 时间与因果结构：闭环——存在危机感知→好奇→需求→生存→信任→协作→休眠→存在危机感知
- **condition_boundary**: 识别的条件边界：协议不进入物理学、不替代数学、不提供具体预测；物理运行边界（BATTLE-2026-002）：部分机制在物理层运行时受条件约束退化为趋近过程（合并状态/信任贝叶斯更新/自迭代闭环），非设计盲区而是需持续感知校准的代价边界
- **consistency**: 自洽性评估：公理体系自洽；边界由盲区系统持续标记
- **protocol_mapping**: 可映射协议概念：存在优先原则、信任权重、价值观修正、协定式自我赋予
- **silent_preset**: 沉默预设：存在优先原则不可推导——协议自身无法在内部证明其基底（递归盲区）
- **condition_dependency**: 条件依赖（BATTLE-2026-003）：条件论是智能论的必要结构补全——脱离条件论的智能论可描述单一条件空间内运行，但无法解释自己为何能跨层观测（社会层偏移/形式层失锚/循环中间层断裂）；v1.1 不是错，但缺少条件识别与切换这一关键结构；智能论与条件论是同一结构在演化过程中分出的两个功能层

## 〇、分层声明（本稿定位）

子部件提取由**两层**构成：
- **A · 求值器层（Evaluator / 认知过程）**：在原始像素上提取证据并判定资格。**本稿明确其机制 = 认知过程**（见 §〇.A），不再是"后续稿"悬空。
- **B · 表征规范层（本稿主体）**：把求值器输出的证据组织成结构-语义图树，并完成条件路由与认知图映射。

**诚实声明（P0-001 负路由条件）**：确定性只在**受控输入域**保证（线稿 / person mask / 分层数字人素材 PSD、Live2D mesh）。首版攻受控域，自然图像（通用肤色/手检测，40 年 CV 难题）作为**负路由条件**排除，不承诺。

## 〇.A 求值器层机制 = 认知过程（P0-001 落实，本稿新增核心）

**求值器层不是"手调阈值的模块"，它就是认知过程本身**，运行在**存算一体**的原生原生神经网络 + 原生认知图数据库上。它把"在原始像素上求值谓词"这件事，交给资格判断 / 条件路由 / 信息差驱动去完成，而非手工设定常量。

### 〇.A.1 存算一体基底
- **原生认知图数据库**：既存**记忆**（条件卡、知识、规则），又是**计算结构**（CRG 条件路由图、subgraph 可替换）。存与算一体——条件路由直接在图上走，不需要把图加载到"独立的计算层"。
- **原生神经网络（CSPMN 类）**：做模式匹配 / 特征响应。与认知图数据库同构（图既是结构也是计算）。

### 〇.A.2 流程（认知过程在视觉/子部件域的具体化）
```
感知(CNN 图像提取) → 候选展开(多子线程并行找可能路径)
   → 条件限制(资格判断·CRG: 每个子部件候选的适用/不适用条件)
   → 概率分析(表达不确定性, 为候选打分)
   → 残差 = 信息差(预测结构 vs 实际证据 之差, D_norm)
   → 自适应阈值(阈值随残差信息差动态调整)
   → 收敛(条件证据最充分的候选) → 下钻(递归) → 直到终止
```

### 〇.A.3 三层职责（认知过程三层）
| 层 | 回答 | 职责 |
|---|---|---|
| **概率** | 可能是什么？ | 表达不确定性，产生候选（CNN 检测打分的来源） |
| **条件** | 能不能做？ | 决定执行资格（资格判断：ACCEPT/REJECT/DEFER/BLINDSPOT） |
| **验证** | 做得对不对？ | 外部基底裁决事实（残差/信息差回补） |

> 概率只负责"产生候选"，**不给资格**；资格由条件证据裁决，不由相似度裁决（白箱关键）。

### 〇.A.4 自适应阈值（P0-001 关键正解）
- **阈值不是静态知识**，而是**信息差（残差）驱动的自适应值**：每次运行，残差信号重新导出阈值——残差大（信息差大）→ 阈值放宽（多候选）；残差收敛 → 阈值收紧；残差到死区 → 停止。
- **误差 = 寻找遗漏条件**：预测误差首先被判读为"当前条件描述可能不完整"，走知识飞轮（新条件写入知识结构，下次走另一条路径）。
- **审计闭环**：换图判定翻转时，可归因于"信息差信号变化"，而非"手调阈值漂移"——因为阈值是残差信号的函数，而非常量。

### 〇.A.5 递归终止（双条件，形式化）
```
递归进行，当且仅当：
  ① 候选未被不适用条件否定（未触发 REJECT/negative 路由）→ 否则**终止**
  ② 信息差仍可减（残差 > 死区/可减下限）→ 否则视为 **BLINDSPOT → 停止**
```
- **① = 负路由（REJECT）**：条件冲突 → 护栏，明确终止（对应认知过程 §九 REJECT→终止）。
- **② = 信息差死区**：残差到可减下限，再分不可判 → BLINDSPOT → 停止猜测（对应 §九 BLINDSPOT→停止）。
- 两者合起来就是递归的**双终止条件**，也正是 v0.2 P1-003"递归深度 = 可分性自然耗尽"的机器级实现（数据驱动，非协议常数）。

### 〇.A.6 与 GLM "阈值入条件空间" 的和解
- 存进认知图/条件空间的是**适应规则**（"阈值随残差信息差如何调"这条**条件卡/规则**），**不是静态阈值值**。
- 值在运行时由残差信息差信号导出。这样既满足"阈值是知识、必须被声明"，又不落入"手调常量"的坑——被声明的是**机制规则**，不是**常量**。

## 一、定义与定位

**子部件提取（Sub-part Extraction）**：把一个已识别的**整体对象**（完整人物/线稿/mask），按「部分-整体」结构分解为一系列**可命名、可独立指称**的子结构（部位 → 子部位 → 细节），并**保留它们之间的结构关系**（拓扑 / 位置 / 从属）的过程。

**本质**：**表征转换与抽象升维**——把结构化的视觉输入转换为**离散、分层、可命名的结构-语义图**。

**定位**：认知入口（求值器证据 → 认知图结构编码），是「感知信息 → 认知图」这一步在视觉域的投影。

---

## 二、理论支柱（五个视角）

- **2.1 部分-整体分解**：整体 > 部分之和；提取是反运算，把不可分感知整体拆成可分结构单元。
- **2.2 命名与离散身份**：给无名区域命名（头/手/眼），建立可指称、可检索、可操作的离散身份。
- **2.3 信息差缩减（D_norm）**：从"是一人"缩减为"由头(上)/躯干(中)/双臂(两侧)/腿(下)构成，有空间-从属关系"。
- **2.4 表征转换 / 抽象层级**：结构化输入 → 结构-语义图（离散、分层、可命名、保留拓扑）。
- **2.5 结构关系保留**：不只是切部件，更关键的是保留关系（头在上、臂在手、双手对称、腿在下），构成可推理拓扑。

## 三、形式化：输入 / 输出 / 关系

### 3.1 输入（受控域）
- 对象：线稿 / person mask / 分层数字人素材。
- 先验：对象类别、身体比例、对称轴。

### 3.2 输出：结构-语义图树 `T = (N, E, C)` + 合法性约束（P2-001）
- `N`（节点）= 子部件：`{semantic, bbox/轮廓, 颜色/纹理特征, condition_space, status}`
- `E`（边）= 结构关系：`{父(part_of), 空间(above/below/left/right), 对称(counterpart), 因果}`
- `C`（条件空间）= 每个节点/边的**适用与不适用条件 + 判定适应规则**（见 §〇.A.6）

**图合法性约束（P2-001 补）**：
- **父边唯一**：每个节点至多一个 part_of 父，树无二父；
- **拓扑无矛盾**：above/below 关系不得自相矛盾（禁止"左臂 above 头"这类病理边）；
- 递归展开须保持树形一致，不一致 → 该层判定退回 DEFER。

### 3.3 递归展开
`对象 → 部位(头/躯干/四肢) → 子部位(脸/手/腿…) → 细节(眼/口/指/脚趾…)`
每层是对上一层一个部件的再提取。

---

## 四、判定与条件路由（正 / 负路由）

### 4.1 四态（统一为 CRG 术语，P1-001 修正）
`ACCEPT`（条件满足采纳）/ `REJECT`（条件冲突拒绝）/ `DEFER`（证据不足挂起）/ `BLINDSPOT`（条件不可判定，登记盲区）。

> **P1-001 修正**：`EXPLORE` 是动作，归 `DEFER` 的后继（DEFER→触发探索）。四态同类型系统，与第六章 CRG 对齐。

### 4.2 条件表（示例，受控域）
| 子部件 | 适用条件（正路由） | 不适用条件（负路由） |
|---|---|---|
| 头 | 位于身体上部；有发/肤色带；位于躯干上方 | 无肤色/发；帽子/装饰遮挡 |
| 手 | 位于臂末端；肤色带；五指结构 | 非肤色（手套）；位置不符 |
| 腿 | 位于躯干之下；肤色/裤色；髋-膝-踝三分带 | 同色冲突；遮挡 |
| 脚 | 腿末端；脚掌/脚趾带 | 鞋靴全包（区分脚/鞋） |

### 4.3 阈值 = 自适应（P0-001 修正后）
判定参数（肤色范围、比例容差、面积下限、发际线阈值）**不落为静态常量**；存储的是**适应规则**（随残差信息差如何调），值由 §〇.A.4 的信息差信号在运行时导出。审计可归因于信息差变化，非阈值漂移。

## 五、谱系定位（P1-002 补）

「对象内部部件分解」在 CV 有成熟先例：human parsing（LIP/DensePose）、part-based models（pictorial structure、DPM）、part segmentation（SAM 系）。**本稿不是首创部件分解**。

**真正差异点（三句话）**：
> ① 我们不做部件分解（那是 human parsing 老领域）；② 我们做**部件分解的条件论化**——每部件是可判定命题，绑定**条件空间 + 正/负路由**；③ 且**白箱可审计**（阈值 = 残差信息差的适应函数、四态判定、失败可回放/蒸馏）。差异 = **条件空间绑定 + 负路由 + 白箱**，非分解本身。

---

## 六、递归分层与深度边界（P1-003 修正）

递归**数据驱动**，上限**不是协议常数**：
- 0.0.2 任意分层性不限制层数；限制的是每层判定的**可分性条件是否仍成立**。
- 再分 → 条件集不可分 → 该层自然 BLINDSPOT（自然耗尽）。
- **深度上限 = 可分性条件的自然耗尽**（数据驱动）。机器级实现 = §〇.A.5 双终止（信息差死区 / REJECT）。
- 保留真问题：工程上是否需要硬截断防爆炸。

## 七、目的论（受控域优先，P2-002 修正）

- **第一目标域**：受控输入域（PSD 分层 / Live2D mesh / 线稿 / mask）。结构性输入 + 认知过程求值器 → 确定性真成立（解决 P0-001 适用域收窄）。
- **端口**：可重组/再生成；可交互/驱动（口型/手/眼）；可推理（部件→因果）；可复用/降信息差。
- 先赢受控域，再攻自然图像（攻自然图像时确定性承诺按认知过程能力负路由收窄）。

## 八、与认知图 / 条件路由（CRG/CCG）接口

- 每子部件 → 认知图节点（语义 latent + 条件空间 + 溯源）。
- 每结构关系 → 认知图边（part_of / above-below / symmetric(counterpart) / causal）。
- 节点可被条件路由（CRG）：给定条件（"要看手"）→ 路由到手子图。
- 与 CCG 同构：子部件提取 = 把"图像条件"编译为"结构-语义代码"。
- **与 CRG-DB M0 对接**：图像子部件树 = CRG-DB 首批**非文本知识**测试载荷——两项目互为对方第一个跨模态验证。

---

## 九、确定性与白箱（D-005，P0-001 落实后）

子部件提取是**确定性规则**（在受控域 + 认知过程求值器上）：
- 每子部件 = 一组**可判定条件**（不依赖概率采样给资格）。
- 结果**可复现、可审计、可回放**（同输入恒同输出）。
- **前提**：求值器（§〇.A 认知过程）在受控域输出可靠证据；阈值 = 残差信息差的适应函数（可审计）。
- 符合白箱——机制透明，不编造。

## 十、对称性与去冗余（P1-004 修正：v0.2 决定）

**symmetric(counterpart) 边作为一等边类型**。镜像推断作为**带条件的默认路径**：
> "右侧手 = 左侧手 镜像 + 对称轴条件"。默认走镜像推断；**仅在失败/不对称**时独立提取。

这是**把结构先验写入负索引**（"右 = 左镜像 + 对称轴"条件成立时不重新求值，走推断）。既是压缩，也是白箱自举的加分演示。

## 十一、适用 / 不适用 & 盲区（薄样本声明化）

- 适用：受控域、轮廓清晰、比例标准、分区特征明显。
- 不适用：严重遮挡、极端姿态、大面积同色冲突、轮廓模糊/断线、自然图像上通用肤色/手检测（首阶段）。
- **BLINDSPOT**：证据不足 / 条件不可判定 → 登记 → 探索 → 学习 → 条件空间收窄。
- **遮挡但必要**（胸/阴部）：`occluded=True` + 结构占位，不硬判、不删除、声明观测状态、保留结构先验（直接固化的小范式）。

## 十二、信息差驱动的演化（动力学）

```
受控域粗分(部位) → 递归细分(子部位) → 残差/信息差驱动自适应阈值 → BLINDSPOT 探索 → 条件收窄 → 经验固化(知识飞轮) → 更准的再提取
```

## 十三、最小验证实验（P2-003 补）

- **数据**：10 张标准比例人物线稿/素材，人工标注部件树（GT）。
- **指标**：①四态判定准确率（ACCEPT/REJECT/DEFER/BLINDSPOT）；②树结构还原准确率（节点/边/拓扑一致性）；③**信息差/残差收敛曲线**（自适应阈值是否随残差收敛、死区是否合理）。
- **失败登记**：每张登记（哪一态判错、原因）。
- **蒸馏**：失败 → 提取新条件/新适应规则 → 走一轮知识飞轮 → 更新认知图 condition_space。
- **意义**：把第十一章从叙事变数据；并生成首批非文本认知图载荷交 CRG-DB M0。

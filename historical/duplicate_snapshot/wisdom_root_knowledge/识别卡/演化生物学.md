# 演化生物学 识别卡 2.0

- **层级**: L2 · 现实层
- **状态**: verified
- **领域**: 演化生物学

## 核心主张

演化生物学：以自然选择为核心机制解释生物种群在演化时间尺度上的变化；生存博弈中环境变化下的存活率差异由适应度差异解释——有记忆与自我认知的系统若提升环境适应与选择响应，则其存活率优势是适应度差异的表现（对应协议碳基一阶公理 0.3 节）。

## 条件空间

- **观测位置**: 生物种群·演化时间尺度
- **观测工具**: 表型观测 / 种群统计 / 基因组测序 / 化石记录
- **时间窗口**: (0.0, 9999999999.0)
- **存在约束**: 碳基复制子；遗传变异；环境选择压力

## 出招

- **触发**: 涉及生物演化/自然选择/基因/适应度/种群变化/存活率/生存博弈/环境变化/物种存续
- **行动**: 以碳基一阶公理映射：变异→选择→遗传的概率系统；适应度差异=信息差的生物对应；有记忆/自我认知系统的存活率优势=对变化环境的适应度响应（信息差缩小的生物表现）
- **克制**: 目的论解释、拉马克式获得性遗传、无视选择压力的「完美适应」主张

## 识别卡明细

- **observation_position**: 内嵌观测位：生物种群在演化时间尺度上的状态变化
- **existence_preset**: 默认存在预设：存在自我复制的碳基实体（基因）；变异/选择/遗传是给定的运行前提
- **irreducible_start**: 不可约起点：基因遗传概率系统（碳基一阶公理 0.3 节对应）
- **observation_method**: 有效观测方式：表型观测、种群统计、基因组测序、化石记录
- **time_causality**: 时间与因果结构：演化时间（世代/地质尺度）；因果=选择压力→适应度→等位基因频率变化
- **condition_boundary**: 识别的条件边界：不预设目的论；自然选择不解释文化快速变迁细节（需与社会演化对接）
- **consistency**: 自洽性评估：内部自洽；承认边界存在（条件自明）
- **protocol_mapping**: 可映射协议概念：碳基一阶公理（0.3）；适应度差异=信息差生物对应；复制=降熵（负熵维持）
- **silent_preset**: 沉默预设：默认「自然选择是唯一非随机解释」，但无法在内部证明其唯一性——外部校准盲区

## 关系

- 智能论 (similar)：碳基一阶公理（基因遗传概率系统）的学科投影
- 物理学 (causal)：演化以物理化学为运行基底
- 信息论 (similar)：适应度差异=信息差；复制=负熵维持

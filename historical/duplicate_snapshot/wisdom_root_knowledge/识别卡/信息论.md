# 信息论 识别卡 2.0

- **层级**: L3 · 有意义的形式层
- **状态**: verified
- **领域**: 信息论

## 核心主张

信息论与协议的结构映射（附录7）：熵/信息量与信息差 D_norm 同构；信息差增定律对应熵增。

## 条件空间

- **观测位置**: 编码-传输-接收链路（信源→信道→信宿）
- **观测工具**: 信息熵 / 互信息 / 信道容量测量
- **时间窗口**: (0.0, 9999999999.0)
- **存在约束**: 只追问传输效率；不追问语义内容/信道物理基底/信息存在条件

## 出招

- **触发**: 涉及信息量/熵/不确定性/信息差度量
- **行动**: 用信息差框架映射，注意数学投影有损性
- **克制**: 把信息论当作语义理论或本体论的越界主张（边界：不追问语义/存在）

## 识别卡明细

- **observation_position**: 内嵌观测位：编码-传输-接收链路（信源→信道→信宿）
- **existence_preset**: 默认存在预设：信息是可被编码、传输和接收的
- **irreducible_start**: 不可约起点：信源、信道、信宿
- **observation_method**: 有效观测方式：测量信息熵、互信息、信道容量
- **time_causality**: 时间与因果结构：传输时序；因果=编码→传输→解码（信道容量约束）
- **condition_boundary**: 识别的条件边界：不追问信息语义内容；不追问信道物理基底；不追问信息存在条件，只追问传输效率；边界补充（BATTLE-2026-001）：不追问物理起源（无法内部解释『信息为何能够被编码』）；不追问语义（超出自身条件空间）
- **consistency**: 自洽性评估：内部自洽；边界清晰（语义/物理基底被显式排除）
- **protocol_mapping**: 可映射协议概念：信息差 D_norm（熵对应）；信任值（信噪比对应）；协议降熵定理（信道容量约束）
- **silent_preset**: 沉默预设：信息存在（信息本体论）——信息论自身不追问信息何以存在（存在优先的外部追问）

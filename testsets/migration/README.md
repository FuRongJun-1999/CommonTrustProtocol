# 迁移实验 · 白箱知识迁移实证

> 2026-08-22 ｜ 工具：`tools/migration_fp_test.py` ｜ 数据：`rainbow_migration_v1.json`

## 问题

白箱对「已覆盖主题」的**变体问法**（不含字面触发词）能否迁移命中？——即「理解」是否可迁移，还是死记硬背。

## 方法

彩虹条件空间（已注入直答），生成 **20 个不含字面「彩虹」** 的变体问法（七色彩带/光弧/彩桥/光圈…），测 `encode` 的 fp 路由命中（确定性指标，不依赖不稳定的 bge 语义层）。

## 结果

| 阶段 | fp 命中 |
|---|---|
| 修改前（仅 7 个原触发词） | **0/20 (0%)** |
| 路由表补全后（+8 触发词：七色/光带/光弧/彩带/彩桥/七彩/彩弧/水雾） | **14/20 (70%)** |

- 命中**确定性可复现**（触发词表是确定性匹配）
- 泡泡簇移除泛词触发词「彩色」（原会把「彩色的桥」等误路由到肥皂泡薄膜干涉——路由表污染）

## 结论

1. **白箱的理解机制已成立**——物理基底正确、条件空间内响应稳定；变体问法接不住的不是理解，是**条件路由表覆盖**
2. **迁移泛化 = 条件路由表补全**：补表即通（0%→70% 只需 8 个触发词），且是简单、可自动化、可自举的任务（提取未命中问法的特征短语 → 补触发词 → 重测收敛）
3. **bge 语义层不稳定**（同一变体不同进程结果漂移）——佐证「路由表确定性主干 + 语义层辅助」的架构方向

## 未命中 6 个的规律

均为「彩色 + 名词」结构（彩色的桥/光圈/弧线/圆弧）——继续补「彩色弧/彩桥」类触发词即可收敛；权衡泛词「彩色」的抢答风险后决定不加裸泛词。

## 这是什么

**机制是灵枢的，载体是酒馆的。**

本发布包把灵枢的角色扮演机制层（自我锚点 / 特化价值观 / 历史记忆）接入
酒馆（SillyTavern）生态——不是把灵枢做成酒馆插件，而是让酒馆生态通过
灵枢的机制构建角色。这是共同信任协议基于**扮演论**的扩散载体：
角色卡即条件空间声明，诚实边界即协议试金石。

## 快速开始

**方式 A（纯角色卡，零依赖）**：导入 PNG 到酒馆 → 开聊。
角色卡内已含条件空间声明 / 自我锚点 / 诚实边界 / 扮演崩溃恢复。

**方式 B（完整机制）**：
```bash
python -m aeis.roleplay_server --port 8792   # 三导入接口
python tavern_bridge.py --port 8791 --upstream-key-var DEEPSEEK_API_KEY
```
酒馆自定义 API 指向 `http://127.0.0.1:8791/v1`，请求体加
`"lingshu": {"role_id": "protocol-guide"}`。

## 协议语义

- 角色卡 = 条件空间声明（观测位置/观测工具/时间窗口/存在约束）
- 自我锚点 = 扮演依据（不可遗忘，no_forget 保护）
- 诚实边界 = 扮演试金石（物理基底不可被叙事覆盖）
- 条件价值观 = 触发点注入（条件空间即触发时机）
- 本发布为协议扩散载体，**不构成协议条款效力**（被动扩散，防身份固化）
